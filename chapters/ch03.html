3장

데이터와 Type

이번 장 목표
  • 변수가 무엇인지, 왜 Type이 필요한지 설명할 수 있어요.
  • DATA로 변수를 만들고 값을 넣고 출력할 수 있어요.
  • ABAP의 기본 Type(c n i p d t string)을 구분해서 쓸 수 있어요.
  • 계산, 문자열 이어 붙이기, 날짜 계산을 해 봐요.
  • 바뀌지 않는 값은 CONSTANTS로 만들어요.

3-1. 변수는 이름표 붙은 상자예요

2장에서는 'Hello ABAP'처럼 정해진 글자만 출력했어요. 하지만 실제 프로그램은 사용자가 넣은 값, 계산한 결과처럼 그때그때 바뀌는 값을 다뤄요. 이런 값을 잠깐 담아 두는 곳이 변수예요.

변수는 이름표가 붙은 상자라고 생각하면 쉬워요. 상자마다 "무엇을 담을 수 있는지"가 정해져 있는데, 이게 바로 Type이에요.

Type이 정해져 있으면 좋은 점이 있어요. 숫자 상자에 글자를 넣으려 하거나, 10칸짜리 상자에 20글자를 넣으려 할 때 SAP가 미리 알려 주거나 정해진 규칙대로 처리해 줘요.

3-2. DATA로 변수 만들기

변수는 DATA 키워드로 만들어요. 이걸 선언이라고 해요.

DATA gv_age  TYPE i.                 " 정수를 담는 변수
DATA gv_name TYPE c LENGTH 10.       " 글자 10칸을 담는 변수

DATA 이름 TYPE 타입. 순서예요. 이름 앞의 gv_는 0장에서 정한 규칙대로 Global Variable(전역 변수)이라는 표시예요.

변수를 여러 개 만들 땐 2장에서 배운 체인 문장이 딱이에요.

DATA: gv_age   TYPE i,
      gv_name  TYPE c LENGTH 10,
      gv_price TYPE p LENGTH 8 DECIMALS 2.

값 넣고 출력하기

= 왼쪽은 상자, 오른쪽은 넣을 값이에요. "오른쪽 값을 왼쪽 상자에 넣어라"로 읽으면 돼요.

REPORT yg##_03_data.

DATA: gv_age  TYPE i,
      gv_name TYPE c LENGTH 10.

START-OF-SELECTION.
  gv_name = '홍길동'.
  gv_age  = 25.

  WRITE: / '이름:', gv_name,
         / '나이:', gv_age.

나이 앞에 공백이 많이 생겼죠? WRITE는 숫자를 오른쪽에 붙여서 출력하기 때문이에요. 틀린 게 아니니 걱정하지 않아도 돼요.

처음부터 값을 넣어 두기: VALUE

선언할 때 VALUE를 붙이면 처음 값을 정해 둘 수 있어요.

DATA gv_count TYPE i VALUE 10.

반대로 CLEAR gv_count.라고 쓰면 상자가 처음 상태(초기값)로 비워져요. 숫자면 0, 글자면 공백이 돼요.

3-3. 꼭 알아야 할 기본 Type

ABAP에는 Type이 많지만, 입문 단계에서는 아래 일곱 가지면 충분해요.

Type 담는 것 선언 예 초기값 예시 값
c 글자(길이 고정) TYPE c LENGTH 10 공백 '홍길동'
string 글자(길이 자유) TYPE string 빈 문자열 '아무리 길어도 OK'
n 숫자로만 된 글자 TYPE n LENGTH 5 '00000' '00123' (우편번호, 사번)
i 정수 TYPE i 0 25, -3
p 소수(자릿수 고정) TYPE p LENGTH 8 DECIMALS 2 0 25000.50 (금액)
d 날짜 YYYYMMDD TYPE d '00000000' '20261117'
t 시간 HHMMSS TYPE t '000000' '153000'
어떤 Type을 고를까요?
  • 계산할 숫자면 i(정수) 또는 p(소수, 금액)를 써요.
  • 우편번호, 사번처럼 숫자로 생겼지만 계산하지 않는 값은 n을 써요. 앞자리 0이 사라지지 않아요.
  • 이름, 메시지 같은 글자는 c 또는 string을 써요. 길이가 정해져 있으면 c, 들쭉날쭉하면 string이 편해요.
p Type의 LENGTH와 DECIMALS

TYPE p LENGTH 8 DECIMALS 2에서 DECIMALS 2는 소수점 아래 두 자리라는 뜻이에요. LENGTH 8은 숫자 칸의 크기(바이트)인데, 숫자 자릿수로는 대략 2 × 8 − 1 = 15자리가 들어가요. 금액이라면 LENGTH 8 DECIMALS 2면 넉넉해요.

3-4. 계산하기

연산자 뜻 예 결과
+ - * 더하기, 빼기, 곱하기 3 * 4 12
/ 나누기 7 / 2 결과 Type에 따라 다름 (아래 참고)
DIV 몫 7 DIV 2 3
MOD 나머지 7 MOD 2 1
** 거듭제곱 2 ** 3 8 
DATA: gv_a      TYPE i VALUE 7,
      gv_b      TYPE i VALUE 2,
      gv_result TYPE i.

START-OF-SELECTION.
  gv_result = gv_a + gv_b.           " 9
  WRITE: / '더하기:', gv_result.

  gv_result = gv_a DIV gv_b.         " 3
  WRITE: / '몫:', gv_result.

  gv_result = gv_a MOD gv_b.         " 1
  WRITE: / '나머지:', gv_result.

  gv_result = gv_a / gv_b.           " 4 (3.5가 반올림돼요!)
  WRITE: / '나누기:', gv_result.
자주 하는 실수
  • 연산자 앞뒤는 꼭 띄어 써요. gv_a+1처럼 붙여 쓰면 ABAP은 "더하기"가 아니라 "글자 자르기"(앞에서 1칸 건너뛴 곳부터 읽기)로 받아들여요. 숫자 변수면 문법 오류가 나고, 글자 변수면 엉뚱한 결과가 나와요. 항상 gv_a + 1처럼 써요.
  • i끼리 나누면 반올림돼요. 7 / 2를 i 변수에 넣으면 3.5가 반올림되어 4가 돼요. 몫이 필요하면 DIV, 소수가 필요하면 결과 변수를 p Type으로 만들어요.
이렇게도 써요

요즘 코드에서는 "자기 자신에 더하기"를 이렇게 짧게 써요. 1주차 과제에서 써 본 친구들도 있었죠.

gv_sum = gv_sum + gv_num.   " 원래 쓰던 방식
gv_sum += gv_num.           " 같은 뜻, 짧은 방식

-=, *=, /=도 같은 식이에요.

3-5. 문자열 이어 붙이기

이름과 인사말을 합쳐서 홍길동님 안녕하세요 같은 문장을 만들고 싶을 때가 많아요. 가장 기본적인 방법은 CONCATENATE예요.

DATA: gv_name TYPE c LENGTH 10 VALUE '홍길동',
      gv_msg  TYPE string.

START-OF-SELECTION.
  CONCATENATE gv_name '님 안녕하세요' INTO gv_msg.
  WRITE / gv_msg.                                  " 홍길동님 안녕하세요

  CONCATENATE '반갑습니다' gv_name INTO gv_msg SEPARATED BY space.
  WRITE / gv_msg.                                  " 반갑습니다 홍길동
  • CONCATENATE 값1 값2 … INTO 결과. 순서예요.
  • SEPARATED BY space를 붙이면 사이에 공백 한 칸을 넣어 줘요.
  • gv_name은 10칸짜리라 뒤에 공백 7칸이 남아 있지만, CONCATENATE는 c Type 뒤쪽 공백을 알아서 빼고 붙여 줘요.
이렇게도 써요

&& 연산자나 문자열 템플릿 |…|으로 더 짧게 쓸 수도 있어요. 템플릿 안에서 변수는 { }로 감싸고, 괄호 안쪽은 꼭 한 칸씩 띄워요.

gv_msg = gv_name && '님 안녕하세요'.
gv_msg = |{ gv_name }님 안녕하세요|.

3-6. 날짜와 시스템 필드

시스템 필드 sy-

SAP는 프로그램이 실행될 때 자주 쓰는 정보를 sy-로 시작하는 시스템 필드에 미리 넣어 둬요. 따로 만들지 않아도 바로 쓸 수 있어요.

시스템 필드 담긴 값 예
sy-datum 오늘 날짜 20261117
sy-uzeit 지금 시각 153000
sy-uname 로그인한 사용자 ID CODE05
sy-index 반복문의 몇 번째 바퀴인지 4장에서
sy-subrc 방금 한 일이 성공했는지(0이면 성공) 8~9장에서

날짜 계산

d Type은 날짜끼리 빼면 날 수, 날짜에 숫자를 더하면 그만큼 지난 날짜가 나와요. 달마다 날 수가 다른 것도 SAP가 알아서 계산해 줘요.

DATA: gv_due  TYPE d,
      gv_end  TYPE d VALUE '20261231',
      gv_days TYPE i.

START-OF-SELECTION.
  gv_due  = sy-datum + 30.       " 오늘부터 30일 뒤
  gv_days = gv_end - sy-datum.   " 올해가 며칠 남았는지

  WRITE: / '오늘:',       sy-datum,
         / '반납 기한:',  gv_due,
         / '올해 남은 날:', gv_days.
날짜가 2026.11.17처럼 보여요

변수 안에는 20261117로 들어 있지만, WRITE는 사용자 설정에 맞춰 보기 좋게 바꿔서 출력해요. 그래서 사람마다 2026.11.17, 11/17/2026처럼 다르게 보일 수 있어요.

3-7. 바뀌지 않는 값: CONSTANTS

배송비, 세율처럼 프로그램 안에서 절대 바뀌면 안 되는 값은 CONSTANTS로 만들어요. 이름은 gc_(Global Constant)로 시작해요.

CONSTANTS: gc_delivery TYPE p LENGTH 8 DECIMALS 2 VALUE '3000.00',
           gc_max_qty  TYPE i VALUE 10.
  • CONSTANTS는 VALUE가 꼭 있어야 해요.
  • 나중에 gc_delivery = 5000.처럼 바꾸려고 하면 문법 오류가 나요. 실수로 값을 바꾸는 걸 막아 주는 거예요.
  • 소수가 있는 값은 '3000.00'처럼 작은따옴표로 감싸서 써요.
나만의 Type 이름: TYPES

같은 모양의 변수를 여러 번 만들 때는 TYPES로 Type에 이름을 붙여 두면 편해요. TYPES는 상자가 아니라 상자의 설계도라서 값을 담을 수 없어요.

TYPES ty_amount TYPE p LENGTH 8 DECIMALS 2.     " 설계도

DATA: gv_price TYPE ty_amount,                   " 설계도로 만든 상자
      gv_total TYPE ty_amount.

TYPES는 8장에서 여러 칸짜리 Structure를 만들 때 본격적으로 써요.

이렇게도 써요

값을 넣는 그 자리에서 변수를 바로 만드는 인라인 선언도 있어요. Type은 오른쪽 값을 보고 SAP가 정해요.

DATA(gv_count) = 10.            " TYPE i 변수가 만들어져요
DATA(gv_text)  = `Hello`.       " TYPE string 변수가 만들어져요

편하지만 Type이 눈에 보이지 않아서, 처음에는 DATA … TYPE …로 직접 선언하는 연습을 충분히 하는 게 좋아요.

3-8. 미니 실습: 장바구니 계산

직접 해 보기

프로그램 YG##_03_CART를 만들어서 아래처럼 출력해 보세요.

  • 상품 이름(c LENGTH 20), 단가(p LENGTH 8 DECIMALS 2), 수량(i) 변수를 만들어요.
  • 배송비 3000은 CONSTANTS로 만들어요.
  • 합계 = 단가 × 수량 + 배송비 로 계산해요.
  • 도착 예정일은 오늘(sy-datum)부터 3일 뒤예요.
  • 첫 줄의 장바구니 계산은 Text Symbol 001로 출력해요(2장 2-7).
예시 답안 보기
*&---------------------------------------------------------------------*
* 작성자: 홍길동   작성일: 2026-11-17
* 설명  : 변수, 계산, CONSTANTS, 날짜 계산 연습
*&---------------------------------------------------------------------*
REPORT yg##_03_cart.

" 바뀌지 않는 값
CONSTANTS gc_delivery TYPE p LENGTH 8 DECIMALS 2 VALUE '3000.00'.

" 변수
DATA: gv_item  TYPE c LENGTH 20,
      gv_price TYPE p LENGTH 8 DECIMALS 2,
      gv_qty   TYPE i,
      gv_total TYPE p LENGTH 8 DECIMALS 2,
      gv_date  TYPE d.

START-OF-SELECTION.
  " 1. 값 넣기
  gv_item  = 'ABAP 입문서'.
  gv_price = '25000.00'.
  gv_qty   = 2.

  " 2. 계산하기
  gv_total = gv_price * gv_qty + gc_delivery.
  gv_date  = sy-datum + 3.

  " 3. 출력하기
  WRITE: / TEXT-001,                 " 장바구니 계산
         / '상품:', gv_item,
         / '단가:', gv_price,
         / '수량:', gv_qty,
         / '배송비:', gc_delivery,
         / '합계:', gv_total,
         / '도착 예정일:', gv_date.
확인 문제
  1. 우편번호 01234를 담으려고 해요. i와 n 중 어떤 Type이 좋을까요? 이유도 말해 보세요.
  2. 아래 코드를 실행하면 gv_r에는 각각 무엇이 들어갈까요? (gv_r은 TYPE i) 
    gv_r = 10 DIV 3.
gv_r = 10 MOD 3.
gv_r = 10 / 4.
  3. 아래 코드에서 잘못된 곳은 어디일까요? 
    CONSTANTS gc_rate TYPE p LENGTH 3 DECIMALS 2.
gv_total = gv_price*gv_qty.
  4. 오늘이 2026년 11월 17일이에요. sy-datum + 14는 어떤 날짜일까요?
정답 보기
  1. n이 좋아요. i에 넣으면 숫자 1234가 되어 앞자리 0이 사라져요. 우편번호는 계산할 일이 없는 "숫자로 된 글자"라서 n이 맞아요.
  2. 3, 1, 3이에요. 10 / 4는 2.5인데 i에 넣으면서 반올림되어 3이 돼요.
  3. ① CONSTANTS에 VALUE가 없어요. VALUE '0.10'처럼 값을 꼭 넣어야 해요. ② gv_price*gv_qty는 연산자 앞뒤에 공백이 없어요. gv_price * gv_qty로 띄어 써요.
  4. 2026년 12월 1일(20261201)이에요. 11월은 30일까지라서 SAP가 달을 넘겨 계산해 줘요.
정리
  • 변수는 DATA 이름 TYPE 타입.으로 만들고, =로 값을 넣어요.
  • 계산은 i·p, 계산하지 않는 숫자 글자는 n, 글자는 c·string, 날짜·시간은 d·t예요.
  • 연산자 앞뒤는 꼭 띄어 쓰고, i끼리 나누면 반올림된다는 걸 기억해요.
  • 글자는 CONCATENATE … INTO …로 이어 붙여요.
  • sy-datum 같은 시스템 필드는 만들지 않아도 바로 쓸 수 있어요. 날짜는 더하고 뺄 수 있어요.
  • 바뀌면 안 되는 값은 CONSTANTS로, Type 설계도는 TYPES로 만들어요.
