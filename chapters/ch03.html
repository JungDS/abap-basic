3장

데이터와 Type

이번 장 목표
  • 변수가 무엇인지, 왜 Type이 필요한지 설명할 수 있어요.
  • DATA로 변수를 만들고 값을 넣고 출력할 수 있어요.
  • ABAP의 기본 Type(c n i p d t string)을 구분해서 쓸 수 있어요.
  • 계산하고, 문자열을 이어 붙이거나 일부만 꺼내고, 날짜를 계산해 봐요.
  • 바뀌지 않는 값은 CONSTANTS로 만들어요.

3-1. 변수는 이름표 붙은 상자예요

2장에서는 'Hello ABAP'처럼 정해진 글자만 출력했어요. 하지만 실제 프로그램은 사용자가 넣은 값, 계산한 결과처럼 그때그때 바뀌는 값을 다뤄요. 이런 값을 잠깐 담아 두는 곳이 변수예요.

변수는 이름표가 붙은 상자라고 생각하면 쉬워요. 상자마다 "무엇을 담을 수 있는지"가 정해져 있는데, 이게 바로 Type이에요.

Type이 정해져 있으면 좋은 점이 있어요. 숫자 상자에 글자를 넣으려 하거나, 10칸짜리 상자에 20글자를 넣으려 할 때 SAP가 미리 알려 주거나 정해진 규칙대로 처리해 줘요.

3-2. DATA로 변수 만들기

변수는 DATA 키워드로 만들어요. 이걸 선언이라고 해요.

DATA gv_age  TYPE i.                 " 정수를 담는 변수
DATA gv_name TYPE c LENGTH 10.       " 글자 10칸을 담는 변수

DATA 이름 TYPE 타입. 순서예요. JavaScript의 let age;와 비슷하지만, ABAP은 Type을 꼭 같이 적어요. 이름 앞의 gv_는 0장에서 정한 규칙대로 Global Variable(전역 변수)이라는 표시예요.

변수를 여러 개 만들 땐 2장에서 배운 체인 문장이 딱이에요.

DATA: gv_age   TYPE i,
      gv_name  TYPE c LENGTH 10,
      gv_price TYPE p LENGTH 8 DECIMALS 2.

값 넣고 출력하기

= 왼쪽은 상자, 오른쪽은 넣을 값이에요. "오른쪽 값을 왼쪽 상자에 넣어라"로 읽으면 돼요.

직접 해 볼게요. 아래 새로 만들기 카드대로 프로그램을 새로 만들고, 코드를 따라 쳐서 실행해 보세요. 만드는 순서는 2-2와 같아요. Title 칸에는 카드에 적힌 글자를 그대로 넣어요. 이 장에서 카드가 붙은 코드는 모두 이렇게 해요. 카드 없이 나오는 짧은 코드는 모양만 눈에 익히면 돼요.

[예제] 변수 선언과 출력

DATA: gv_age  TYPE i,
      gv_name TYPE c LENGTH 10.

START-OF-SELECTION.
  gv_name = '홍길동'.
  gv_age  = 25.

  WRITE: / '이름:', gv_name,
         / '나이:', gv_age.

25 앞에 공백이 많이 생겼죠? WRITE는 숫자를 오른쪽에 붙여서 출력하기 때문이에요. 틀린 게 아니니 걱정하지 않아도 돼요.

  • DATA는 REPORT 줄 아래, START-OF-SELECTION 위에 모아 써요. 상자를 먼저 만들어 둬야 그 아래에서 쓸 수 있어요.
  • 글자 값은 '홍길동'처럼 작은따옴표로 감싸고, 숫자는 25처럼 그대로 써요.
  • 쉼표로 이은 값은 같은 줄에 한 칸 띄고 이어서 나와요. /가 붙은 값부터 새 줄이에요.
  • 내 화면 맨 위에는 그림 2-7처럼 Title이 적힌 제목 줄과 가로선이 더 있어요. 교재는 앞으로 이 두 줄을 빼고 결과만 보여 줘요.
처음부터 값을 넣어 두기: VALUE

선언할 때 VALUE를 붙이면 처음 값을 정해 둘 수 있어요.

DATA gv_count TYPE i VALUE 10.

반대로 CLEAR gv_count.라고 쓰면 상자가 비워져요. VALUE로 넣어 둔 10으로 돌아가는 게 아니라 Type의 초기값이 돼요. 숫자면 0, 글자면 공백이에요.

VALUE 없이 만든 변수에도 처음부터 이 초기값이 들어 있어요. JavaScript의 undefined 같은 것은 없어요.

3-3. 꼭 알아야 할 기본 Type

ABAP에는 Type이 많지만, 입문 단계에서는 아래 일곱 가지면 충분해요.

Type 담는 것 선언 예 초기값 예시 값
c 글자(길이 고정) TYPE c LENGTH 10 공백 '홍길동'
string 글자(길이 자유) TYPE string 빈 문자열 '아무리 길어도 OK'
n 숫자로만 된 글자 TYPE n LENGTH 5 '00000' '00123' (우편번호, 사번)
i 정수 TYPE i 0 25, -3
p 소수(자릿수 고정) TYPE p LENGTH 8 DECIMALS 2 0 25000.50 (금액)
d 날짜 YYYYMMDD TYPE d '00000000' '20261117'
t 시간 HHMMSS TYPE t '000000' '153000'
어떤 Type을 고를까요?
  • 계산할 숫자면 i(정수) 또는 p(소수, 금액)를 써요.
  • 우편번호, 사번처럼 숫자로 생겼지만 계산하지 않는 값은 n을 써요. 앞자리 0이 사라지지 않아요.
  • 이름, 메시지 같은 글자는 c 또는 string을 써요. 길이가 정해져 있으면 c, 들쭉날쭉하면 string이 편해요.
LENGTH를 빼먹으면 1칸이에요

DATA gv_name TYPE c.처럼 LENGTH를 빼먹으면 1칸짜리 상자가 돼요. 여기에 '홍길동'을 넣으면 홍 한 글자만 남아요. 오류가 나지 않아서 더 찾기 어려워요. c와 n에는 LENGTH를 꼭 적어요.

p Type의 LENGTH와 DECIMALS

TYPE p LENGTH 8 DECIMALS 2에서 DECIMALS 2는 소수점 아래 두 자리라는 뜻이에요. LENGTH 8은 숫자 칸의 크기(바이트)인데, 숫자 자릿수로는 소수 자리까지 합쳐 2 × 8 − 1 = 15자리가 들어가요. 금액이라면 LENGTH 8 DECIMALS 2면 넉넉해요.

소수가 있는 값을 넣을 때는 gv_price = '25000.50'.처럼 작은따옴표로 감싸요. 따옴표 없이 25000.50이라고 쓰면 문법 오류가 나요. ABAP에서 마침표는 문장의 끝이니까요.

3-4. 계산하기

숫자를 담은 변수로는 계산을 할 수 있어요. 연산자는 수학에서 보던 것과 거의 같아요.

연산자 뜻 예 결과
+ - * 더하기, 빼기, 곱하기 3 * 4 12
/ 나누기 7 / 2 결과 Type에 따라 다름 (아래 참고)
DIV 몫 7 DIV 2 3
MOD 나머지 7 MOD 2 1
** 거듭제곱 2 ** 3 8

프로그램으로 하나씩 확인해 봐요.

Title
[예제] 계산하기
REPORT yg##_104.

DATA: gv_a      TYPE i VALUE 7,
      gv_b      TYPE i VALUE 2,
      gv_result TYPE i,
      gv_dec    TYPE p LENGTH 8 DECIMALS 2.

START-OF-SELECTION.
  gv_result = gv_a + gv_b.           " 9
  WRITE: / '더하기:', gv_result.

  gv_result = gv_a DIV gv_b.         " 3
  WRITE: / '몫:', gv_result.

  gv_result = gv_a MOD gv_b.         " 1
  WRITE: / '나머지:', gv_result.

  gv_result = gv_a / gv_b.           " 4 (3.5가 반올림돼요!)
  WRITE: / '나누기:', gv_result.

  gv_dec = gv_a / gv_b.              " 3.50 (소수를 담는 상자라 그대로)
  WRITE: / '소수로:', gv_dec.

실행하면 이렇게 나와요. 숫자 앞의 긴 공백은 3-2에서 본 그대로예요. 칸 수는 조금 달라도 괜찮아요.

더하기:          9
몫:          3
나머지:          1
나누기:          4
소수로:             3.50
  • 계산한 결과는 = 왼쪽 상자에 담겨요. 같은 상자에 새 값을 넣으면 앞의 값은 지워져요. 그래서 계산할 때마다 바로 출력했어요.
  • 7 / 2는 3.5예요. 정수 상자 gv_result에는 반올림한 4가 들어가고, 소수까지 담는 gv_dec에는 3.50이 그대로 들어가요.
  • gv_result = gv_b - gv_a.처럼 결과가 음수면 5-처럼 부호가 숫자 뒤에 붙어서 나와요. 틀린 게 아니라 SAP가 음수를 보여 주는 방식이에요.
  • 3.50이 3,50처럼 보여도 틀린 게 아니에요. 숫자의 점과 쉼표 모양은 사용자 설정에 따라 달라요. 코드에 값을 쓸 때는 설정과 상관없이 늘 '3.50'처럼 점을 써요.

VALUE 7을 9로, VALUE 2를 4로 바꾸면 어떻게 될까요? 먼저 예상해 보고 실행해서 확인해요. 차례로 13, 2, 1, 2, 2.25가 나와요.

자주 하는 실수
  • 연산자 앞뒤는 꼭 띄어 써요. gv_a+1처럼 붙여 쓰면 ABAP은 "더하기"가 아니라 "글자 일부만 꺼내기"(앞에서 1칸 건너뛴 곳부터 읽기)로 받아들여요. 숫자 변수면 문법 오류가 나고, 글자 변수면 엉뚱한 결과가 나와요. 항상 gv_a + 1처럼 써요. 일부만 꺼내기는 3-6에서 배워요.
  • 나눈 결과를 정수 상자에 담으면 반올림돼요. 7 / 2를 i 변수에 넣으면 3.5가 반올림되어 4가 돼요. 몫이 필요하면 DIV, 소수가 필요하면 결과 변수를 p Type으로 만들어요.
  • 괄호도 안쪽을 한 칸씩 띄어 써요. ( gv_a + gv_b ) * 2처럼요. 곱하기와 나누기를 더하기와 빼기보다 먼저 계산하는 것은 수학과 같아요.
이렇게도 써요

요즘 코드에서는 "자기 자신에 더하기"를 이렇게 짧게 써요(ABAP 7.54부터 돼요). 1주차 과제에서 써 본 친구들도 있었죠.

gv_sum = gv_sum + gv_num.   " 원래 쓰던 방식
gv_sum += gv_num.           " 같은 뜻, 짧은 방식

-=, *=, /=도 같은 식이에요.

3-5. 문자열 이어 붙이기

이름과 인사말을 합쳐서 홍길동님 안녕하세요 같은 문장을 만들고 싶을 때가 많아요. JavaScript에서는 +로 이어 붙였지만, ABAP의 +는 숫자 계산에만 써요. 글자를 이어 붙이는 가장 기본적인 방법은 CONCATENATE예요.

Title
[예제] 문자열 이어 붙이기
REPORT yg##_105.

DATA: gv_name TYPE c LENGTH 10 VALUE '홍길동',
      gv_msg  TYPE string.

START-OF-SELECTION.
  CONCATENATE gv_name '님 안녕하세요' INTO gv_msg.
  WRITE / gv_msg.                                  " 홍길동님 안녕하세요

  CONCATENATE '반갑습니다' gv_name INTO gv_msg SEPARATED BY space.
  WRITE / gv_msg.                                  " 반갑습니다 홍길동
홍길동님 안녕하세요
반갑습니다 홍길동
  • CONCATENATE 값1 값2 … INTO 결과. 순서예요.
  • SEPARATED BY space를 붙이면 사이에 공백 한 칸을 넣어 줘요.
  • gv_name은 10칸짜리라 뒤에 공백 7칸이 남아 있지만, CONCATENATE는 c Type 뒤쪽 공백을 알아서 빼고 붙여 줘요.
  • CONCATENATE에는 글자만 넣을 수 있어요. 숫자 변수(i, p)를 바로 넣으면 문법 오류가 나요. 숫자는 글자 변수에 먼저 옮긴 다음 이어 붙여요. 방법은 3-6에서 CONDENSE와 함께 볼게요.
이렇게도 써요

&& 연산자나 문자열 템플릿 |…|으로 더 짧게 쓸 수도 있어요. 템플릿 안에서 변수는 { }로 감싸고, 괄호 안쪽은 꼭 한 칸씩 띄워요.

gv_msg = gv_name && '님 안녕하세요'.
gv_msg = |{ gv_name }님 안녕하세요|.

3-6. 문자열 다루기

글자로 하는 일이 이어 붙이기만 있는 건 아니에요. 일부만 꺼내고, 길이를 세고, 다듬는 일도 자주 해요. 가장 많이 쓰는 네 가지만 먼저 익혀요.

하고 싶은 일 쓰는 법 예
일부만 꺼내기 변수+시작(길이) 20261103에서 gv_date+4(2) → 11
길이 세기 strlen( 변수 ) abap → 4
대문자로 바꾸기 TRANSLATE 변수 TO UPPER CASE. abap → ABAP
공백 정리하기 CONDENSE 변수. 앞뒤 공백은 없애고, 사이 공백은 한 칸으로

이 가운데 일부만 꺼내기가 가장 헷갈려요. + 뒤의 숫자는 앞에서 건너뛸 칸 수(시작), 괄호 안의 숫자는 꺼낼 칸 수(길이)예요. 변수 이름, +, 괄호를 띄우지 않고 붙여 써요. gv_date(4)처럼 +를 빼면 맨 앞부터 꺼내요.

gv_date        2 0 2 6 1 1 0 3
gv_date(4)     2 0 2 6            앞에서 4칸
gv_date+4(2)           1 1        4칸 건너뛰고 2칸
gv_date+6(2)               0 3    6칸 건너뛰고 2칸

3-4에서 gv_a+1처럼 붙여 쓰지 말라고 했죠? 붙여 쓴 +는 더하기가 아니라 바로 이 "건너뛸 칸 수"로 읽히기 때문이에요. 그리고 8칸짜리 gv_date에 gv_date+6(4)처럼 길이를 넘겨서 꺼내려고 하면 문법 오류가 나요.

네 가지를 프로그램 하나로 해 볼게요. 조금 길지만 한 번에 다 치지 않아도 돼요. 코드의 주석에 1번부터 4번까지 번호를 달아 뒀어요. 먼저 1번의 WRITE까지만 치고 실행해 봐요. 세 줄이 나오면 2번, 3번, 4번을 하나씩 덧붙이면서 실행해요.

Title
[예제] 문자열 다루기
REPORT yg##_106.

DATA: gv_date  TYPE d VALUE '20261103',
      gv_year  TYPE c LENGTH 4,
      gv_month TYPE c LENGTH 2,
      gv_id    TYPE c LENGTH 5 VALUE 'B0001',
      gv_no    TYPE c LENGTH 4,
      gv_word  TYPE c LENGTH 10 VALUE 'abap',
      gv_len   TYPE i,
      gv_text  TYPE c LENGTH 10.

START-OF-SELECTION.
  " 1. 일부만 꺼내기
  gv_year  = gv_date(4).             " 앞에서 4칸       → 2026
  gv_month = gv_date+4(2).           " 4칸 건너뛰고 2칸 → 11
  gv_no    = gv_id+1(4).             " 1칸 건너뛰고 4칸 → 0001
  WRITE: / '연도:', gv_year,
         / '월:', gv_month,
         / '번호:', gv_no.

  " 2. 길이 세기
  gv_len = strlen( gv_word ).        " 4 (뒤쪽 공백은 세지 않아요)
  WRITE: / '길이:', gv_len.

  " 3. 대문자로 바꾸기
  TRANSLATE gv_word TO UPPER CASE.   " abap → ABAP
  WRITE: / '대문자:', gv_word.

  " 4. 공백 정리하기
  gv_text = gv_len.                  " 숫자를 글자 변수로 옮겨요
  WRITE: / '정리 전:', gv_text.
  CONDENSE gv_text.
  WRITE: / '정리 후:', gv_text.
연도: 2026
월: 11
번호: 0001
길이:          4
대문자: ABAP
정리 전:         4
정리 후: 4
  • 1번. 날짜에서 연도와 월을 꺼내는 gv_date(4), gv_date+4(2)는 회사 코드에서 정말 자주 만나요. 도서 번호 B0001에서 숫자 부분 0001만 꺼낸 것도 같은 방법이에요.
  • 2번. strlen( gv_word )는 괄호 안쪽을 한 칸씩 띄어 써요. c Type은 뒤쪽 공백을 세지 않아서, 10칸짜리 gv_word도 4가 나와요.
  • 3번. TRANSLATE는 변수에 든 값을 그 자리에서 바꿔요. CONDENSE도 그래요. 바꾸기 전 값은 남지 않아요.
  • 4번. 숫자를 글자 변수에 옮기면(gv_text = gv_len.) 오른쪽에 붙어서 앞에 공백이 생겨요. CONDENSE가 이 공백을 없애 줘요. 이제 gv_text는 글자라서, 3-5에서처럼 CONCATENATE '길이:' gv_text INTO gv_msg.로 이어 붙일 수 있어요. 결과는 길이:4예요.
더 알아 두면 좋아요

지금은 이런 것이 있다는 것만 알아 둬요.

  • 글자 나누기: SPLIT gv_line AT ',' INTO gv_first gv_second. 쉼표를 기준으로 나눠서 두 변수에 담아요.
  • 글자 바꾸기: REPLACE ALL OCCURRENCES OF '-' IN gv_tel WITH '.'. gv_tel 안의 -를 모두 .으로 바꿔요.
이렇게도 써요

요즘 코드는 같은 일을 함수 모양으로 써요. 3-5의 문자열 템플릿에는 숫자도 바로 넣을 수 있어서, 글자 변수에 옮기고 CONDENSE 하는 수고가 없어요. gv_msg는 3-5에서 만든 TYPE string 변수예요.

gv_word = to_upper( gv_word ).       " TRANSLATE … TO UPPER CASE와 같아요
gv_text = condense( gv_text ).       " CONDENSE와 같아요
gv_msg  = |길이: { gv_len }|.        " 길이: 4

3-7. 날짜와 시스템 필드

시스템 필드 sy-

SAP는 프로그램이 실행될 때 자주 쓰는 정보를 sy-로 시작하는 시스템 필드에 미리 넣어 둬요. 따로 만들지 않아도 바로 쓸 수 있어요.

시스템 필드 담긴 값 예
sy-datum 오늘 날짜 20261117
sy-uzeit 지금 시각 153000
sy-uname 로그인한 사용자 ID CODE05
sy-index 반복문의 몇 번째 바퀴인지 4장에서
sy-subrc 방금 한 일이 성공했는지(0이면 성공) 8~9장에서

자주 쓰는 시스템 필드는 부록 B에 모아 뒀어요.

날짜 계산

d Type은 날짜끼리 빼면 날수, 날짜에 숫자를 더하면 그만큼 지난 날짜가 나와요. 달마다 날수가 다른 것도 SAP가 알아서 계산해 줘요.

오늘 날짜로 직접 계산해 봐요.

새로 만들기ProgramSE38
Program
YG##_107
Title
[예제] 날짜 계산
REPORT yg##_107.

DATA: gv_due  TYPE sy-datum,
      gv_end  TYPE sy-datum VALUE '20261231',
      gv_days TYPE i.

START-OF-SELECTION.
  gv_due  = sy-datum + 30.       " 오늘부터 30일 뒤
  gv_days = gv_end - sy-datum.   " 올해가 며칠 남았는지

  WRITE: / '오늘:',       sy-datum,
         / '반납 기한:',  gv_due,
         / '올해 남은 날:', gv_days.

2026년 11월 17일에 실행하면 이렇게 나와요. 실행한 날에 따라 값이 달라져요. 2027년 이후에 실행한다면 '20261231'을 그해의 마지막 날로 바꿔요. 안 바꾸면 남은 날이 음수로 나와요.

오늘: 2026.11.17
반납 기한: 2026.12.17
올해 남은 날:         44
  • gv_due와 gv_end는 TYPE d가 아니라 TYPE sy-datum으로 선언했어요. "sy-datum과 똑같은 Type으로 만들어 줘요"라는 뜻이에요. 담기는 값은 d와 똑같이 YYYYMMDD 8칸이에요. 왜 이렇게 했는지는 아래의 "화면에 출력할 날짜 변수는 TYPE sy-datum으로" 상자에서 알려 줄게요.
  • 날짜 값을 직접 쓸 때는 '20261231'처럼 작은따옴표 안에 숫자 8개를 붙여 써요. '2026.12.31'처럼 점을 넣으면 안 돼요.
  • 3-6에서 배운 대로 sy-datum(4)라고 쓰면 올해 연도 2026만 꺼낼 수 있어요.
날짜가 2026.11.17처럼 보여요

변수 안에는 20261117로 들어 있지만, WRITE는 사용자 설정에 맞춰 보기 좋게 바꿔서 출력해요. 그래서 사람마다 2026.11.17, 11/17/2026처럼 다르게 보일 수 있어요.

화면에 출력할 날짜 변수는 TYPE sy-datum으로

TYPE d로 만든 변수는 출력할 때 8칸만 써요. 구분 기호가 들어갈 자리가 없어서 20261217처럼 숫자만 붙어서 나와요(날짜 표시 설정에 따라 숫자 순서는 다를 수 있어요). sy-datum은 10칸을 쓰기 때문에 2026.12.17처럼 나와요. 그래서 이 교재는 화면에 출력할 날짜 변수를 TYPE sy-datum으로 만들어요. 날짜를 계산하는 방법은 둘 다 똑같아요.

3-8. 바뀌지 않는 값: CONSTANTS

배송비, 세율처럼 프로그램 안에서 절대 바뀌면 안 되는 값은 CONSTANTS로 만들어요. 이름은 gc_(Global Constant)로 시작해요.

CONSTANTS: gc_delivery TYPE p LENGTH 8 DECIMALS 2 VALUE '3000.00',
           gc_max_qty  TYPE i VALUE 10.
  • CONSTANTS는 VALUE가 꼭 있어야 해요.
  • 나중에 gc_delivery = 5000.처럼 바꾸려고 하면 문법 오류가 나요. 실수로 값을 바꾸는 걸 막아 주는 거예요.
  • 소수가 있는 값은 3-3에서 본 대로 '3000.00'처럼 작은따옴표로 감싸서 써요.
  • CONSTANTS도 DATA처럼 REPORT 줄 아래, START-OF-SELECTION 위에 써요.
나만의 Type 이름: TYPES

같은 모양의 변수를 여러 번 만들 때는 TYPES로 Type에 이름을 붙여 두면 편해요. 이름은 ty_로 시작해요(0-3). TYPES는 상자가 아니라 상자의 설계도라서 값을 담을 수 없어요.

TYPES ty_amount TYPE p LENGTH 8 DECIMALS 2.     " 설계도

DATA: gv_price TYPE ty_amount,                   " 설계도로 만든 상자
      gv_total TYPE ty_amount.

TYPES는 8장에서 여러 칸짜리 Structure를 만들 때 본격적으로 써요.

이렇게도 써요

값을 넣는 그 자리에서 변수를 바로 만드는 인라인 선언도 있어요. Type은 오른쪽 값을 보고 SAP가 정해요.

DATA(lv_count) = 10.            " TYPE i 변수가 만들어져요
DATA(lv_text)  = `Hello`.       " TYPE string 변수가 만들어져요

그 자리에서 만든 변수는 이름을 gv_가 아니라 lv_로 시작해요(부록 F). 작은따옴표 대신 백틱(`)으로 감싼 글자는 string이에요. 인라인 선언은 편하지만 Type이 눈에 보이지 않아서, 처음에는 DATA … TYPE …로 직접 선언하는 연습을 충분히 하는 게 좋아요.

3-9. 미니 실습: 장바구니 계산

이 장에서 배운 변수, 계산, CONSTANTS, 날짜 계산을 한 프로그램에 모아 볼게요.

새로 만들기ProgramSE38
Program
YG##_108
Title
[실습] 장바구니 계산
Text Symbol
001 = 장바구니 계산
직접 해 보기

위 카드대로 프로그램을 만들어서 아래 그림처럼 출력해 보세요. 값은 그림에 보이는 대로 넣어요.

  • 상품 이름(c LENGTH 20), 단가(p LENGTH 8 DECIMALS 2), 수량(i) 변수를 만들어요.
  • 배송비 3000은 CONSTANTS로 만들어요. Type은 단가와 같게 해요.
  • 합계 = 단가 × 수량 + 배송비 로 계산해요. 합계를 담을 변수도 단가와 같은 Type으로 만들어요.
  • 도착 예정일은 오늘(sy-datum)부터 3일 뒤예요. 날짜 변수는 TYPE sy-datum으로 만들어요(3-7).
  • 첫 줄의 장바구니 계산은 Text Symbol 001로 출력해요(2-7). Text Symbol도 활성화해야 글자가 나와요.
예시 답안 보기
*&---------------------------------------------------------------------*
* 작성자: 홍길동   작성일: 2026-11-17
* 설명  : 변수, 계산, CONSTANTS, 날짜 계산 연습
*&---------------------------------------------------------------------*
REPORT yg##_108.

" 바뀌지 않는 값
CONSTANTS gc_delivery TYPE p LENGTH 8 DECIMALS 2 VALUE '3000.00'.

" 변수
DATA: gv_item  TYPE c LENGTH 20,
      gv_price TYPE p LENGTH 8 DECIMALS 2,
      gv_qty   TYPE i,
      gv_total TYPE p LENGTH 8 DECIMALS 2,
      gv_date  TYPE sy-datum.

START-OF-SELECTION.
  " 1. 값 넣기
  gv_item  = 'ABAP 입문서'.
  gv_price = '25000.00'.
  gv_qty   = 2.

  " 2. 계산하기
  gv_total = gv_price * gv_qty + gc_delivery.
  gv_date  = sy-datum + 3.

  " 3. 출력하기
  WRITE: / TEXT-001,                 " 장바구니 계산
         / '상품:', gv_item,
         / '단가:', gv_price,
         / '수량:', gv_qty,
         / '배송비:', gc_delivery,
         / '합계:', gv_total,
         / '도착 예정일:', gv_date.
확인 문제
  1. 우편번호 01234를 담으려고 해요. i와 n 중 어떤 Type이 좋을까요? 이유도 말해 보세요.
  2. 아래 코드를 실행하면 gv_r에는 각각 무엇이 들어갈까요? (gv_r은 TYPE i) 
    gv_r = 10 DIV 3.
gv_r = 10 MOD 3.
gv_r = 10 / 4.
  3. 아래 코드에서 잘못된 곳은 어디일까요? 
    CONSTANTS gc_rate TYPE p LENGTH 3 DECIMALS 2.
gv_total = gv_price*gv_qty.
  4. 오늘이 2026년 11월 17일이에요. sy-datum + 14는 어떤 날짜일까요?
  5. gv_id(TYPE c LENGTH 5)에 'B0004'가 들어 있어요. gv_id(1)과 gv_id+1(4)는 각각 무엇일까요?
  6. gv_d1은 TYPE d, gv_d2는 TYPE sy-datum이에요. 둘 다 '20261224'를 넣고 WRITE로 출력하면 화면에 어떻게 다르게 보일까요?
정답 보기
  1. n이 좋아요. i에 넣으면 숫자 1234가 되어 앞자리 0이 사라져요. 우편번호는 계산할 일이 없는 "숫자로 된 글자"라서 n이 맞아요.
  2. 3, 1, 3이에요. 10 / 4는 2.5인데 i에 넣으면서 반올림되어 3이 돼요.
  3. ① CONSTANTS에 VALUE가 없어요. VALUE '0.10'처럼 값을 꼭 넣어야 해요. ② gv_price*gv_qty는 연산자 앞뒤에 공백이 없어요. gv_price * gv_qty로 띄어 써요.
  4. 2026년 12월 1일(20261201)이에요. 11월은 30일까지라서 SAP가 달을 넘겨 계산해 줘요.
  5. B와 0004예요. gv_id(1)은 맨 앞에서 1칸, gv_id+1(4)는 1칸 건너뛰고 4칸이에요.
  6. gv_d1은 20261224처럼 숫자만 붙어서 나오고, gv_d2는 2026.12.24처럼 구분 기호가 들어가요(모양은 사용자 설정에 따라 달라요). TYPE d는 8칸, sy-datum은 10칸으로 출력하기 때문이에요.
정리
  • 변수는 DATA 이름 TYPE 타입.으로 만들고, =로 값을 넣어요.
  • 계산은 i·p, 계산하지 않는 숫자 글자는 n, 글자는 c·string, 날짜·시간은 d·t예요. c와 n에는 LENGTH를 꼭 적어요.
  • 연산자 앞뒤는 꼭 띄어 쓰고, 나눈 결과를 i에 담으면 반올림된다는 걸 기억해요.
  • 글자는 CONCATENATE … INTO …로 이어 붙이고, 변수+시작(길이)로 일부만 꺼내요. strlen, TRANSLATE, CONDENSE로 세고 다듬어요.
  • sy-datum 같은 시스템 필드는 만들지 않아도 바로 쓸 수 있어요. 날짜는 더하고 뺄 수 있어요. 화면에 출력할 날짜 변수는 TYPE sy-datum으로 만들어요.
  • 바뀌면 안 되는 값은 CONSTANTS로, Type 설계도는 TYPES로 만들어요.
