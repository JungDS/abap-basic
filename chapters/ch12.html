12장

종합 실습: 도서 조회 프로그램

이번 장 목표
  • 0장에서 본 다섯 칸 흐름(입력 → 읽기 → 담기 → 계산 → 보여 주기)을 프로그램 하나로 이어요.
  • 요구 사항을 읽고 순서를 나눠서 프로그램을 만드는 연습을 해요.
  • 지금까지 배운 Selection Screen, Open SQL, Internal Table, CASE, FORM, ALV를 한꺼번에 써요.

12-1. 무엇을 만들까요?

도서관 직원이 쓰는 도서 조회 프로그램 YG##_12_BOOK_REPORT를 만들어요. 7장에서 만든 YG##_BOOK Table을 그대로 써요.

번호 요구 사항 쓰는 것 (배운 장)
① 도서 번호, 장르, 가격을 범위로 넣어 조회해요. 비우면 전체예요. SELECT-OPTIONS (9장)
② "재고 있는 책만" 체크박스를 켜면 재고 0인 책은 빼요. AS CHECKBOX (5장), DELETE … WHERE (8장)
③ 정렬 방법을 "가격 높은 순"과 "제목순" 중에서 골라요. RADIOBUTTON (5장), SORT (8장)
④ 장르 코드(N, I, E) 옆에 장르 이름을 보여 줘요. CASE (4장)
⑤ 재고에 따라 상태를 보여 줘요. 0은 품절, 3 미만은 부족, 나머지는 충분이에요. IF … ELSEIF (4장)
⑥ 조건에 맞는 책이 없으면 메시지를 띄워요. MESSAGE (5장)
⑦ 결과는 ALV로 보여 주고, 정렬·필터·엑셀 버튼을 켜요. CL_SALV_TABLE (11장)
⑧ 일은 FORM으로 나눠요. FORM·PERFORM (10장)

완성하면 이런 모습이에요.

그림의 결과 표는 칸을 몇 개 줄여서 그렸어요. 실제로는 저자와 장르 코드 칸도 함께 나와요.

12-2. 먼저 설계하기

코드를 바로 쓰기 전에 어떤 순서로, 어떤 덩어리로 만들지 정해요. 큰 프로그램일수록 이 단계가 시간을 아껴 줘요.

프로그램 코드는 위에서부터 이런 구역으로 나눠 써요. 회사 프로그램도 대부분 이 순서예요.

START-OF-SELECTION에는 PERFORM만 차례로 적어요. 그러면 이 부분만 읽어도 프로그램이 무슨 일을 어떤 순서로 하는지 한눈에 보여요.

12-3. 1단계: 뼈대와 Selection Screen

SE38에서 YG##_12_BOOK_REPORT를 Local Object로 만들고 아래까지 써요.

REPORT yg##_12_book_report.

*----------------------------------------------------------------------*
* ① 타입과 변수
*----------------------------------------------------------------------*
TYPES: BEGIN OF ty_list,
         book_id TYPE yg##_book-book_id,
         title   TYPE yg##_book-title,
         author  TYPE yg##_book-author,
         genre   TYPE yg##_book-genre,
         genre_t TYPE c LENGTH 10,          " 장르 이름 (DB에 없는 칸)
         price   TYPE yg##_book-price,
         stock   TYPE yg##_book-stock,
         status  TYPE c LENGTH 10,          " 상태 (DB에 없는 칸)
       END OF ty_list,
       ty_t_list TYPE STANDARD TABLE OF ty_list WITH DEFAULT KEY.

DATA: gt_list TYPE ty_t_list,
      gs_book TYPE yg##_book.              " SELECT-OPTIONS의 FOR에만 써요

*----------------------------------------------------------------------*
* ② Selection Screen
*----------------------------------------------------------------------*
SELECTION-SCREEN BEGIN OF BLOCK b1 WITH FRAME TITLE TEXT-b01.
  SELECT-OPTIONS: so_id    FOR gs_book-book_id,
                  so_genre FOR gs_book-genre,
                  so_price FOR gs_book-price.
  PARAMETERS pa_stock AS CHECKBOX.
SELECTION-SCREEN END OF BLOCK b1.

SELECTION-SCREEN BEGIN OF BLOCK b2 WITH FRAME TITLE TEXT-b02.
  PARAMETERS: pa_price RADIOBUTTON GROUP srt DEFAULT 'X',
              pa_title RADIOBUTTON GROUP srt.
SELECTION-SCREEN END OF BLOCK b2.

이번 장에서 처음 나오는 것이 두 가지 있어요.

새로 나오는 것 ① Selection Screen 묶음 상자

SELECTION-SCREEN BEGIN OF BLOCK 이름 WITH FRAME TITLE TEXT-… 와 … END OF BLOCK 이름으로 감싸면 입력 칸들이 제목 있는 상자로 묶여요(그림 12-1). 상자 제목은 Text Symbol에 적어요. 여기서는 b01에 "조회 조건", b02에 "정렬"을 넣어요.

새로 나오는 것 ② Internal Table의 Type 이름 붙이기

ty_t_list TYPE STANDARD TABLE OF ty_list WITH DEFAULT KEY는 "ty_list 모양의 줄을 여러 개 담는 표"라는 표의 Type에 이름을 붙인 거예요. FORM의 파라미터는 Type을 적어야 해서, 표를 넘기려면 이렇게 표의 Type 이름이 필요해요. 이름 앞의 ty_t_는 "표 Type"이라는 표시예요.

직접 해 보기
  1. 위 코드를 쓰고 저장·검사·활성화해요.
  2. Goto → Text Elements에서 Text Symbol을 넣어요.
Sym Text
b01 조회 조건
b02 정렬
e01 조건에 맞는 책이 없어요.
t01 도서 조회
  1. Selection Texts 탭에서 이름표를 넣어요. so_id, so_genre, so_price는 Dictionary Ref.에 체크하면 Data Element 이름표가 자동으로 들어가요. pa_stock은 "재고 있는 책만", pa_price는 "가격 높은 순", pa_title은 "제목순"이에요.
  2. Text Elements도 활성화한 뒤 F8로 실행해서 그림 12-1의 왼쪽과 같은지 확인해요. 아직 START-OF-SELECTION이 없으니 실행해도 아무 일도 일어나지 않아요.

12-4. 2단계: 읽어 담기 (get_data)

이제 이벤트와 첫 번째 FORM을 써요. START-OF-SELECTION은 Selection Screen 코드 아래에, FORM은 프로그램 맨 아래에 둬요.

*----------------------------------------------------------------------*
* ③ 이벤트
*----------------------------------------------------------------------*
START-OF-SELECTION.
  PERFORM get_data CHANGING gt_list.

  IF gt_list IS INITIAL.                   " 한 줄도 없으면
    MESSAGE TEXT-e01 TYPE 'S' DISPLAY LIKE 'E'.
    RETURN.
  ENDIF.

*----------------------------------------------------------------------*
* ④ FORM들
*----------------------------------------------------------------------*
*&---------------------------------------------------------------------*
*& Form get_data : 조건에 맞는 책 읽기
*&---------------------------------------------------------------------*
FORM get_data CHANGING ct_list TYPE ty_t_list.

  SELECT book_id title author genre price stock
    FROM yg##_book
    INTO CORRESPONDING FIELDS OF TABLE ct_list
    WHERE book_id IN so_id
      AND genre   IN so_genre
      AND price   IN so_price.

  IF pa_stock = abap_true.                 " "재고 있는 책만"에 체크했으면
    DELETE ct_list WHERE stock = 0.
  ENDIF.

ENDFORM.
  • ty_list에는 DB에 없는 칸(genre_t, status)이 있어서, 이름이 같은 칸만 골라 담는 INTO CORRESPONDING FIELDS OF TABLE을 써요(9장).
  • Selection Screen의 so_id, pa_stock 같은 값은 프로그램 어디서나 읽을 수 있어서 FORM 안에서 바로 써요.
  • gt_list IS INITIAL은 "표가 비어 있으면"이라는 뜻이에요. DELETE로 다 지워진 경우까지 함께 잡을 수 있어서 sy-subrc보다 여기서는 이쪽이 정확해요.
확인해 보기

PERFORM get_data 줄에 Breakpoint를 걸고 실행해요(6장). F6으로 한 줄 넘긴 뒤, 변수 칸에 gt_list를 넣고 더블클릭하면 표 모양으로 내용을 볼 수 있어요. 조건을 바꿔 가며 줄 수가 맞는지 확인해 보세요.

12-5. 3단계: 글자 채우고 정렬하기 (fill_text, sort_list)

읽어 온 줄을 하나씩 돌면서 장르 이름과 상태를 채워요. 8장의 "Work Area로 꺼내서 고치고 MODIFY로 되돌려 놓기" 그대로예요.

*&---------------------------------------------------------------------*
*& Form fill_text : 장르 이름과 재고 상태 채우기
*&---------------------------------------------------------------------*
FORM fill_text CHANGING ct_list TYPE ty_t_list.
  DATA ls_list TYPE ty_list.              " 이 FORM 안에서만 쓰는 Work Area

  LOOP AT ct_list INTO ls_list.
    " 장르 이름
    CASE ls_list-genre.
      WHEN 'N'.
        ls_list-genre_t = '소설'.
      WHEN 'I'.
        ls_list-genre_t = 'IT'.
      WHEN 'E'.
        ls_list-genre_t = '에세이'.
      WHEN OTHERS.
        ls_list-genre_t = '기타'.
    ENDCASE.

    " 재고 상태
    IF ls_list-stock = 0.
      ls_list-status = '품절'.
    ELSEIF ls_list-stock < 3.
      ls_list-status = '부족'.
    ELSE.
      ls_list-status = '충분'.
    ENDIF.

    MODIFY ct_list FROM ls_list INDEX sy-tabix.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*& Form sort_list : 고른 방법으로 정렬
*&---------------------------------------------------------------------*
FORM sort_list CHANGING ct_list TYPE ty_t_list.
  IF pa_price = abap_true.
    SORT ct_list BY price DESCENDING.
  ELSE.
    SORT ct_list BY title.
  ENDIF.
ENDFORM.

START-OF-SELECTION의 ENDIF. 아래에 두 줄을 더해요.

  PERFORM fill_text CHANGING gt_list.
  PERFORM sort_list CHANGING gt_list.
지역 변수: `ls_list`

FORM 안에서 DATA로 만든 변수는 그 FORM 안에서만 쓸 수 있어요. 이런 변수를 지역 변수라고 하고, 이름 앞에 L을 붙여 전역 변수(G)와 구분해요. FORM이 끝나면 사라지니, 다른 곳의 변수와 이름이 겹칠 걱정이 없어요.

장르 이름은 Domain에도 있어요

7장에서 Domain YG##_D_GENRE의 고정값에 "소설, IT, 에세이"를 이미 적었어요. 그 값을 프로그램에서 읽어 오는 방법도 있지만, 여기서는 CASE 연습을 위해 직접 적었어요. 장르가 새로 생기면 Domain과 이 CASE를 둘 다 고쳐야 한다는 점은 기억해 두세요.

12-6. 4단계: ALV로 보여 주기 (display_alv)

11장에서 배운 순서(만들기 → 설정 → 띄우기)를 FORM 하나에 담아요. genre_t와 status는 Data Element가 없어서 제목이 비니, 제목을 직접 붙여요.

*&---------------------------------------------------------------------*
*& Form display_alv : ALV로 결과 보여 주기
*&---------------------------------------------------------------------*
FORM display_alv CHANGING ct_list TYPE ty_t_list.
  DATA: lo_alv     TYPE REF TO cl_salv_table,
        lo_columns TYPE REF TO cl_salv_columns_table,
        lo_column  TYPE REF TO cl_salv_column.

  " 1. 만들기
  TRY.
      cl_salv_table=>factory(
        IMPORTING
          r_salv_table = lo_alv
        CHANGING
          t_table      = ct_list ).
    CATCH cx_salv_msg.
      MESSAGE 'ALV를 만들지 못했어요.' TYPE 'S' DISPLAY LIKE 'E'.
      RETURN.
  ENDTRY.

  " 2. 설정: 폭 맞추기, 제목 없는 칸에 제목 붙이기
  lo_columns = lo_alv->get_columns( ).
  lo_columns->set_optimize( abap_true ).

  TRY.
      lo_column = lo_columns->get_column( 'GENRE_T' ).
      lo_column->set_short_text( '장르 이름' ).
      lo_column->set_medium_text( '장르 이름' ).
      lo_column->set_long_text( '장르 이름' ).

      lo_column = lo_columns->get_column( 'STATUS' ).
      lo_column->set_short_text( '상태' ).
      lo_column->set_medium_text( '상태' ).
      lo_column->set_long_text( '상태' ).
    CATCH cx_salv_not_found.
  ENDTRY.

  " 3. 설정: 툴바 버튼, 화면 제목, 줄무늬
  lo_alv->get_functions( )->set_all( abap_true ).
  lo_alv->get_display_settings( )->set_list_header( TEXT-t01 ).
  lo_alv->get_display_settings( )->set_striped_pattern( abap_true ).

  " 4. 띄우기
  lo_alv->display( ).
ENDFORM.

START-OF-SELECTION 마지막에 한 줄을 더하면 완성이에요.

  PERFORM display_alv CHANGING gt_list.

FORM 안에서 만든 ALV 변수는 지역 변수라서 go_가 아니라 lo_로 시작해요.

다 만들었으면 아래 표대로 실행해 보고, 결과가 같은지 확인해요. 7장에서 넣은 책 다섯 권 기준이에요.

번호 입력 기대 결과
1 아무것도 안 넣고 실행 (가격 높은 순) 5권. B0004 → B0001 → B0005 → B0002 → B0003
2 정렬만 "제목순" 5권. ABAP 첫걸음 → SQL 한 그릇 → 바다의 노래 → 별을 세는 밤 → 오늘의 산책
3 "재고 있는 책만" 체크 4권. B0002(품절)가 빠져요
4 장르 I 2권. B0004, B0001 (상태: 부족, 충분)
5 가격 15000 ~ 20000 2권. B0005, B0002
6 도서 번호 B0009 메시지 "조건에 맞는 책이 없어요."
7 장르 N + "재고 있는 책만" 1권. B0005
막혔을 때 점검하기
  • 결과가 하나도 안 나와요 → 디버거로 get_data 다음에서 gt_list를 봐요. 비어 있으면 WHERE 조건이나 Table 데이터를 확인해요(SE16N).
  • 장르 이름·상태 칸이 비어 있어요 → fill_text에서 MODIFY 줄을 빠뜨리지 않았는지 봐요.
  • 상자 제목이나 메시지가 안 나와요 → Text Elements를 활성화했는지 확인해요.
  • 정렬이 안 바뀌어요 → sort_list를 PERFORM했는지, display_alv보다 먼저 불렀는지 확인해요.
  • "제목순"에서 영어 제목이 한글 제목보다 먼저 나오는 것은 정상이에요. 글자 코드 순서로 정렬해서 그래요.

  2. 품절 책 세기: ALV를 띄우기 전에 품절 책이 몇 권인지 세어서, 1권 이상이면 MESSAGE '품절 도서가 있어요.' TYPE 'S'로 알려 줘요. (LOOP … WHERE와 변수 하나면 돼요.)
  3. 잘못된 입력 막기: AT SELECTION-SCREEN에서 가격 범위의 시작값 so_price-low가 0보다 작으면 오류 메시지를 띄워요. SELECT-OPTIONS는 Header Line이 있어서 so_price-low로 첫 줄의 값을 바로 읽을 수 있어요(8장 노트).
  4. Function Module로 바꾸기: fill_text의 장르 이름 부분을 10장처럼 Function Module Y_G##_GENRE_TEXT(Import IV_GENRE, Export EV_TEXT)로 만들고 CALL FUNCTION으로 바꿔 불러요.
  5. 합계 줄: ALV에서 가격 칸을 고르고 합계 버튼을 눌러 보세요. 코드로 처음부터 합계를 보이게 하는 방법(get_aggregations( ))도 SE24에서 CL_SALV_TABLE의 Method 목록을 보며 찾아보세요.
정리
  • 프로그램은 요구 사항 → 설계(흐름과 덩어리) → 단계별로 만들고 확인 순서로 만들어요.
  • 코드는 타입·변수 → Selection Screen → 이벤트 → FORM 순서로 구역을 나눠요.
  • START-OF-SELECTION에는 PERFORM만 적어서 흐름이 한눈에 보이게 해요.
  • 표를 FORM에 넘길 때는 TYPES … TYPE STANDARD TABLE OF …로 표의 Type 이름을 만들어요.
  • 단계마다 실행하고 디버거로 확인하면 큰 프로그램도 무섭지 않아요.
