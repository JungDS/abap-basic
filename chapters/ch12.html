12장

종합 실습: 도서 조회 프로그램

이번 장 목표
  • 0장에서 본 다섯 칸 흐름(입력 → 읽기 → 담기 → 계산 → 보여 주기)을 프로그램 하나로 이어요.
  • 요구 사항을 읽고 순서를 나눠서 프로그램을 만드는 연습을 해요.
  • 지금까지 배운 Selection Screen, Open SQL, Internal Table, CASE, FORM, ALV를 한꺼번에 써요.
  • 남이 만든 프로그램을 따라가며 읽는 법(SE80, 더블클릭, Where-Used List)을 익히고, 옛 스타일 프로그램을 읽고 고쳐 봐요.

12-1. 무엇을 만들까요?

도서관 직원이 쓰는 도서 조회 프로그램을 만들어요. 7장에서 만든 Table YTA_G##_BOOK을 그대로 써요.

번호 요구 사항 쓰는 것 (배운 장)
① 도서 번호, 장르, 가격을 범위로 넣어 조회해요. 비우면 전체예요. SELECT-OPTIONS (9장)
② "재고 있는 책만" 체크박스를 켜면 재고 0인 책은 빼요. AS CHECKBOX (5장), DELETE … WHERE (8장)
③ 정렬 방법을 "가격 높은 순"과 "제목순" 중에서 골라요. RADIOBUTTON (5장), SORT (8장)
④ 장르 코드(N, I, E) 옆에 장르 이름을 보여 줘요. CASE (4장)
⑤ 재고에 따라 상태를 보여 줘요. 0은 품절, 3 미만은 부족, 나머지는 충분이에요. IF … ELSEIF (4장)
⑥ 조건에 맞는 책이 없으면 메시지를 띄워요. MESSAGE (5장)
⑦ 결과는 ALV로 보여 주고, 정렬·필터·엑셀 버튼을 켜요. CL_SALV_TABLE (11장)
⑧ 일은 FORM으로 나눠요. FORM·PERFORM (10장)

완성하면 이런 모습이에요.

그림의 결과 표는 칸을 몇 개 줄여서 그렸어요. 실제로는 저자와 장르 코드 칸도 함께 나와요. 위쪽 Selection Screen의 제목은 프로그램의 Title이에요. 아래쪽 결과 화면의 제목 도서 조회는 코드에서 따로 정해요(12-6).

12-2. 먼저 설계하기

코드를 바로 쓰기 전에 어떤 순서로, 어떤 덩어리로 만들지 정해요. 큰 프로그램일수록 이 단계가 시간을 아껴 줘요.

프로그램 코드는 위에서부터 이런 구역으로 나눠 써요. 회사 프로그램도 대부분 이 순서예요.

START-OF-SELECTION에는 실제 일을 하는 코드 대신 PERFORM을 차례로 적어요. 그 사이에는 "한 줄도 없으면 멈추기" 같은 확인만 둬요. 그러면 이 부분만 읽어도 프로그램이 무슨 일을 어떤 순서로 하는지 한눈에 보여요.

12-3. 1단계: 뼈대와 Selection Screen

먼저 프로그램을 만들어요(만드는 순서는 2-2). 이 프로그램은 스스로 완성하는 실습이라서 코드 상자에 복사 버튼이 없어요. 한 단계씩 직접 쳐 보세요.

새로 만들기ProgramSE38
Program
YG##_146
Title
[실습] 도서 조회 프로그램
REPORT yg##_146.

*----------------------------------------------------------------------*
* ① Type과 변수
*----------------------------------------------------------------------*
TYPES: BEGIN OF ty_list,
         book_id TYPE yta_g##_book-book_id,
         title   TYPE yta_g##_book-title,
         author  TYPE yta_g##_book-author,
         genre   TYPE yta_g##_book-genre,
         genre_t TYPE c LENGTH 10,          " 장르 이름 (DB에 없는 칸)
         price   TYPE yta_g##_book-price,
         stock   TYPE yta_g##_book-stock,
         status  TYPE c LENGTH 10,          " 상태 (DB에 없는 칸)
       END OF ty_list,
       ty_t_list TYPE STANDARD TABLE OF ty_list WITH DEFAULT KEY.

DATA: gt_list TYPE ty_t_list,
      gs_book TYPE yta_g##_book.           " SELECT-OPTIONS의 FOR에만 써요

*----------------------------------------------------------------------*
* ② Selection Screen
*----------------------------------------------------------------------*
SELECTION-SCREEN BEGIN OF BLOCK b1 WITH FRAME TITLE TEXT-b01.
  SELECT-OPTIONS: so_id    FOR gs_book-book_id,
                  so_genre FOR gs_book-genre,
                  so_price FOR gs_book-price.
  PARAMETERS pa_stock AS CHECKBOX.
SELECTION-SCREEN END OF BLOCK b1.

SELECTION-SCREEN BEGIN OF BLOCK b2 WITH FRAME TITLE TEXT-b02.
  PARAMETERS: pa_price RADIOBUTTON GROUP srt DEFAULT 'X',
              pa_title RADIOBUTTON GROUP srt.
SELECTION-SCREEN END OF BLOCK b2.
  • ty_t_list는 10-2에서 배운 표 Type이에요. FORM에 Internal Table을 통째로 넘기려고 이름을 붙여 뒀어요. TYPE STANDARD TABLE OF … WITH DEFAULT KEY는 8-2에서 본, TYPE TABLE OF의 긴 모양이에요.
  • genre_t와 status는 Table에 없는 칸이에요. 화면에 보여 줄 글자를 담으려고 직접 더했어요.
  • gs_book은 SELECT-OPTIONS의 FOR 뒤에 쓰려고 만들었어요(9-5).
  • pa_price, pa_title은 값을 넣는 칸이 아니라 정렬 방법을 고르는 라디오 버튼이에요. 가격 범위를 넣는 so_price와 헷갈리지 마세요.

처음 나오는 문법은 하나뿐이에요.

12-4. 2단계: 읽어 담기 (get_data)

이제 이벤트와 첫 번째 FORM을 써요. START-OF-SELECTION은 Selection Screen 코드 아래에, FORM은 프로그램 맨 아래에 둬요.

*----------------------------------------------------------------------*
* ③ 이벤트
*----------------------------------------------------------------------*
START-OF-SELECTION.
  PERFORM get_data CHANGING gt_list.

  IF gt_list IS INITIAL.                   " 한 줄도 없으면
    MESSAGE TEXT-e01 TYPE 'S' DISPLAY LIKE 'E'.
    RETURN.
  ENDIF.

*----------------------------------------------------------------------*
* ④ FORM들
*----------------------------------------------------------------------*
*&---------------------------------------------------------------------*
*& Form get_data : 조건에 맞는 책 읽기
*&---------------------------------------------------------------------*
FORM get_data CHANGING ct_list TYPE ty_t_list.

  SELECT book_id title author genre price stock
    FROM yta_g##_book
    INTO CORRESPONDING FIELDS OF TABLE ct_list
    WHERE book_id IN so_id
      AND genre   IN so_genre
      AND price   IN so_price.

  IF pa_stock = abap_true.                 " "재고 있는 책만"에 체크했으면
    DELETE ct_list WHERE stock = 0.
  ENDIF.

ENDFORM.
  • ty_list에는 DB에 없는 칸(genre_t, status)이 있어서, 이름이 같은 칸만 골라 담는 INTO CORRESPONDING FIELDS OF TABLE을 써요(9-3).
  • Selection Screen의 so_id, pa_stock 같은 값은 프로그램 어디서나 읽을 수 있어서 FORM 안에서 바로 써요.
  • pa_stock = abap_true의 abap_true는 5-3에서 배운 대로 'X'와 같은 값이에요. pa_stock = 'X'라고 써도 똑같아요.
  • gt_list IS INITIAL은 "표가 비어 있으면"이라는 뜻이에요. DELETE로 다 지워진 경우까지 함께 잡을 수 있어서 sy-subrc보다 여기서는 이쪽이 정확해요.
  • 한 줄도 없을 때의 MESSAGE … TYPE 'S' DISPLAY LIKE 'E'.와 RETURN.은 5-5에서 배운 짝이에요.
확인해 보기

아직 화면에 보여 주는 코드가 없어서, 실행해도 Selection Screen으로 돌아오기만 해요. 그래서 디버거로 확인해요. 코드를 활성화한 뒤 PERFORM get_data 줄에 Breakpoint를 걸고 실행해요(6-3). F6으로 한 줄 넘긴 뒤, 8-4에서 해 본 것처럼 gt_list를 더블클릭해 변수 목록에 올리고, 목록의 GT_LIST를 다시 더블클릭하면 표 모양으로 내용을 볼 수 있어요.

조건을 바꿔 가며 줄 수를 확인해 보세요(7-7의 다섯 권 기준). 아무것도 안 넣으면 5줄, 장르에 I를 넣으면 2줄, "재고 있는 책만"에 체크하면 4줄이면 맞아요. GENRE_T와 STATUS 칸은 아직 비어 있어요. 12-5에서 채워요.

12-5. 3단계: 글자 채우고 정렬하기 (fill_text, sort_list)

읽어 온 줄을 하나씩 돌면서 장르 이름과 상태를 채워요. 8-6의 "Work Area로 꺼내서 고치고 MODIFY로 되돌려 놓기" 그대로예요. 두 FORM은 get_data의 ENDFORM. 아래, 프로그램 맨 아래에 이어 써요.

*&---------------------------------------------------------------------*
*& Form fill_text : 장르 이름과 재고 상태 채우기
*&---------------------------------------------------------------------*
FORM fill_text CHANGING ct_list TYPE ty_t_list.
  DATA ls_list TYPE ty_list.              " 이 FORM 안에서만 쓰는 Work Area

  LOOP AT ct_list INTO ls_list.
    " 장르 이름
    CASE ls_list-genre.
      WHEN 'N'.
        ls_list-genre_t = '소설'.
      WHEN 'I'.
        ls_list-genre_t = 'IT'.
      WHEN 'E'.
        ls_list-genre_t = '에세이'.
      WHEN OTHERS.
        ls_list-genre_t = '기타'.
    ENDCASE.

    " 재고 상태
    IF ls_list-stock = 0.
      ls_list-status = '품절'.
    ELSEIF ls_list-stock < 3.
      ls_list-status = '부족'.
    ELSE.
      ls_list-status = '충분'.
    ENDIF.

    MODIFY ct_list FROM ls_list INDEX sy-tabix.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*& Form sort_list : 고른 방법으로 정렬
*&---------------------------------------------------------------------*
FORM sort_list CHANGING ct_list TYPE ty_t_list.
  IF pa_price = abap_true.
    SORT ct_list BY price DESCENDING.
  ELSE.
    SORT ct_list BY title.
  ENDIF.
ENDFORM.

그리고 위쪽 START-OF-SELECTION으로 돌아가서, ENDIF. 바로 아래에 두 줄을 더해요.

  PERFORM fill_text CHANGING gt_list.
  PERFORM sort_list CHANGING gt_list.
  • ls_list는 10-2에서 배운 지역 변수예요. fill_text 안에서만 쓰는 Work Area라서 gs_가 아니라 ls_로 시작해요.
  • 11-3의 YG##_144에서는 같은 일을 Field Symbol로 했어요. 여기서는 Work Area와 MODIFY로 써 봐요. 결과는 같아요.
확인해 보기

이번에도 디버거로 확인해요. 활성화한 뒤 PERFORM sort_list 줄에 Breakpoint를 걸고, 아무것도 안 넣고 실행해요. 12-4에서 건 Breakpoint에 먼저 멈추면 F8로 넘어가요.

  1. 멈췄을 때 gt_list를 열어요. GENRE_T와 STATUS 칸이 채워져 있으면 fill_text는 성공이에요. 줄 순서는 아직 그대로예요.
  2. F5를 눌러 sort_list 안으로 들어가요. 몇 번 더 눌러 SORT 줄을 지난 뒤 gt_list를 다시 봐요. 줄 순서가 B0004, B0001, B0005, B0002, B0003으로 바뀌어 있으면 돼요.

PERFORM sort_list는 지금 마지막 문장이에요. F6으로 넘겨 버리면 프로그램이 끝나서 표를 볼 수 없으니 F5로 들어가요.

장르 이름은 Domain에도 있어요

7장에서 Domain YDO_G##_GENRE의 고정값에 "소설, IT, 에세이"를 이미 적었어요. 그 값을 프로그램에서 읽어 오는 방법도 있지만, 여기서는 CASE 연습을 위해 직접 적었어요. 장르가 새로 생기면 Domain과 이 CASE를 둘 다 고쳐야 한다는 점은 기억해 두세요.

12-6. 4단계: ALV로 보여 주기 (display_alv)

11장에서 배운 순서(만들기 → 설정 → 띄우기)를 FORM 하나에 담아요. genre_t와 status는 Data Element가 없어서 컬럼 제목이 비니, 직접 붙여요. 11-3에서 만든 YST_G##_BOOK_LIST를 쓰면 필요 없는 코드인데, 먼저 손으로 붙여 보고 12-10에서 바꿔 봐요. 이 FORM도 프로그램 맨 아래, sort_list의 ENDFORM. 아래에 이어 써요.

*&---------------------------------------------------------------------*
*& Form display_alv : ALV로 결과 보여 주기
*&---------------------------------------------------------------------*
FORM display_alv CHANGING ct_list TYPE ty_t_list.
  DATA: lo_alv     TYPE REF TO cl_salv_table,
        lo_columns TYPE REF TO cl_salv_columns_table,
        lo_column  TYPE REF TO cl_salv_column,
        lv_title   TYPE lvc_title.         " 화면 제목 (글자 70칸)

  " 1. 만들기
  TRY.
      cl_salv_table=>factory(
        IMPORTING
          r_salv_table = lo_alv
        CHANGING
          t_table      = ct_list ).
    CATCH cx_salv_msg.
      MESSAGE 'ALV를 만들지 못했어요' TYPE 'S' DISPLAY LIKE 'E'.
      RETURN.
  ENDTRY.

  " 2. 설정: 폭 맞추기, 비어 있는 컬럼 제목 붙이기
  lo_columns = lo_alv->get_columns( ).
  lo_columns->set_optimize( abap_true ).

  TRY.
      lo_column = lo_columns->get_column( 'GENRE_T' ).
      lo_column->set_short_text( '장르 이름' ).
      lo_column->set_medium_text( '장르 이름' ).
      lo_column->set_long_text( '장르 이름' ).

      lo_column = lo_columns->get_column( 'STATUS' ).
      lo_column->set_short_text( '상태' ).
      lo_column->set_medium_text( '상태' ).
      lo_column->set_long_text( '상태' ).
    CATCH cx_salv_not_found.
      MESSAGE '칸 이름을 다시 확인해 주세요' TYPE 'S' DISPLAY LIKE 'E'.
  ENDTRY.

  " 3. 설정: 툴바 버튼, 화면 제목, 줄무늬
  lo_alv->get_functions( )->set_all( abap_true ).

  lv_title = TEXT-t01.
  lo_alv->get_display_settings( )->set_list_header( lv_title ).
  lo_alv->get_display_settings( )->set_striped_pattern( abap_true ).

  " 4. 띄우기
  lo_alv->display( ).
ENDFORM.

START-OF-SELECTION의 PERFORM sort_list 줄 바로 아래에 한 줄을 더하면 완성이에요.

  PERFORM display_alv CHANGING gt_list.
  • display_alv는 표를 고치지 않아요. 그래도 factory가 표를 CHANGING으로 받으니(11-2), FORM도 CHANGING으로 받았어요.
  • FORM 안에서 만든 ALV 변수는 지역 변수라서 go_가 아니라 lo_로 시작해요.
  • 11장에서는 set_list_header( '도서 목록' )처럼 글자를 바로 넘겼어요. 여기서는 Text Symbol T01을 쓰려고 lv_title에 한 번 옮겨 담아서 넘겼어요. set_list_header는 글자 70칸(lvc_title)을 받는데, Text Symbol을 바로 넘기면 Type이 맞지 않는다는 문법 오류가 날 수 있거든요. 따옴표로 직접 적은 글자는 SAP가 알아서 맞춰 줘요.

걸어 둔 Breakpoint는 다시 클릭해서 지워요(6-3). 활성화하고 실행해 봐요. 그림 12-1의 아래쪽처럼 ALV가 뜨면 성공이에요.

  SELECT book_id title author genre price stock
    FROM yta_g##_book
    INTO CORRESPONDING FIELDS OF TABLE ct_list
    WHERE book_id IN so_id
      AND genre   IN so_genre
      AND price   IN so_price.

  IF pa_stock = abap_true.                 " "재고 있는 책만"에 체크했으면
    DELETE ct_list WHERE stock = 0.
  ENDIF.

ENDFORM.

*&---------------------------------------------------------------------*
*& Form fill_text : 장르 이름과 재고 상태 채우기
*&---------------------------------------------------------------------*
FORM fill_text CHANGING ct_list TYPE ty_t_list.
  DATA ls_list TYPE ty_list.              " 이 FORM 안에서만 쓰는 Work Area

  LOOP AT ct_list INTO ls_list.
    " 장르 이름
    CASE ls_list-genre.
      WHEN 'N'.
        ls_list-genre_t = '소설'.
      WHEN 'I'.
        ls_list-genre_t = 'IT'.
      WHEN 'E'.
        ls_list-genre_t = '에세이'.
      WHEN OTHERS.
        ls_list-genre_t = '기타'.
    ENDCASE.

    " 재고 상태
    IF ls_list-stock = 0.
      ls_list-status = '품절'.
    ELSEIF ls_list-stock < 3.
      ls_list-status = '부족'.
    ELSE.
      ls_list-status = '충분'.
    ENDIF.

    MODIFY ct_list FROM ls_list INDEX sy-tabix.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*& Form sort_list : 고른 방법으로 정렬
*&---------------------------------------------------------------------*
FORM sort_list CHANGING ct_list TYPE ty_t_list.
  IF pa_price = abap_true.
    SORT ct_list BY price DESCENDING.
  ELSE.
    SORT ct_list BY title.
  ENDIF.
ENDFORM.

12-8. 남이 만든 프로그램 읽는 법

회사에 가면 프로그램을 새로 쓰는 날보다 남이 만든 프로그램을 읽는 날이 훨씬 많아요. "이 화면의 이 칸이 왜 이렇게 나와요?"라는 질문을 받고 코드를 찾아가는 일부터 시작하거든요. 이 절에서는 새로 만드는 것이 없어요. 방금 완성한 YG##_146을 남이 만든 프로그램인 것처럼 읽어 봐요.

이 화면은 어느 프로그램일까요?

YG##_146을 실행해서 Selection Screen이 떠 있을 때 메뉴 System → Status를 눌러요. 열린 창에서 Program (screen) 칸을 찾으면 YG##_146이 적혀 있어요. 사용자가 "이 화면이 이상해요"라고 할 때 가장 먼저 여는 창이에요. ALV 결과 화면에서 열면 ALV를 그려 주는 SAP 프로그램의 이름이 대신 보여요. 그럴 때는 F3으로 Selection Screen에 돌아가서 다시 열어요.

SE80: 프로그램을 한눈에 보기

명령 필드에 /nSE80을 넣으면 Object Navigator가 열려요. 왼쪽 목록에서 Program을 고르고 1, 그 아래 칸에 YG##_146을 넣고 Enter를 눌러요 2.

  • 왼쪽에 프로그램이 트리로 펼쳐져요. Types, Fields(변수), Events, Subroutines(FORM) 같은 마디가 보여요. Screens 마디에는 Selection Screen이 들어 있어요.
  • 마디를 펼쳐서 FILL_TEXT를 더블클릭하면 3 오른쪽에 그 FORM의 코드가 바로 열려요. 긴 프로그램에서 목차처럼 써요.
  • 목록에서 Local Objects를 고르면 지금까지 내가 만든 프로그램, Table, Function Group이 모두 보여요. 복습할 때 편해요.

더블클릭은 "정의한 곳으로", F3은 "돌아오기"

코드 안의 이름을 더블클릭하면 그 이름을 정의한 곳으로 데려다줘요. 10-2에서는 아직 없는 FORM을 더블클릭해서 만들었죠. 이미 있는 것을 더블클릭하면 그곳으로 가요. 돌아올 때는 F3(Back)이에요.

직접 해 보기

SE80 오른쪽의 코드 창에서 해 봐요. 트리 맨 위의 YG##_146을 더블클릭하면 프로그램이 처음부터 보여요. SE38에서 열어도 똑같이 돼요.

  1. PERFORM get_data 줄의 get_data를 더블클릭해요. FORM get_data로 가요. F3으로 돌아와요.
  2. gt_list를 더블클릭해요. DATA 줄로 가요. 거기서 ty_t_list를 더블클릭하면 TYPES 줄로 가요.
  3. yta_g##_book을 더블클릭해요. SE11의 Table 화면이 열려요. TITLE 줄의 Data Element YDE_G##_TITLE을 더블클릭하고, 그 안의 Domain YDO_G##_NAME을 또 더블클릭해요. 7장에서 Domain → Data Element → Table 순서로 만든 길을 거꾸로 걷는 거예요. F3을 누른 만큼 되돌아와요.

Where-Used List: 누가 이것을 쓰나요?

더블클릭이 "어디서 정의했나"라면, Where-Used List는 반대로 "어디서 쓰나"를 찾아 줘요. 도구 모음의 Where-Used List 버튼(Ctrl+Shift+F3)이에요.

  • FORM fill_text 줄의 fill_text에 커서를 두고 버튼을 누르면, 이 FORM을 부르는 PERFORM 줄이 목록으로 나와요. 줄을 더블클릭하면 그 자리로 가요.
  • SE11에서 Table YTA_G##_BOOK을 열고 같은 버튼을 누르면, 이 Table을 쓰는 프로그램이 나와요. 9장부터 만든 프로그램들이 줄줄이 보일 거예요.

어느 쪽이든 찾을 범위를 묻는 창이 먼저 뜨면 그대로 Enter를 눌러요. Table에서는 Programs에 체크가 되어 있는지만 봐요.

Table의 칸을 바꾸거나 FORM의 파라미터를 고치면, 그것을 쓰는 곳이 모두 영향을 받아요. 그래서 Where-Used List는 고치기 전에 꼭 눌러 보는 버튼이에요.

코드가 안 보여요: INCLUDE

회사 프로그램을 열면 코드는 없고 INCLUDE로 시작하는 줄만 몇 개 보일 때가 많아요. 우리도 이미 하나 갖고 있어요. SE80의 목록에서 Function Group을 고르고 10-3에서 만든 YFG_G##를 넣어 봐요. 트리의 Includes 마디에 LYFG_G##TOP, LYFG_G##UXX가 보여요. LYFG_G##UXX를 더블클릭하면 이런 줄이 보여요.

INCLUDE lyfg_g##u01.      " Y_G##_DISCOUNT
INCLUDE lyfg_g##u02.      " Y_G##_GET_BOOK

교재에는 간추려 적었어요. 실제 화면에서는 이름이 대문자이고, 맨 위에 손으로 고치지 말라는 주석이 붙어 있어요. SAP가 관리하는 소스라서 그래요.

INCLUDE 이름.은 "다른 곳에 저장해 둔 소스를 이 자리에 끼워 넣어요"라는 뜻이에요. Function Module 하나가 INCLUDE 하나에 들어 있고, SAP가 알아서 나눠 둔 거예요. INCLUDE 줄의 이름을 더블클릭하면 그 소스로 들어가요.

회사의 조회 프로그램도 대부분 이렇게 나뉘어 있어요. 이름이 …TOP으로 끝나면 변수 선언, …F01로 끝나면 FORM 모음인 경우가 많아요. 그림 12-3의 구역을 하나씩 따로 저장해 둔 셈이에요. 프로그램을 열었는데 INCLUDE 몇 줄만 보여도 당황하지 말고 더블클릭으로 들어가요.

처음 보는 프로그램을 읽는 순서

위에서부터 한 줄씩 다 읽지 않아요. 이 순서로 읽어요.

  1. 먼저 실행해 봐요. 무엇을 넣으면 무엇이 나오는지 알고 읽으면 훨씬 쉬워요.
  2. 코드는 START-OF-SELECTION부터 봐요. 위쪽의 선언은 필요할 때 더블클릭으로 찾아가요.
  3. PERFORM 이름만 따라가며 큰 흐름을 잡아요.
  4. 궁금한 FORM만 더블클릭해서 들어가요.
  5. 값이 궁금하면 Breakpoint를 걸고 디버거로 확인해요(6장).
화면에서 거꾸로 찾는 방법 두 가지
  • 이 칸은 어느 Table의 값일까요? 화면의 입력 칸에 커서를 두고 F1을 누른 뒤, 도움말 창의 Technical Information 버튼을 눌러요. Table(또는 Structure) 이름과 Field 이름이 나와요.
  • 이 메시지는 어디서 나올까요? 상태 표시줄의 메시지를 더블클릭하면 Message Class와 메시지 번호가 보여요. SE91에서 그 번호를 찾아 Where-Used List를 누르면 메시지를 띄우는 코드가 나와요(5-6). 5-6의 YG##_122처럼 Message Class를 쓴 프로그램으로 해 보세요. YG##_146처럼 글자를 바로 넘겨 띄운 메시지(MESSAGE TEXT-e01 TYPE …)는 Message Class가 00으로 보여서 이 방법으로는 찾기 어려워요.

창의 모양은 버전에 따라 조금 달라요.

12-9. 읽기 실습: 선배가 만든 프로그램 고치기

이번에는 정말로 남이 쓴 코드를 읽어 봐요. 선배가 몇 해 전에 만든 "재고 부족 목록" 프로그램을 물려받았다고 해 볼게요. 하는 일은 11-6에서 내가 만든 YG##_145와 같아요. 뜻은 이미 아니까, 낯선 모양만 읽으면 돼요.

EV_TEXT의 Type은 받는 칸 genre_t(글자 10칸)와 같아야 해요. 11-3에서 만든 Data Element YDE_G##_GENRE_T가 바로 그 모양이에요. Type이 다르면 실행 중에 덤프가 나요.

Source code 탭에는 CASE를 그대로 옮기고, ls_list-genre는 iv_genre로, ls_list-genre_t는 ev_text로 바꿔 써요. fill_text에서는 CASE부터 ENDCASE까지를 지우고 그 자리에 Pattern 버튼으로 CALL FUNCTION을 넣어요(10-3). iv_genre에는 ls_list-genre를, ev_text에는 ls_list-genre_t를 짝지어요.

Method로 (10-4): 같은 CASE를 이번에는 로컬 클래스 lcl_book의 Method genre_text로 옮겨요. 장르 코드를 받아서(IMPORTING iv_genre) 장르 이름을 돌려줘요(RETURNING VALUE(rv_text) TYPE string). fill_text 안의 CASE부터 ENDCASE까지 열 줄이 한 줄로 줄어요. 앞의 Function Module 과제를 했다면 CALL FUNCTION 문장을 그 한 줄로 바꾸면 돼요.

Method로 바꾼 예시 답안 보기

클래스는 Selection Screen 코드 아래, START-OF-SELECTION 위에 둬요. 쓰는 곳보다 위에 있어야 하거든요(10-4).

CLASS lcl_book DEFINITION.
  PUBLIC SECTION.
    CLASS-METHODS genre_text
      IMPORTING iv_genre       TYPE yta_g##_book-genre
      RETURNING VALUE(rv_text) TYPE string.
ENDCLASS.

CLASS lcl_book IMPLEMENTATION.
  METHOD genre_text.
    CASE iv_genre.
      WHEN 'N'.
        rv_text = '소설'.
      WHEN 'I'.
        rv_text = 'IT'.
      WHEN 'E'.
        rv_text = '에세이'.
      WHEN OTHERS.
        rv_text = '기타'.
    ENDCASE.
  ENDMETHOD.
ENDCLASS.

    ls_list-genre_t = lcl_book=>genre_text( iv_genre = ls_list-genre ).

  • 프로그램은 요구 사항 → 설계(흐름과 덩어리) → 단계별로 만들고 확인 순서로 만들어요.
