5장

Selection Screen으로 입력받기

이번 장 목표
  • PARAMETERS로 입력 칸을 만들고, 입력한 값을 프로그램에서 쓸 수 있어요.
  • 필수 입력(OBLIGATORY), 기본값(DEFAULT), 체크박스, 라디오 버튼을 만들 수 있어요.
  • 입력 칸의 이름표를 Selection Text로 붙일 수 있어요.
  • 프로그램이 실행되는 이벤트 순서를 알고, 2장에서 미뤄 둔 START-OF-SELECTION의 정체를 이해해요.
  • 잘못된 값은 AT SELECTION-SCREEN에서 오류 메시지로 막을 수 있어요.
  • 메시지를 Message Class에 모아 두고 번호로 꺼내 쓸 수 있어요.

5-1. 입력 칸 만들기: PARAMETERS

4장까지는 점수나 단 같은 값을 코드 안에 직접 적었어요. 그러면 값을 바꿀 때마다 코드를 고쳐야 하죠. PARAMETERS를 쓰면 프로그램을 실행할 때 사용자가 값을 입력하는 화면이 먼저 나와요. 이 화면을 Selection Screen이라고 해요. 아래 카드대로 새 프로그램을 만들어서(2-2) 코드를 넣고 실행해 보세요.

새로 만들기ProgramSE38
Program
YG##_118
Title
[예제] 이름 입력받아 인사하기
REPORT yg##_118.

PARAMETERS pa_name TYPE c LENGTH 10.

START-OF-SELECTION.
  WRITE: / pa_name, '님, 반가워요!'.
  1. 입력 칸 1에 이름을 넣고,
  2. Execute 버튼 2(또는 F8)을 누르면 START-OF-SELECTION 아래 코드가 실행돼요.

F8을 두 번 누르는 셈이에요. 코드 화면에서 한 번 누르면 Selection Screen이 나오고, 여기서 한 번 더 눌러야 결과가 나와요. Selection Screen에서 Enter만 누르면 결과 화면으로 넘어가지 않아요(이유는 5-4에서 알려 줄게요).

결과 화면에는 이렇게 나와요.

홍길동     님, 반가워요!
  • 이름과 님 사이가 벌어진 것은 pa_name이 10칸짜리라서예요. 남는 칸이 공백으로 같이 출력돼요(공백 칸 수는 조금 달라도 괜찮아요).
  • 영문으로 kim을 넣으면 KIM으로 바뀌어 나와요. 고장이 아니에요. 이유와 막는 방법은 5-3에서 알려 줄게요.
  • 결과 화면에서 F3(Back)을 누르면 Selection Screen으로 돌아와요. 넣었던 값이 그대로 남아 있어서 값만 바꿔 다시 실행하기 좋아요. 한 번 더 F3을 누르면 코드 화면이에요.

PARAMETERS 이름 TYPE 타입.은 DATA와 모양이 거의 같아요. 실제로 pa_name은 변수처럼 쓸 수 있어요. 가장 큰 차이는 화면에 입력 칸이 생긴다는 거예요.

자주 하는 실수

PARAMETERS 이름은 8글자까지만 돼요. pa_number(9글자)처럼 길게 지으면 문법 오류가 나요. 그래서 pa_num, pa_dan처럼 짧게 지어요.

5-2. 이름표 붙이기: Selection Text

그림 5-1에서 입력 칸 옆에 PA_NAME이라는 이름이 그대로 보였죠? 사용자에게는 이름처럼 보여 주는 게 좋아요. 이 이름표를 Selection Text라고 해요.

직접 해 보기
  1. YG##_118을 저장하고 활성화한 다음, ABAP Editor 메뉴에서 Goto → Text Elements로 들어가요(2-7에서 Text Symbol을 만든 곳이에요). 버전에 따라 하위 메뉴가 보이면 Selection Texts를 골라요.
  2. Selection Texts 탭을 눌러요. PA_NAME이 목록에 이미 있을 거예요.
  3. Text 칸에 이름을 입력해요.
  4. 저장하고 활성화(Ctrl+F3)한 뒤 F3으로 돌아와 다시 실행해 보세요. 입력 칸 옆이 이름으로 바뀌어요.

앞으로 이름표가 필요한 프로그램에서는 Name과 Text에 넣을 글자를 표나 카드로 알려 줄게요. 그대로 넣어야 화면이 교재의 그림과 같아져요. 그림 5-2의 Dictionary Ref. 칸은 지금은 건드리지 않아요. 9장에서 써요.

Text Symbol과 Selection Text

둘 다 Text Elements 화면에 있어서 헷갈리기 쉬워요. Text Symbol은 TEXT-001처럼 코드에서 꺼내 쓰는 글자, Selection Text는 입력 칸 옆에 붙는 이름표예요.

  • 둘은 Text Elements 화면에서 한 번에 활성화돼요. 코드를 활성화하는 것과는 별개라서, 이 화면에서도 꼭 활성화해요.
  • 둘 다 로그인한 언어마다 따로 저장돼요. 그래서 늘 같은 언어로 로그인해요(1-3).

5-3. 입력 칸 꾸미기

PARAMETERS 뒤에 몇 마디를 덧붙이면 입력 칸의 성격이 바뀌어요.

쓰는 법 뜻 예
OBLIGATORY 필수 입력. 비워 두면 실행이 안 돼요 PARAMETERS pa_num TYPE i OBLIGATORY.
DEFAULT 값 처음부터 값이 들어 있어요 PARAMETERS pa_dan TYPE i DEFAULT 2.
LOWER CASE 영문 소문자를 넣은 그대로 받아요 PARAMETERS pa_name TYPE c LENGTH 10 LOWER CASE.
AS CHECKBOX 체크박스. 체크하면 'X', 아니면 빈칸 PARAMETERS pa_vip AS CHECKBOX.
RADIOBUTTON GROUP 그룹 라디오 버튼. 같은 그룹 중 하나만 골라요 아래 예 참고

5-1에서 kim을 넣었더니 KIM이 됐죠. SAP는 글자 입력 칸의 영문을 대문자로 바꿔서 받아요. 넣은 그대로 받고 싶을 때 LOWER CASE를 붙여요. YG##_118의 pa_name 줄을 위 표의 예처럼 고쳐 보세요. LOWER CASE는 마침표 앞에 덧붙여요. 활성화한 다음 kim을 넣어 실행하면 이번에는 kim 그대로 나와요. 한글은 대문자와 소문자가 없어서 어느 쪽이든 그대로예요.

한 프로그램에 모아 보기

나머지 네 가지는 새 프로그램 하나에 모아 볼게요.

새로 만들기ProgramSE38
Program
YG##_119
Title
[예제] 입력 칸 꾸미기
REPORT yg##_119.

PARAMETERS: pa_num  TYPE i OBLIGATORY,               " 필수 입력
            pa_dan  TYPE i DEFAULT 2,                " 기본값 2
            pa_vip  AS CHECKBOX,                     " 체크박스
            pa_kor  RADIOBUTTON GROUP lang DEFAULT 'X',
            pa_eng  RADIOBUTTON GROUP lang.

START-OF-SELECTION.
  IF pa_vip = 'X'.
    WRITE / 'VIP 회원이에요'.
  ENDIF.

  IF pa_kor = 'X'.
    WRITE / '안녕하세요'.
  ELSE.
    WRITE / 'Hello'.
  ENDIF.

코드를 활성화한 다음, 5-2에서 한 것처럼 Selection Text를 아래 표대로 넣고 활성화해요.

Name Text
PA_NUM 숫자
PA_DAN 단
PA_VIP VIP 회원
PA_KOR 한국어
PA_ENG 영어

숫자에 7을 넣고, VIP 회원에 체크하고, 영어를 고른 뒤 F8을 누르면 이렇게 나와요.

VIP 회원이에요
Hello

숫자와 단은 화면 모양을 보려고 만든 칸이라 결과에는 쓰지 않았어요.

체크했는지 확인하기

체크박스와 라디오 버튼은 값이 'X'인지를 보고 확인해요. 체크했거나 골랐으면 'X', 아니면 빈칸이에요. 4-4에서 본 "예는 'X', 아니요는 빈칸" 습관 그대로예요.

'X' 대신 abap_true라고 쓴 코드도 자주 만나요. abap_true는 'X', abap_false는 빈칸과 같은 값이에요. SAP가 미리 만들어 둔 이름이라 선언하지 않고 바로 쓸 수 있어요. IF pa_vip = abap_true.라고 써도 똑같이 동작해요. 이 교재도 11장부터는 이 모양을 써요.

자주 하는 실수
  • 라디오 버튼의 그룹 이름은 4글자까지예요. GROUP lang은 되지만 GROUP color는 문법 오류예요.
  • 한 그룹에는 라디오 버튼이 두 개 이상 있어야 해요. DEFAULT 'X'를 아무 데도 안 쓰면 첫 번째 버튼이 골라져 있어요.
  • 숫자 칸(TYPE i)은 값이 0이면 화면에 빈칸으로 보여요. 그래서 필수 칸에 0을 넣으면 SAP가 "비어 있어요"라고 막을 수 있어요.
입력값을 저장해 두기: Variant

값을 바꿔 가며 여러 번 테스트하다 보면 매번 다시 입력하기가 번거로워요. Selection Screen에서 값을 채운 다음 저장 버튼(Ctrl+S)을 누르면, 지금 넣은 값들을 Variant라는 묶음으로 저장할 수 있어요.

  1. Variant 이름(예: VIP_EN)과 설명을 넣고 저장해요.
  2. 다음에 실행할 때 Get Variant 버튼을 눌러 그 이름을 고르면, 저장해 둔 값이 한 번에 채워져요.

버튼 모양과 화면은 버전에 따라 조금 달라요.

5-4. 프로그램이 실행되는 순서: 이벤트

2장에서 START-OF-SELECTION을 "시작 표시"라고만 했었죠. 이제 정체를 밝힐 때가 됐어요.

실행형 프로그램(Executable program)은 위에서 아래로 그냥 흘러가는 게 아니라, SAP가 정해 둔 순서(이벤트)에 맞춰 코드 덩어리를 불러요. 각 덩어리 맨 앞에 적는 낱말이 이벤트 키워드예요.

이벤트 언제 실행되나요 주로 하는 일
INITIALIZATION Selection Screen이 뜨기 직전에 한 번 "오늘부터 7일 뒤"처럼 계산이 필요한 기본값 넣기
AT SELECTION-SCREEN 사용자가 Enter나 F8을 눌렀을 때 입력값이 올바른지 검사하기
START-OF-SELECTION F8을 눌렀고 검사를 통과한 뒤 프로그램의 본 작업

Enter를 누르면 검사만 하고 Selection Screen에 그대로 머물러요. 본 작업으로 넘어가는 것은 F8(Execute)뿐이에요.

그럼 START-OF-SELECTION은 꼭 써야 해요?

이벤트 키워드 없이 쓴 코드는 SAP가 알아서 START-OF-SELECTION에 넣어 줘요. 그래서 2장 프로그램은 빼도 돌아가요. 하지만 INITIALIZATION 같은 다른 이벤트를 쓰기 시작하면, 다음 이벤트 키워드가 나올 때까지는 전부 앞 이벤트의 코드가 돼요. 본 작업이 어디서 시작하는지 분명하게 하려고 항상 START-OF-SELECTION을 써요.

INITIALIZATION으로 기본값 넣기

DEFAULT 뒤에는 값 하나만 쓸 수 있어요. DEFAULT 2 같은 숫자나 글자, DEFAULT sy-datum(오늘 날짜)처럼 이미 있는 변수는 돼요. 하지만 DEFAULT sy-datum + 7 같은 계산식은 문법 오류예요. "오늘부터 7일 뒤"처럼 계산이 필요한 기본값은 INITIALIZATION에서 넣어요.

새로 만들기ProgramSE38
Program
YG##_120
Title
[예제] INITIALIZATION으로 기본값 넣기
REPORT yg##_120.

PARAMETERS pa_date TYPE sy-datum.

INITIALIZATION.
  pa_date = sy-datum + 7.      " 화면이 뜨기 전에 기본값 넣기

START-OF-SELECTION.
  WRITE: / '선택한 날짜:', pa_date.

실행하면 입력 칸에 오늘부터 7일 뒤 날짜가 미리 들어 있어요. 오늘이 2026년 11월 17일이라면 2026.11.24예요. 그대로 F8을 누르면 이렇게 나와요.

선택한 날짜: 2026.11.24
  • 날짜 입력 칸은 3-7에서 배운 대로 TYPE sy-datum으로 만들어요. 그래야 결과 화면에서도 2026.11.24처럼 점이 찍혀 나와요.
  • 날짜 칸에서 F4를 누르면 달력에서 날짜를 고를 수 있어요.
  • 이름표를 붙이지 않아서 입력 칸 옆에는 PA_DATE가 보여요. 연습 삼아 Selection Text에 날짜를 넣어 봐도 좋아요.

5-5. 잘못된 값 막기: AT SELECTION-SCREEN과 MESSAGE

구구단 프로그램에 15단이나 -3단을 넣으면 곤란하겠죠. AT SELECTION-SCREEN에서 입력값을 검사하고, 틀렸으면 MESSAGE로 알려 줘요. 숫자 칸에 글자를 넣는 것 같은 실수는 Type이 알아서 막아 주니, 우리는 "2단부터 9단까지" 같은 내 프로그램만의 규칙만 검사하면 돼요.

새로 만들기ProgramSE38
Program
YG##_121
Title
[예제] 입력한 단의 구구단
REPORT yg##_121.

PARAMETERS pa_dan TYPE i OBLIGATORY DEFAULT 2.

DATA gv_result TYPE i.

AT SELECTION-SCREEN.
  IF pa_dan < 2 OR pa_dan > 9.
    MESSAGE TEXT-e01 TYPE 'E'.        " E01: 2단부터 9단까지만 입력할 수 있어요
  ENDIF.

START-OF-SELECTION.
  DO 9 TIMES.
    gv_result = pa_dan * sy-index.
    WRITE: /(1) pa_dan, 'x', (1) sy-index, '=', (2) gv_result.
  ENDDO.
직접 해 보기
  1. 위 카드대로 프로그램을 만들고, 코드를 넣어 저장하고 활성화해요.
  2. Goto → Text Elements로 들어가서 아래 표의 두 가지를 넣어요. Text Symbol의 Sym 칸에는 001 같은 숫자뿐 아니라 E01처럼 글자를 섞은 세 글자도 쓸 수 있어요. 오류 문장은 E로 시작하게 지어 두면 찾기 쉬워요. 코드에서는 TEXT-e01로 꺼내요.
  3. 그 화면에서 저장하고 활성화(Ctrl+F3)해요.
  4. F3으로 코드 화면에 돌아와 실행해요. 15를 넣고 F8을 눌러 보세요. 그다음 7로 고쳐서 다시 눌러 보세요.
탭 이름 Text
Text Symbols E01 2단부터 9단까지만 입력할 수 있어요
Selection Texts PA_DAN 단

AT SELECTION-SCREEN에서 TYPE 'E' 메시지를 보내면 프로그램이 다음 단계로 넘어가지 않고 Selection Screen에 그대로 머물러요. 사용자는 값을 고쳐서 다시 F8을 누르면 돼요. 오류 문장은 2-7에서 배운 대로 Text Symbol(TEXT-e01)로 빼 두었어요.

7로 고쳐서 실행하면 검사를 통과하고 7단이 나와요. WRITE 줄은 4-9의 구구단과 같은 모양이에요.

7 x 1 = 7
7 x 2 = 14
…
7 x 9 = 63

MESSAGE의 종류

MESSAGE 문장의 기본 모양은 MESSAGE 글자 TYPE '종류'.예요.

  • 글자 자리에는 Text Symbol 대신 MESSAGE '2단부터 9단까지만 입력할 수 있어요' TYPE 'E'.처럼 따옴표 글자를 바로 써도 돼요. 똑같이 동작해요. 뒤 장의 짧은 예제에서는 이 모양도 자주 만나요.
  • 종류 자리에는 아래 여섯 가지 가운데 하나를 써요.
TYPE 이름 보이는 모습 그 뒤에는
'S' Success 상태 표시줄에 초록색 계속 진행
'I' Information 팝업 창 확인을 누르면 계속
'W' Warning 상태 표시줄에 노란색 Selection Screen에서는 Enter로 넘어갈 수 있어요
'E' Error 상태 표시줄에 빨간색 Selection Screen에서는 화면에 머물러요
'A' Abort 팝업 창 프로그램을 끝내요 (읽기용)
'X' Exit 덤프 화면 일부러 덤프(6-8)를 내요 (읽기용)

'A'와 'X'는 직접 쓸 일이 거의 없어요. 회사 코드에서 만났을 때 뜻만 알면 돼요.

자주 하는 실수
  • 검사 코드를 START-OF-SELECTION에 넣고 TYPE 'E'를 쓰면, 이미 입력 화면을 떠난 뒤라 프로그램이 그 자리에서 끝나 버려요. 값을 고치려면 처음부터 다시 실행해야 해요. 입력값 검사는 AT SELECTION-SCREEN에 두는 습관을 들여요.
  • F8을 눌렀는데 다음으로 넘어가지 않고 메시지 글자가 비어 보이면(빨간 표시만 나오거나 아무 글자도 안 보이면) Text Symbol을 안 만들었거나 활성화하지 않은 거예요.
  • 오류 메시지를 하나로 뭉뚱그리지 말고, 상황마다 나눠 주면 사용자가 무엇을 고쳐야 할지 바로 알아요. 예를 들어 "2보다 작아요"와 "9보다 커요"를 따로 보여 줄 수 있어요.

실행을 시작한 뒤에 멈춰야 할 때

입력값은 맞는데 본 작업을 하다가 멈춰야 할 때가 있어요. 예를 들어 9장에서 배울 데이터 조회에서, 조건에 맞는 것이 한 건도 없을 때예요. 이미 START-OF-SELECTION에 들어온 뒤라서, 위에서 본 것처럼 TYPE 'E'를 쓰면 프로그램이 끝나 버려요.

이럴 때는 아래처럼 MESSAGE … TYPE 'S' DISPLAY LIKE 'E'.와 RETURN. 두 줄을 짝으로 써요. 모양만 보여 주는 조각이라 지금 따라 치지는 않아요(gv_count는 예로 든 변수예요).

START-OF-SELECTION.
  IF gv_count = 0.                   " 예: 찾은 데이터가 0건일 때
    MESSAGE '조건에 맞는 데이터가 없어요' TYPE 'S' DISPLAY LIKE 'E'.
    RETURN.                          " 본 작업을 여기서 끝내요
  ENDIF.
  • TYPE 'S' DISPLAY LIKE 'E'는 동작은 Success, 모양만 Error인 메시지예요. 빨간색으로 보이지만 프로그램은 끝나지 않아요.
  • RETURN.은 지금 하던 처리 덩어리를 그 자리에서 끝내요(4-8). 여기서는 START-OF-SELECTION 아래에 남은 코드를 모두 건너뛰어요.
  • 출력한 것이 없으니 Selection Screen으로 돌아와요. 넣었던 값이 그대로 남아 있고, 메시지는 그 화면의 상태 표시줄에 보여요. 사용자는 값을 고쳐서 다시 실행하면 돼요.

회사 코드에서도 흔히 보는 오래된 모양이에요. 6-8에서 처음 직접 써 보고, 9장부터는 "조건에 맞는 데이터가 없어요" 같은 안내에 계속 쓰니 짝으로 기억해 두세요.

5-6. 메시지를 한곳에 모으기: Message Class

5-5에서는 오류 문장을 Text Symbol E01에 넣었어요. 그런데 Text Symbol은 그 프로그램 안에서만 쓸 수 있어요. 다른 프로그램에서 같은 문장이 필요하면 또 만들어야 해요. 그래서 회사 프로그램은 메시지를 Message Class라는 공용 보관함에 번호를 붙여 모아 두고, 여러 프로그램이 같이 꺼내 써요. 메시지를 관리하는 T-code SE91에서 내 Message Class를 하나 만들어 볼게요.

새로 만들기Message ClassSE91
Message Class
YMSG_G##
Short Description
G## 연습용 메시지
직접 해 보기
  1. 명령 필드에 /nSE91을 넣고 Enter를 눌러요.
  2. Message class 칸에 YMSG_G##를 넣고 Create를 눌러요.
  3. Short text 칸에 카드의 Short Description 값 G## 연습용 메시지를 넣고 저장(Ctrl+S)해요. 늘 하던 대로 Local Object를 골라요.
  4. Messages 탭을 눌러요. 001 줄에 이름을 입력해 주세요, 002 줄에 &1님, 반가워요!를 넣고 다시 저장해요.

Message Class는 활성화가 따로 없어요. 저장하면 바로 쓸 수 있어요. 메시지도 Text Symbol처럼 로그인한 언어마다 따로 저장되니 늘 같은 언어로 로그인해요(5-2). 화면 모양과 순서는 버전에 따라 조금 달라요.

&1은 나중에 값이 들어올 빈자리예요. 메시지를 띄울 때 프로그램이 넘겨준 값이 이 자리에 들어가요. 이제 이 메시지를 쓰는 프로그램을 만들어요.

새로 만들기ProgramSE38
Program
YG##_122
Title
[예제] Message Class로 입력 검사
REPORT yg##_122 MESSAGE-ID ymsg_g##.   " 이 프로그램이 쓸 Message Class

PARAMETERS pa_name TYPE c LENGTH 10.

AT SELECTION-SCREEN.
  IF pa_name IS INITIAL.
    MESSAGE e001.                     " 001: 이름을 입력해 주세요
  ENDIF.

START-OF-SELECTION.
  MESSAGE s002 WITH pa_name.          " 002: &1님, 반가워요!
  • 이번에는 SAP가 넣어 준 REPORT 줄도 고쳐요. 마침표 앞에 MESSAGE-ID ymsg_g##를 덧붙여요. "이 프로그램은 YMSG_G##의 메시지를 써요"라는 뜻이에요. 빼먹으면 MESSAGE e001. 줄에서 문법 오류가 나요.
  • MESSAGE e001.의 e는 5-5에서 배운 종류(Error), 001은 메시지 번호예요. 종류 글자를 번호 앞에 붙여 써요. s002는 002번을 Success로 띄워요.
  • WITH pa_name은 메시지의 &1 자리에 pa_name의 값을 넣어요. 빈자리는 &1부터 &4까지 네 개를 쓸 수 있어요.
  • 빈칸을 막는 것은 OBLIGATORY로도 돼요. 여기서는 내가 만든 메시지를 띄워 보려고 직접 검사했어요.

이름을 비우고 F8을 누르면 상태 표시줄에 빨간색으로 이름을 입력해 주세요가 나와요. 홍길동을 넣고 누르면 홍길동님, 반가워요!가 초록색으로 나와요. WRITE로 출력한 것이 없어서 결과 화면은 뜨지 않고 Selection Screen에 그대로 있어요. s002를 i002로 바꾸면 같은 문장이 팝업 창으로 나와요.

이름표를 붙이지 않아서 입력 칸 옆에는 PA_NAME이 보여요. 문장 대신 E:YMSG_G##:001 같은 글자가 나오면 SE91의 Messages 탭에서 그 번호에 글자를 넣고 저장했는지 봐요.

회사 코드에서 만나는 모양

" ① Message Class 이름을 괄호 안에 적은 꼴
MESSAGE s001(ymsg_g##) DISPLAY LIKE 'E'.

" ② 다른 코드가 남긴 메시지를 그대로 다시 띄우는 꼴
MESSAGE ID sy-msgid TYPE sy-msgty NUMBER sy-msgno
        WITH sy-msgv1 sy-msgv2 sy-msgv3 sy-msgv4.
  • ①처럼 괄호 안에 Message Class를 적으면 REPORT 줄에 MESSAGE-ID가 없어도 돼요. 회사 코드의 MESSAGE e001(zsd) WITH …가 이 꼴이에요. 뒤에는 5-5의 DISPLAY LIKE 'E'도 붙일 수 있어요.
  • ②는 남이 남긴 메시지를 그대로 다시 띄우는 줄이에요. 10장에서 배울 Function Module 같은 다른 코드는 메시지를 직접 띄우지 않고 시스템 필드에 적어만 둘 때가 있어요. sy-msgid는 Message Class, sy-msgty는 종류, sy-msgno는 번호, sy-msgv1~sy-msgv4는 &1~&4에 들어갈 값이에요. 지금은 한 덩어리로 알아보기만 하면 돼요. 10-3에서 다시 만나요.
  • 코드에서 e001 같은 메시지 번호를 더블클릭하면 SE91의 그 메시지로 바로 가요. 문장을 확인하거나 고칠 때 편해요.

이 교재의 짧은 예제는 5-5처럼 글자를 따옴표 안에 그대로 쓰거나 Text Symbol을 써요. 회사 프로그램은 Message Class를 써요. 세 가지 모두 읽을 줄 알면 돼요.

5-7. 미니 실습: 도서 대여 기간 계산

이 장에서 배운 입력 칸, 기본값, 입력 검사를 한 프로그램에 모아 볼게요.

YG##_123
Title
[실습] 도서 대여 기간 계산
직접 해 보기

위 카드대로 프로그램을 만들고, 아래 순서로 코드를 써 보세요.

  1. 입력 칸 세 개를 만들어요.
    • pa_date 대여일(TYPE sy-datum): 기본값은 오늘 날짜예요. DEFAULT sy-datum으로도 되지만, 이번에는 연습 삼아 INITIALIZATION에서 넣어 봐요.
    • pa_days 대여 일수(TYPE i): 필수 입력이에요.
    • pa_vip VIP 회원(체크박스)
  2. 여기까지 쓴 코드를 저장하고 활성화해요. 그다음 Selection Text와 Text Symbol을 아래 표대로 넣고, 그 화면에서도 활성화해요(5-2).
  3. AT SELECTION-SCREEN에서 대여 일수가 1보다 작으면 TEXT-e01, 14보다 크면 TEXT-e02 오류를 보여 줘요.
  4. 반납일 = 대여일 + 대여 일수. VIP면 7일 더 빌릴 수 있어요. 반납일을 담을 변수도 TYPE sy-datum으로 만들어요. TYPE d로 만들면 화면에 점 없이 나와요(3-7).
  5. 대여일, 대여 일수, 반납일을 출력해요. VIP 회원이면 반납일 앞에 VIP 회원이라 7일 더 빌릴 수 있어요도 한 줄 출력해요(그림 5-7).
  6. 대여 일수에 20과 -1을 차례로 넣어서 두 오류 메시지가 나오는지 확인해요. -1은 넣고 나면 1-처럼 부호가 뒤에 보일 수 있어요. 0은 SAP가 빈칸으로 봐서, 내가 만든 메시지 대신 필수 칸을 채우라는 메시지가 먼저 나올 수 있어요.
탭 이름 Text
Selection Texts PA_DATE 대여일
Selection Texts PA_DAYS 대여 일수
Selection Texts PA_VIP VIP 회원
Text Symbols E01 대여 일수는 1일 이상이어야 해요
Text Symbols E02 대여 일수는 최대 14일이에요
예시 답안 보기
*&---------------------------------------------------------------------*
* 설명: PARAMETERS, INITIALIZATION, AT SELECTION-SCREEN 연습
* Text Symbol  E01: 대여 일수는 1일 이상이어야 해요
*              E02: 대여 일수는 최대 14일이에요
* Selection Text PA_DATE 대여일 / PA_DAYS 대여 일수 / PA_VIP VIP 회원
*&---------------------------------------------------------------------*
REPORT yg##_123.

PARAMETERS: pa_date TYPE sy-datum,
            pa_days TYPE i OBLIGATORY,
            pa_vip  AS CHECKBOX.

DATA gv_return TYPE sy-datum.          " TYPE d로 만들면 점 없이 나와요 (3-7)

INITIALIZATION.
  pa_date = sy-datum.                  " 기본값: 오늘

AT SELECTION-SCREEN.
  " 대여 일수 검사 (상황별로 메시지를 나눠요)
  IF pa_days < 1.
    MESSAGE TEXT-e01 TYPE 'E'.
  ELSEIF pa_days > 14.
    MESSAGE TEXT-e02 TYPE 'E'.
  ENDIF.

START-OF-SELECTION.
  gv_return = pa_date + pa_days.

  WRITE: / '대여일:',    pa_date,
         / '대여 일수:', pa_days.

  IF pa_vip = 'X'.
    gv_return = gv_return + 7.         " VIP는 7일 더
    WRITE / 'VIP 회원이라 7일 더 빌릴 수 있어요'.
  ENDIF.

  WRITE: / '반납일:', gv_return.
확인 문제
  1. PARAMETERS pa_student TYPE c LENGTH 10.은 왜 오류가 날까요?
  2. 입력 칸 옆에 PA_DAYS가 그대로 보여요. 무엇을 하면 대여 일수로 바꿀 수 있을까요?
  3. 아래 네 가지를 실행되는 순서대로 놓아 보세요. START-OF-SELECTION, Selection Screen 표시, INITIALIZATION, AT SELECTION-SCREEN
  4. 입력값이 틀렸을 때 사용자가 바로 고칠 수 있게 하려면, 검사 코드를 어느 이벤트에 두고 어떤 TYPE의 메시지를 써야 할까요?
  5. 체크박스 pa_vip가 체크되었는지 어떻게 확인할까요?
  6. START-OF-SELECTION 안에서 "데이터가 없어요"라고 알리고 멈추려고 해요. TYPE 'E' 메시지 대신 어떤 두 줄을 쓸까요?
  7. 회사 코드에서 MESSAGE e002(zlib) WITH gv_name.을 만났어요. e, 002, zlib, WITH gv_name은 각각 무슨 뜻일까요?
정답 보기
  1. PARAMETERS 이름은 8글자까지인데 pa_student는 10글자예요. pa_stud처럼 줄여요.
  2. Goto → Text Elements → Selection Texts에서 PA_DAYS의 Text에 대여 일수를 넣고 활성화해요.
  3. INITIALIZATION → Selection Screen 표시 → AT SELECTION-SCREEN → START-OF-SELECTION
  4. AT SELECTION-SCREEN에서 TYPE 'E' 메시지를 써요. 그러면 화면에 머물러서 바로 고칠 수 있어요.
  5. IF pa_vip = 'X'.로 확인해요. IF pa_vip = abap_true.라고 써도 같아요. 체크하지 않으면 빈칸이에요.
  6. MESSAGE … TYPE 'S' DISPLAY LIKE 'E'. 다음 줄에 RETURN.을 써요. 프로그램이 끝나지 않고 Selection Screen으로 돌아와서 값을 고칠 수 있어요.
  7. e는 종류(Error), 002는 메시지 번호, zlib은 그 메시지가 들어 있는 Message Class 이름이에요. WITH gv_name은 메시지 글자의 &1 자리에 gv_name의 값을 넣으라는 뜻이에요.
정리
  • PARAMETERS는 입력 칸이 생기는 변수예요. 이름은 8글자까지예요.
  • OBLIGATORY는 필수, DEFAULT는 기본값, LOWER CASE는 소문자 그대로 받기, AS CHECKBOX와 RADIOBUTTON GROUP은 체크박스와 라디오 버튼이에요.
  • 체크했는지는 'X'로 확인해요. abap_true는 'X', abap_false는 빈칸과 같은 값이에요.
  • 입력 칸 이름표는 Selection Text로 붙이고, 꼭 활성화해요.
  • 이벤트 순서: INITIALIZATION → Selection Screen → AT SELECTION-SCREEN → START-OF-SELECTION.
  • 입력값 검사는 AT SELECTION-SCREEN에서 MESSAGE … TYPE 'E'로 해요. 메시지 글자는 따옴표 안에 바로 쓰거나 Text Symbol로 빼 둬요.
  • 본 작업을 시작한 뒤에 멈출 때는 MESSAGE … TYPE 'S' DISPLAY LIKE 'E'. 다음에 RETURN.을 써요.
  • 회사 프로그램은 메시지를 Message Class에 번호로 모아 두고 MESSAGE e001(클래스) WITH 값.처럼 꺼내 써요.
