B. 자주 쓰는 sy- 필드

sy-로 시작하는 값은 SAP가 알아서 채워 주는 시스템 필드예요.

필드 뜻 예 / 언제 봐요?
sy-subrc 방금 한 일의 결과. 0이면 성공 READ TABLE, SELECT, CALL FUNCTION 바로 뒤
sy-tabix LOOP에서 지금 줄 번호 MODIFY gt FROM gs INDEX sy-tabix
sy-index DO·WHILE에서 지금 몇 번째 바퀴 4장 구구단
sy-dbcnt SELECT 등으로 처리한 줄 수 9장
sy-datum 오늘 날짜 (YYYYMMDD) 20261117
sy-uzeit 지금 시각 (HHMMSS) 093000
sy-uname 로그인한 사용자 ID
sy-mandt 로그인한 클라이언트 번호 100
sy-langu 로그인 언어 3(한국어), E(영어)
sy-repid 지금 실행 중인 프로그램 이름
sy-sysid 시스템 ID
기억해 두기

sy-subrc, sy-tabix, sy-dbcnt는 다음 문장이 실행되면 바뀌어요. 필요하면 바로 다음 줄에서 확인하거나 내 변수에 옮겨 둬요.

C. 자주 보는 오류와 해결

문법 검사·활성화에서 나는 오류

이럴 때 원인 이렇게 고쳐요
엉뚱한 줄에서 이상한 오류가 나요 앞줄 끝의 마침표가 빠져서 두 문장이 이어졌어요 오류 줄과 바로 윗줄 끝을 확인해요 (2장)
글자 뒤쪽이 모두 초록색이에요 작은따옴표 짝이 안 맞아요 여는 '와 닫는 '를 맞춰요
… is unknown이 나와요 변수·Table 이름 오타, 또는 쓰기 전에 만들지 않았어요 이름을 확인하고, DATA가 위에 있는지 봐요
괄호 근처에서 오류가 나요 display()처럼 괄호 안쪽을 붙여 썼어요 display( )처럼 한 칸씩 띄워요 (11장)
gs_book - title에서 오류가 나요 Structure의 하이픈 앞뒤를 띄웠어요 gs_book-title처럼 붙여요 (8장)
ENDSELECT가 없다고 해요 여러 줄을 담으면서 INTO TABLE이 아니라 INTO를 썼어요 INTO TABLE gt_…로 고쳐요 (9장)
이름을 넣었더니 Access Key를 물어요 이름이 Y나 Z로 시작하지 않아요 취소하고 Y로 시작하는 이름으로 다시 만들어요 (0장)
저장할 때 Transport Request를 물어요 Package를 골랐어요 연습용은 Local Object를 눌러요 (1장)

실행했는데 이상할 때

이럴 때 원인 이렇게 고쳐요
고친 내용이 반영이 안 돼요 저장만 하고 활성화를 안 했어요 Ctrl+F3
입력 칸 이름이 PA_NUM처럼 나와요 Selection Text를 안 넣었거나 활성화를 안 했어요 Text Elements도 활성화해요 (5장)
결과가 하나도 안 나와요 WHERE 조건이 틀렸거나 Table에 데이터가 없어요 디버거로 Internal Table을 보고, SE16N으로 데이터를 확인해요
두 번째 줄에 첫 줄 값이 남아 있어요 Work Area를 CLEAR하지 않았어요 새로 채우기 전에 CLEAR gs_…. (8장)
LOOP 안에서 고쳤는데 표가 그대로예요 Work Area만 바꾸고 MODIFY를 안 했어요 MODIFY gt_… FROM gs_… INDEX sy-tabix. (8장)
ALV에 컬럼 제목이 비어 있어요 Data Element 없이 만든 칸이에요 Table 칸을 참조하거나 set_short_text 등으로 제목을 붙여요 (11장)

실행 중에 멈췄을 때: 덤프와 ST22

실행 중에 처리할 수 없는 문제가 생기면 프로그램이 멈추고 Runtime Error 화면이 나와요. 이것을 흔히 덤프라고 해요. 겁먹지 말고 화면 위쪽의 오류 이름과 "Source Code Extract"(멈춘 줄)를 먼저 봐요. 나중에 다시 보려면 ST22에서 날짜와 내 ID로 찾을 수 있어요.

오류 이름 무슨 일이에요? 자주 하는 원인
COMPUTE_INT_ZERODIVIDE, BCD_ZERODIVIDE 0으로 나눴어요 나누는 값이 0인지 먼저 IF로 확인하지 않았어요
CONVT_NO_NUMBER 숫자로 바꿀 수 없는 글자를 숫자에 넣었어요 '12a' 같은 값을 TYPE i 변수에 넣었어요
…_OVERFLOW 값이 Type에 비해 너무 커요 TYPE p LENGTH 3처럼 작은 칸에 큰 수를 넣었어요
CALL_FUNCTION_NOT_FOUND Function Module을 못 찾았어요 이름 오타, 소문자로 적음, 활성화 안 함 (10장)
RAISE_EXCEPTION Function Module의 예외를 받을 곳이 없어요 CALL FUNCTION에서 EXCEPTIONS를 지웠어요 (10장)
UNCAUGHT_EXCEPTION 클래스 예외를 CATCH하지 않았어요 TRY … CATCH 없이 get_column( ) 등을 불렀어요 (11장)

D. 옛 문법과 새 문법 대응표

이 교재는 회사 프로그램에서 가장 많이 보는 옛(Classic) 문법으로 배웠어요. 요즘 코드에서는 오른쪽 모양도 자주 보이니, 보면 "아, 그거구나" 할 정도로만 알아 두세요. 수업 시스템의 버전에 따라 쓸 수 없는 것도 있어요.

하는 일 옛 문법 (이 교재) 새 문법
1 더하기 gv_cnt = gv_cnt + 1. gv_cnt += 1.
Work Area 선언 DATA gs_book TYPE … 후 LOOP AT gt_book INTO gs_book. LOOP AT gt_book INTO DATA(ls_book).
DB 읽기 SELECT * FROM yg##_book INTO TABLE gt_book WHERE genre = pa_genre. SELECT * FROM yg##_book WHERE genre = @pa_genre INTO TABLE @DATA(lt_book).
한 줄 찾기 READ TABLE gt_book INTO gs_book WITH KEY book_id = 'B0001'. gs_book = gt_book[ book_id = 'B0001' ]. (없으면 예외)
줄 수 DESCRIBE TABLE gt_book LINES gv_lines. gv_lines = lines( gt_book ).
글자 잇기 CONCATENATE gv_a gv_b INTO gv_c SEPARATED BY space. gv_c = |{ gv_a } { gv_b }|.
여러 줄 넣기 APPEND를 여러 번 gt_book = VALUE #( ( … ) ( … ) ).
같은 이름 칸 옮기기 MOVE-CORRESPONDING gs_a TO gs_b. gs_b = CORRESPONDING #( gs_a ).
조건으로 값 고르기 IF … gv_s = '품절'. ELSE. … ENDIF. gv_s = COND #( WHEN gv_stock = 0 THEN '품절' ELSE '있음' ).
값에 따라 고르기 CASE … WHEN … ENDCASE. gv_t = SWITCH #( gv_genre WHEN 'N' THEN '소설' WHEN 'I' THEN 'IT' ).
코드 나누기 FORM / PERFORM 클래스의 METHOD
실패 알리기 EXCEPTIONS + sy-subrc 예외 클래스 + TRY … CATCH

F. 다음에 배울 것

이 교재는 SAP GUI에서 쓰는 Classic ABAP까지 다뤘어요. 요즘 SAP 개발은 여기서 몇 걸음 더 나아가요. 지금 다 알 필요는 없고, 이름만 눈에 익혀 두세요.

이름 한 줄 설명
ADT (ABAP Development Tools) Eclipse에서 ABAP을 개발하는 도구. SE38 대신 쓰는 편집기라고 생각하면 돼요
CDS View DB 데이터를 원하는 모양으로 미리 정의해 두는 "똑똑한 View". 7장 Dictionary와 9장 SQL의 다음 단계예요
새 ABAP 문법 부록 D의 오른쪽 문법들. 인라인 선언, 문자열 템플릿, VALUE, COND 등
ABAP 객체지향 클래스, 객체, Method, 예외 클래스. 10장 맛보기의 본편이에요
RAP (RESTful Application Programming Model) CDS View와 클래스로 Fiori 앱의 뒷단(OData 서비스)을 만드는 방법
ABAP Cloud 클라우드에서도 쓸 수 있도록 정해진 규칙 안에서 개발하는 방식
