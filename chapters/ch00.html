0-1. 이 교재로 배우는 것

ABAP은 SAP 시스템 안에서 돌아가는 프로그래밍 언어예요. 처음엔 낯선 화면과 용어가 많아서 길을 잃기 쉬운데요, 사실 우리가 만들 프로그램은 대부분 아래 다섯 칸짜리 흐름 하나로 설명할 수 있어요.

사용자가 조건을 넣으면, 프로그램이 DB에서 데이터를 읽어 메모리에 담고, 필요한 계산을 한 뒤 화면에 보여 줘요. 장이 하나 끝날 때마다 이 흐름의 한 칸이 채워진다고 생각하면 돼요. 마지막 12장에서는 다섯 칸을 모두 이어서 "도서 조회 프로그램"을 하나 완성할 거예요.

장 제목 한 줄 소개
1 SAP 시스템과 SAP GUI 첫걸음 로그인하고, 화면을 둘러보고, 트랜잭션 코드로 이동해요
2 첫 프로그램 만들기 SE38에서 만들고 → 검사하고 → 활성화하고 → 실행해요
3 데이터와 Type 숫자·문자열·날짜를 담는 변수를 만들어요
4 조건문과 반복문 IF로 판단하고 DO로 반복해요
5 Selection Screen으로 입력 받기 실행 전에 값을 입력받고, 잘못된 값을 막아요
6 디버거 기초 프로그램을 한 줄씩 멈춰 가며 들여다봐요
7 ABAP Dictionary Domain → Data Element → Table을 만들어요
8 Structure와 Internal Table 여러 줄 데이터를 메모리에 담아 다뤄요
9 Open SQL DB Table을 읽고, 쓰고, 고치고, 지워요
10 모듈화 코드를 FORM · Function Module · Method로 나눠요
11 ALV로 결과 보기 결과를 정렬·필터가 되는 표로 보여 줘요
12 종합 실습 도서 조회 프로그램을 처음부터 끝까지 만들어요
순서가 왜 이래요?

수업에서는 Dictionary를 먼저 해 봤지만, 이 교재는 혼자 다시 볼 때 가장 덜 막히는 순서로 짰어요. 화면에 글자 한 줄 띄우는 것(2장)부터 시작해서, 변수(3장) → 판단과 반복(4장) → 입력(5장)처럼 한 장에 새 개념이 조금씩만 늘어나요. Dictionary는 "데이터를 저장할 곳"이 필요해지는 7장에서 다시 자세히 다뤄요.

코드와 그림 읽는 법

  • 코드는 모두 이런 글꼴로 보여요: WRITE 'Hello ABAP'.
  • 코드 상자 오른쪽 위의 복사 버튼을 누르면 코드를 그대로 복사할 수 있어요.
  • 코드 안의 G## 처럼 노란색으로 칠한 부분은 내 번호로 바꿔야 하는 곳이에요. 예를 들어 5번 학생이면 G## → G05가 돼요.
  • SAP GUI 화면은 설명 그림으로 그렸어요. 실제 화면과 색이나 버튼 배치가 조금 다를 수 있어요. 그림 안의 1 같은 번호는 본문 설명의 번호와 짝이에요.
  • 키보드 단축키는 Ctrl+F2 처럼 보여 줘요.

0-3. 실습 이름 규칙

SAP 시스템은 여러 사람이 함께 쓰는 하나의 큰 건물이에요. 그래서 이름이 겹치지 않게 규칙을 정해 두고 써요. 이 교재의 실습은 아래 규칙을 따라요.

무엇 규칙 예시 (5번 학생)
연습 프로그램(Local Object) YG##_장번호_이름 YG05_02_HELLO
Selection Screen 입력칸 PA_ + 이름 PA_NUM
전역 변수 GV_ + 이름 GV_RESULT
전역 Structure 변수 GS_ + 이름 GS_BOOK
전역 Internal Table GT_ + 이름 GT_BOOK
왜 Z나 Y로 시작해요?

SAP가 만든 프로그램과 이름이 겹치지 않도록, 고객(우리)이 만드는 객체는 Z 또는 Y로 시작해야 해요. 그 밖의 이름(예: ABC_TEST)은 SAP가 쓰는 자리라서, 만들려고 하면 등록 키(Access Key)를 물어보며 막혀요.

둘 중 무엇을 쓸지는 이렇게 나눠 기억하면 편해요. Package에 담아 다른 시스템으로 옮길 객체는 Z, 혼자 연습하는 Local Object는 Y로 시작해요. 그래서 이 교재의 연습 프로그램은 모두 YG##_...이에요. 1장 1-6에서 그림으로 다시 볼게요.

0-4. 막혔을 때

  1. 상태 표시줄(화면 맨 아래)을 먼저 보세요. SAP는 오류나 안내를 거의 다 거기에 보여 줘요.
  2. F1 도움말을 써 보세요. 코드에서 궁금한 단어(예: WRITE)에 커서를 놓고 F1을 누르면 설명서가 열려요.
  3. 질문할 땐 캡처를 같이 보내 주세요. 코드 화면과 오류 메시지가 함께 보이게 캡처하면 훨씬 빨리 답을 받을 수 있어요.
정리
  • 우리가 만들 프로그램은 대부분 "입력 → DB 읽기 → 메모리에 담기 → 계산 → 보여 주기" 흐름이에요.
  • 상자 색으로 지금 하는 일을 구분해요. 노란색 G## 는 내 번호로 바꾸는 곳이에요.
  • 내가 만드는 객체 이름은 Z 또는 Y로 시작해요. Package에 담을 객체는 Z, 연습용 Local Object는 Y예요.
