2장

첫 프로그램 만들기

이번 장 목표
  • SE38에서 프로그램을 만들고, 저장하고, 실행하는 순서를 처음부터 끝까지 해 봐요.
  • 새로 만들기 카드만 보고도 프로그램을 만들 수 있어요.
  • 저장과 활성화가 어떻게 다른지 알아요.
  • ABAP 문장의 기본 규칙(마침표, 주석, 체인 문장)을 익혀요.
  • 문법 오류가 났을 때 메시지를 읽고 고칠 수 있어요.
  • 만든 프로그램을 다시 열 수 있고, 복사하고 지우는 방법을 알아요.

2-1. 전체 순서 미리 보기

처음엔 단계가 많아 보이지만, 앞으로 만들 모든 프로그램이 이 순서를 그대로 따라요. 몇 번 하다 보면 손이 먼저 움직일 거예요.

2-2. 따라 하기: Hello ABAP

화면에 글자 두 줄을 출력하는 프로그램을 만들어 볼게요. 이번에 만들 것은 아래 카드와 같아요.

새로 만들기ProgramSE38
Program
YG##_101
Title
[예제] 나의 첫 ABAP 프로그램

이 새로 만들기 카드(0-2)는 "SE38에서 Program을 하나 만들어요. 이름은 YG##_101이고, Title은 적힌 글자 그대로예요"라는 뜻이에요. 카드의 값을 어느 화면에 넣는지 일곱 단계로 따라가 봐요.

단계 1. SE38에서 이름 정하기

직접 해 보기
  1. 명령 필드에 /nSE38을 입력하고 Enter를 눌러요.
  2. Program 칸에 카드의 이름 YG##_101을 입력해요. G 뒤의 두 자리는 내 번호예요(0-2). 5번 학생이면 YG05_101이에요. 1
  3. Create 버튼을 눌러요. 2
이미 있는 프로그램이라면?

같은 이름의 프로그램이 이미 있으면 Create 대신 Change(고치기)나 Display(보기만)를 눌러요. 만든 프로그램을 다시 여는 방법은 2-8에서 자세히 봐요.

단계 2. 프로그램 속성 정하기

Program Attributes 창이 떠요. 프로그램의 이름표를 붙이는 단계예요.

직접 해 보기
  1. Title에 카드의 Title [예제] 나의 첫 ABAP 프로그램을 글자 그대로 입력해요. 대괄호와 띄어쓰기까지 똑같이요. 1
  2. Type이 Executable program인지 확인해요. 비어 있거나 다른 값이면 목록에서 골라요. 바로 실행할 수 있는 프로그램이라는 뜻이에요. 2
  3. 나머지는 그대로 두고 Save를 눌러요. 3

Title은 프로그램의 제목이에요. 실행 결과 화면 맨 위에 나오고(그림 2-7), 나중에 내 프로그램 목록에서 찾을 때도 이름 옆에 보여요(2-8). 이름이 번호뿐이라서 Title이 이름표 노릇을 해요. 그래서 카드에 적힌 글자 그대로 넣어요.

자주 하는 실수

Fixed point arithmetic의 체크는 풀지 마세요. 이 체크가 풀리면 소수점이 있는 계산 결과가 엉뚱하게 나와요. 처음 상태(체크됨) 그대로 두면 돼요.

단계 3. 저장 위치 정하기: Local Object

이어서 Create Object Directory Entry 창이 떠요. "어느 Package에 넣을까요?"라고 묻는 창이에요(1-6). 연습용이니 Package 칸은 비워 둔 채로 Local Object 버튼을 눌러요. 1

단계 4. 코드 쓰고 저장하기

드디어 ABAP Editor 화면이에요. 편집기에는 *로 시작하는 설명 줄 몇 개와 REPORT yg##_101. 한 줄이 이미 들어 있어요. SAP가 넣어 준 줄이에요. REPORT 줄은 다시 쓰지 말고, 그 아래에 나머지를 이어서 써요. 다 쓴 모습이 아래와 같으면 돼요.

REPORT yg##_101.

START-OF-SELECTION.
  WRITE 'Hello ABAP'.
  WRITE / '안녕하세요, ABAP!'.

다 썼으면 Ctrl+S로 저장해요.

이미 들어 있는 줄은 어떻게 해요?
  • *로 시작하는 줄은 사람이 읽는 메모예요(2-5에서 배워요). 그대로 둬도 돼요. 교재의 코드와 그림은 이 줄들을 빼고 REPORT 줄부터 보여 줘요. 그래서 내 화면의 줄 번호가 교재보다 몇 줄 커도 괜찮아요.
  • REPORT 뒤의 이름이 대문자로 들어 있어도 괜찮아요. 같은 뜻이에요.
  • 웹 교재의 복사 버튼으로 코드를 가져올 때는 편집기 내용을 전부 고르고(Ctrl+A) 그 위에 붙여 넣어요(Ctrl+V). REPORT 줄이 두 번 들어가면 오류가 나요. 그래도 첫 프로그램은 손으로 직접 쳐 보세요.
번호 버튼 단축키 하는 일
1 검사(Check) Ctrl+F2 문법이 맞는지 검사해요
2 활성화(Activate) Ctrl+F3 저장한 코드를 "정식 버전"으로 만들어요
3 실행(Direct Processing) F8 프로그램을 실행해요
4 Pretty Printer Shift+F1 들여쓰기와 대소문자를 보기 좋게 정리해요

단계 5. 문법 검사하기

Ctrl+F2를 눌러요. 상태 표시줄에 문법이 맞다는 초록색 메시지가 나오면 통과예요. 빨간 오류가 나오면 2-6을 보고 고쳐요.

단계 6. 활성화하기

Ctrl+F3을 눌러요. 활성화할 객체 목록 창이 뜨면 내 프로그램이 선택되어 있는지 보고 Enter(✓)를 눌러요. 코드 위쪽 프로그램 이름 옆의 Inactive 글자가 Active로 바뀌면 끝이에요.

단계 7. 실행하기

F8을 누르면 결과 화면이 나와요. 이렇게 나오면 첫 프로그램 완성이에요!

결과 화면 맨 위의 제목 줄과 가로선은 SAP가 자동으로 붙여 줘요. 단계 2에서 적은 Title이 여기에 나오고, 오른쪽 숫자는 쪽 번호예요. F3을 누르면 코드 화면으로 돌아가요.

앞으로는 카드만 보고 만들어요

여기까지가 프로그램 하나를 만드는 순서예요. 앞으로 새 프로그램이 나올 때는 화면 그림 없이 새로 만들기 카드만 보여 줄게요. 만드는 방법은 늘 같아요.

순서 할 일 카드에서 볼 곳
1 /nSE38 → Program 칸에 이름 → Create 맨 윗줄의 SE38, Program 줄
2 Title 입력, Type은 Executable program → Save Title 줄 (글자 그대로)
3 Local Object 카드에 없어요 (늘 같아요)
4 코드 쓰기(이미 있는 REPORT 줄은 다시 쓰지 않아요) → 저장 → 검사 → 활성화 → 실행 카드 바로 아래의 코드

Type(Executable program)과 저장 위치(Local Object)는 늘 같아서 카드에 적지 않아요. 카드에 줄이 더 붙을 때도 있어요. 그런 카드는 2-9에서 처음 만나요.

2-3. 저장과 활성화는 달라요

여기가 처음 배울 때 가장 많이 헷갈리는 부분이에요. 저장은 "초안 저장", 활성화는 "정식 발행"이라고 생각하면 쉬워요.

지금 어느 쪽인지는 편집기에서 바로 보여요. 코드 바로 위, 프로그램 이름 옆에 Inactive라고 적혀 있으면 아직 초안이에요. Active면 정식 버전이에요(그림 2-5).

자주 하는 실수
  • 코드를 고치고 저장만 하고 활성화를 잊는 경우가 정말 많아요. 고친 뒤엔 습관처럼 Ctrl+F3까지 눌러 주세요.
  • 편집기에서 내가 직접 F8을 누르면 활성화하지 않은 초안도 실행돼요. 그래서 "잘 되네" 하고 넘어가기 쉬워요. 다른 사람이 실행할 때는 활성화된 버전만 돌아요.
  • 문법 오류가 남은 채로 활성화하면 오류를 보여 주면서 그래도 활성화할지 묻는 창이 떠요. 그대로 활성화하지 말고 취소한 다음, Ctrl+F2로 오류를 찾아 먼저 고쳐요.

2-4. 첫 코드 뜯어보기

방금 쓴 코드를 한 줄씩 볼게요.

REPORT yg##_101.               " ① 프로그램의 첫 문장

START-OF-SELECTION.            " ② 실행하면 여기서부터 시작
  WRITE 'Hello ABAP'.          " ③ 화면에 글자 출력
  WRITE / '안녕하세요, ABAP!'.  " ④ 줄을 바꾸고 출력
번호 코드 뜻
① REPORT 이름. "이건 실행할 수 있는 프로그램이에요"라고 알리는 첫 문장이에요. * 메모 줄을 빼면 맨 앞에 와요. 프로그램을 만들면 자동으로 들어가요.
② START-OF-SELECTION. F8을 누르면 이 줄 아래부터 실행돼요. 왜 이런 줄이 필요한지는 5장에서 자세히 알아봐요. 지금은 "시작 표시"라고만 기억해요.
③ WRITE '글자'. 작은따옴표 안의 글자를 화면에 출력해요.
④ WRITE / '글자'. /는 줄 바꿈이에요. 새 줄로 내려가서 출력해요.
들여쓰기는 왜 해요?

WRITE 앞의 공백 두 칸은 없어도 실행돼요. 하지만 "이 줄들은 START-OF-SELECTION 아래에 속해요"라는 것이 한눈에 보이도록 들여 써요. 직접 맞추기 귀찮을 때는 Shift+F1(Pretty Printer)을 눌러요. 알아서 정리해 줘요.

직접 해 보기 · Pretty Printer 한 번 설정해 두기
  1. ABAP Editor 메뉴에서 Utilities → Settings로 들어가요.
  2. ABAP Editor 탭 안에 있는 Pretty Printer 탭을 눌러요.
  3. Indent와 Convert Uppercase/Lowercase를 체크하고, 그 아래에서 Keyword Uppercase를 골라요. "들여쓰기를 맞추고, WRITE 같은 키워드(ABAP이 미리 정해 둔 낱말)는 대문자로, 나머지는 소문자로 바꿔 줘요"라는 뜻이에요.
  4. Enter(✓)를 눌러 창을 닫아요.
  5. 코드의 WRITE 하나를 소문자 write로 바꿔요(소문자로 써도 오류는 아니에요. 2-5에서 배워요). 그다음 Shift+F1을 눌러요. 다시 WRITE로 바뀌면 설정이 된 거예요. 코드를 건드렸으니 저장하고 활성화해 둬요.

이 설정은 내 계정에 저장돼요. 한 번만 하면 돼요. 안 해 두면 Shift+F1을 눌러도 교재처럼 대문자로 바뀌지 않을 수 있어요.

2-5. ABAP 문장의 다섯 가지 규칙

규칙 1. 문장은 마침표(.)로 끝나요

ABAP은 줄이 아니라 마침표로 문장을 나눠요. 그래서 한 문장을 여러 줄에 걸쳐 써도 되고, 마침표를 빠뜨리면 오류가 나요.

WRITE
  'Hello ABAP'.      " 두 줄이지만 마침표가 하나니까 한 문장이에요

규칙 2. 대소문자를 구분하지 않아요

WRITE, write, Write는 모두 같아요. 단, 작은따옴표 안의 글자는 쓴 그대로 출력돼요. 보통 키워드는 대문자, 이름은 소문자로 써서 구분하기 쉽게 해요. 2-4에서 설정해 둔 Pretty Printer가 이렇게 맞춰 줘요.

규칙 3. 단어 사이는 한 칸 이상 띄워요

WRITE'Hello'.처럼 붙여 쓰지 말고, 키워드와 값 사이는 꼭 한 칸 이상 띄어 써요. 붙여 쓰면 읽기 어렵고, 나중에 배울 괄호 같은 곳에서는 바로 오류가 나요.

규칙 4. 주석은 *와 " 두 가지예요

주석은 프로그램이 무시하는, 사람을 위한 메모예요. 1주차 과제에서도 강조했듯이 주석은 "나중의 나"와 "코드를 읽는 동료"를 위한 친절이에요.

* 줄 맨 앞(첫 칸)에 별표를 쓰면 그 줄 전체가 주석이에요
WRITE 'Hello ABAP'.   " 큰따옴표부터 줄 끝까지가 주석이에요
기호 위치 범위
* 줄의 맨 첫 칸 그 줄 전체
" 줄 어디든 그 자리부터 줄 끝까지

단계 4에서 본, 편집기에 처음부터 들어 있던 * 줄들이 바로 주석이에요.

단축키로 주석 달기

여러 줄을 선택하고 Ctrl+,(또는 Ctrl+<)를 누르면 한꺼번에 주석이 되고, Ctrl+.(또는 Ctrl+>)를 누르면 주석이 풀려요. 코드를 잠깐 꺼 두고 싶을 때 편해요.

규칙 5. 같은 키워드가 반복되면 체인 문장으로 묶어요

같은 키워드로 시작하는 문장이 여러 개면, 키워드 뒤에 콜론(:)을 붙이고 나머지를 쉼표(,)로 이어 쓸 수 있어요. 마지막에만 마침표를 찍어요.

" 따로 쓴 경우
WRITE 'Hello ABAP'.
WRITE / '안녕하세요'.
WRITE / '반가워요'.
" 체인 문장으로 묶은 경우
WRITE: 'Hello ABAP',
       / '안녕하세요',
       / '반가워요'.

두 코드의 결과는 똑같아요. 체인 문장은 앞으로 변수를 여러 개 만들 때(3장) 아주 자주 쓰니 지금 눈에 익혀 두세요.

2-6. 오류를 일부러 만나 보기

오류 메시지는 무서운 게 아니라 "여기를 고치세요"라는 안내문이에요. YG##_101에서 일부러 한 번 틀려 볼게요.

직접 해 보기
  1. 코드 마지막 줄 WRITE / '안녕하세요, ABAP!'.의 마침표를 지워요.
  2. Ctrl+F2로 검사해요.
  3. 화면 아래쪽에 오류 목록이 나와요. 줄 번호와 메시지를 확인해요. 줄 번호는 내 코드의 마지막 줄 번호예요. 그림의 숫자와 달라도 괜찮아요.
  4. 오류 줄을 더블클릭하면 그 줄로 커서가 이동해요. 마침표를 다시 넣고 검사해서 통과하는지 확인해요. 통과하면 저장하고 활성화해 둬요.

메시지를 우리말로 옮기면 "마지막 문장이 끝나지 않았어요(마침표가 없어요)"예요. 영어 메시지라도 Line(줄 번호)과 핵심 단어(period, unknown, expected)만 봐도 대부분 원인을 찾을 수 있어요.

증상 원인 고치는 법
period missing 오류 문장 끝 마침표 빠짐 마침표 넣기
글자가 이상하게 이어짐, 따옴표 오류 작은따옴표 짝이 안 맞음 '...' 짝 확인
WRITE "Hello".처럼 썼더니 오류 글자를 큰따옴표로 쌈 (ABAP에서 "는 주석의 시작이에요) 작은따옴표 'Hello'로 바꾸기
코드를 붙여 넣은 뒤 REPORT 줄에서 오류 REPORT 줄이 두 번 들어감 (2-2) 한 줄만 남기기

이름에 ##가 글자 그대로 들어감 내 번호로 바꾸지 않고 만듦 2-8의 Rename으로 YG05_101처럼 고치기

2-7. 한 걸음 더: Text Symbol

지금까지는 출력할 글자를 코드 안에 직접 썼어요. 그런데 회사에서는 같은 프로그램을 한국어와 영어로 함께 쓰는 경우가 많아요. 그래서 글자를 코드 밖 Text Symbol에 따로 모아 두는 습관을 들여요. 1주차 과제에서 써 본 TEXT-001이 바로 이거예요. 방금 만든 YG##_101에 이어서 해 봐요.

직접 해 보기
  1. ABAP Editor 메뉴에서 Goto → Text Elements로 들어가요. 아래에 메뉴가 더 나오면 Text Symbols를 골라요.
  2. Text Symbols 탭에서 Sym 칸에 001, Text 칸에 Hello ABAP을 입력해요.
  3. 이 화면에서도 저장 후 활성화(Ctrl+F3)를 해요. F3으로 코드 화면에 돌아와요.
  4. 첫 번째 WRITE 줄의 'Hello ABAP'을 TEXT-001로 바꿔요(아래 코드). TEXT- 뒤에 Sym 칸의 번호를 붙여 쓰고, 따옴표는 붙이지 않아요. 활성화한 뒤 실행해서 결과가 그림 2-7과 같은지 확인해요.
REPORT yg##_101.

START-OF-SELECTION.
  WRITE TEXT-001.               " Text Symbol 001의 글자를 출력해요
  WRITE / '안녕하세요, ABAP!'.
자주 하는 실수
  • Text Symbol은 따로 활성화해야 해요. 프로그램만 활성화하고 Text Symbol을 활성화하지 않으면 실행했을 때 그 자리가 비어서 나와요.
  • Text Symbol과 Title은 로그인한 언어마다 따로 저장돼요. 다른 언어로 로그인하면 비어 보일 수 있으니 늘 같은 언어로 로그인해요(1-3).

2-8. 만든 프로그램 다시 열기 · 고치기 · 복사 · 지우기

한번 만든 프로그램은 SAP GUI를 꺼도 시스템에 남아 있어요. 다시 꺼내 고치는 일, 복사하는 일, 잘못 만든 것을 지우는 일은 모두 SE38 첫 화면에서 해요.

다시 열기

직접 해 보기
  1. /nSE38로 가서 Program 칸에 YG##*를 입력하고 F4를 눌러요. 1 *는 "뒤에 무엇이 오든"이라는 뜻이에요. F4는 SAP 어느 화면에서나 그 칸에 넣을 수 있는 값의 목록을 보여 주는 키라서 앞으로도 자주 써요.
  2. YG##로 시작하는 내 프로그램 목록이 나와요. 조건을 묻는 창이 먼저 뜨면 그대로 Enter를 눌러요. 프로그램이 아직 하나뿐이면 목록 없이 Program 칸에 이름이 바로 채워질 수도 있어요. 그러면 4번으로 가요.
  3. 목록에서 YG##_101을 더블클릭해요. Program 칸에 이름이 들어가요.
  4. Change(고치기)나 Display(보기만)를 눌러요. 2 실행만 할 거면 F8을 눌러도 돼요.

목록에서 이름 옆에 보이는 글자가 내가 넣은 Title이에요. 그림에서는 Short Description 칸이에요. 지금은 프로그램이 하나뿐이지만 늘어나면 그림 2-11의 아래쪽처럼 돼요. 2-2에서 Title을 글자 그대로 넣어 둔 덕분에 번호뿐인 이름도 쉽게 고를 수 있어요.

이름을 외우고 있으면 Program 칸에 바로 적고 Change를 눌러도 돼요. Display로 열면 글자가 쳐지지 않아요. 고치고 싶으면 Ctrl+F1(Display ↔ Change. 그림 2-5 맨 왼쪽의 "표시↔변경" 버튼)을 눌러요.

Title 고치기

Title을 잘못 넣었다면 프로그램을 Change로 연 다음, 편집기 메뉴 Goto → Attributes로 Program Attributes 창(그림 2-3)을 다시 열어요. Title을 고치고 Save를 누른 뒤 활성화해요. 버전에 따라 Attributes 대신 Properties라고 적혀 있기도 해요. 같은 것이에요.

복사 · 이름 바꾸기 · 지우기

SE38 첫 화면의 Program 칸에 원래 프로그램의 이름을 적고, 화면별 도구 모음에서 버튼을 눌러요(그림 2-11의 3). 실제 화면에서는 글자 없는 아이콘이에요. 마우스를 올리면 이름이 보여요.

버튼 하는 일 누른 뒤
Copy 같은 내용의 프로그램을 새 이름으로 하나 더 만들어요 새 이름 입력 → 같이 복사할 것을 묻는 창에서 Text elements에 체크(Text Symbol이 여기에 들어 있어요) → Local Object
Rename 프로그램의 이름을 바꿔요 새 이름 입력 (저장 위치를 물으면 Local Object)
Delete 프로그램을 지워요 이름을 한 번 더 확인하고 지우기
복사하거나 이름을 바꾼 뒤에는
  • 새 이름의 프로그램을 Change로 열어 REPORT 줄에 적힌 이름을 봐요. 새 이름으로 바뀌어 있으면 그대로 두고, 옛 이름 그대로면 직접 고쳐요.
  • 복사한 프로그램은 Title도 원본과 같아요. 위의 방법으로 Title을 고쳐요.
  • 마지막으로 활성화해요. Text Symbol이 있으면 Text Symbol도 활성화해요(2-7).

이름에 ##를 글자 그대로 넣었거나 번호를 틀리게 넣어 만든 프로그램은 Rename으로 바로잡아요. Delete로 지우고 다시 만들어도 돼요. 단, Rename과 Delete는 내가 만든 프로그램에만 써요. 열어 봤을 때 내가 쓴 적 없는 코드가 들어 있으면 친구의 프로그램이에요. 그대로 두고 이름의 번호부터 확인해요(0-3). 지운 프로그램은 되살릴 수 없어요.

그 프로그램을 다른 창에서 Change로 열어 두었다면 먼저 닫아요. 열려 있으면 이름을 바꾸거나 지울 수 없어요. 버튼의 위치와 창의 모양은 버전에 따라 조금 달라요. 버튼을 못 찾겠으면 메뉴 Program 안에서 같은 이름을 찾아봐요.

2-9. 미니 실습: 자기소개 프로그램

이번에는 카드만 보고 처음부터 혼자 만들어 봐요. 순서가 기억나지 않으면 2-2의 "앞으로는 카드만 보고 만들어요"를 다시 봐요.

새로 만들기ProgramSE38
Program
YG##_102
Title
[실습] 자기소개
Text Symbol
001 = CODE 2기 자기소개

이번 카드에는 Text Symbol 줄이 하나 더 있어요. 001 = CODE 2기 자기소개는 "Text Symbol 001을 만들고, Text 칸에 CODE 2기 자기소개를 넣어요"라는 뜻이에요. 만드는 방법은 2-7과 같아요. 앞으로도 카드에 이런 줄이 있으면 같은 방법으로 만들어요.

직접 해 보기

프로그램 YG##_102를 새로 만들어서 아래 결과가 나오게 해 보세요.

  • 이름과 Title은 카드에 적힌 그대로 넣어요.
  • WRITE는 체인 문장 한 개로 써요.
  • 맨 위에 * 주석으로 "작성자, 작성일"을 남겨요.
  • 첫 줄의 CODE 2기 자기소개는 Text Symbol 001로 출력해요(2-7). Text Symbol도 활성화해야 글자가 나와요.
  • 이름, 반, 한마디는 내 이야기로 바꿔 써요.
예시 답안 보기
*&---------------------------------------------------------------------*
* 작성자: 홍길동
* 작성일: 2026-11-17
* 설명  : 체인 문장과 Text Symbol 연습
*&---------------------------------------------------------------------*
REPORT yg##_102.

START-OF-SELECTION.
  WRITE: TEXT-001,                       " Text Symbol 001: CODE 2기 자기소개
         / '이름: 홍길동',
         / '반: CODE 2기 부산반',
         / '한마디: ABAP 잘해 보고 싶어요!'.

첫 줄이 비어서 나오면 Text Symbol 001을 만들고 활성화했는지 확인해요(2-7). 첫 줄이 중간에 끊기고 끝에 >가 보이면 글자 칸이 모자란 거예요. Text Symbols 화면에서 001 줄의 mLen을 30으로 늘리고 다시 활성화해요.

확인 문제
  1. 코드를 고치고 저장만 했어요. 다른 친구가 내 프로그램을 실행하면 고친 내용이 보일까요?
  2. 아래 코드에서 틀린 곳 두 군데를 찾아보세요. 
    START-OF-SELECTION.
  WRITE 'Hello'
  WRITE / 'ABAP".
  3. *로 시작하는 주석과 "로 시작하는 주석은 어떻게 다를까요?
  4. 아래 세 줄을 체인 문장 하나로 바꿔 보세요. 
    WRITE 'A'.
WRITE / 'B'.
WRITE / 'C'.
  5. 새로 만들기 카드에는 Type과 저장 위치가 적혀 있지 않아요. 무엇으로 하면 될까요?
  6. 지난주에 만든 프로그램의 이름이 기억나지 않아요. SE38에서 어떻게 찾을까요?
정답 보기
  1. 안 보여요. 저장만 한 것은 Inactive(초안)라서, 다른 사람은 활성화된 옛 버전을 실행해요. Ctrl+F3으로 활성화해야 해요.
  2. ① WRITE 'Hello' 끝에 마침표가 없어요. ② 'ABAP"는 작은따옴표로 열고 큰따옴표로 닫아서 따옴표 짝이 안 맞아요. 작은따옴표로 열었으면 작은따옴표로 닫아야 해요. 'ABAP'으로 고쳐요.
  3. *는 줄 맨 첫 칸에 써서 그 줄 전체를 주석으로 만들고, "는 줄 어디서든 쓸 수 있고 그 자리부터 줄 끝까지 주석이에요.
  4. WRITE: 'A',
       / 'B',
       / 'C'.
  5. Type은 Executable program, 저장 위치는 Local Object예요. 늘 같아서 카드에 적지 않아요.
  6. SE38 첫 화면의 Program 칸에 YG##*를 넣고 F4를 눌러요. 내 프로그램 목록에 Title이 같이 나오니 Title을 보고 골라요.
정리
  • 프로그램은 SE38 → 이름 → Create → Title · Type → Save → Local Object → 코드 → 저장 → 검사 → 활성화 → 실행 순서로 만들어요.
  • 앞으로는 새로 만들기 카드만 보고 같은 순서로 만들어요. Title은 카드의 글자 그대로 넣고, Text Symbol 줄이 있으면 2-7처럼 만들어요.
  • 저장은 초안(Inactive), 활성화는 정식 버전(Active)이에요. 고친 뒤엔 꼭 활성화해요.
  • ABAP 문장은 마침표로 끝나고, 대소문자를 가리지 않고, 주석은 *와 "로 달아요.
  • 같은 키워드가 반복되면 :과 ,로 묶는 체인 문장을 써요.
  • 출력할 글자는 Text Symbol(TEXT-001)로 빼 두는 습관을 들여요. Text Symbol도 따로 활성화해요.
  • 만든 프로그램은 SE38에서 YG##*와 F4로 찾아요. 복사는 Copy, 이름 바꾸기는 Rename, 지우기는 Delete예요.
