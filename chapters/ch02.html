2장

첫 프로그램 만들기

이번 장 목표
  • SE38에서 프로그램을 만들고, 저장하고, 실행하는 순서를 처음부터 끝까지 해 봐요.
  • 저장과 활성화가 어떻게 다른지 알아요.
  • ABAP 문장의 기본 규칙(마침표, 주석, 체인 문장)을 익혀요.
  • 문법 오류가 났을 때 메시지를 읽고 고칠 수 있어요.

2-1. 전체 순서 미리 보기

처음엔 단계가 많아 보이지만, 앞으로 만들 모든 프로그램이 이 순서를 그대로 따라요. 몇 번 하다 보면 손이 먼저 움직일 거예요.

2-2. 따라 하기: Hello ABAP

단계 1. SE38에서 이름 정하기

직접 해 보기
  1. 명령 필드에 /nSE38을 입력하고 Enter를 눌러요.
  2. Program 칸에 YG##_02_HELLO를 입력해요. ## 자리는 내 번호예요. 1
  3. Create 버튼을 눌러요. 2
이미 있는 프로그램이라면?

같은 이름의 프로그램이 이미 있으면 Create 대신 Change(고치기)나 Display(보기만)를 눌러요.

단계 2. 프로그램 속성 정하기

Program Attributes 창이 떠요. 프로그램의 이름표를 붙이는 단계예요.

직접 해 보기
  1. Title에 나의 첫 ABAP 프로그램처럼 이 프로그램이 무엇인지 적어요. 1
  2. Type이 Executable program인지 확인해요. 2 바로 실행할 수 있는 프로그램이라는 뜻이에요.
  3. 나머지는 그대로 두고 Save를 눌러요. 3
자주 하는 실수

Fixed point arithmetic의 체크는 풀지 마세요. 이 체크가 풀리면 소수점이 있는 계산 결과가 엉뚱하게 나와요. 처음 상태(체크됨) 그대로 두면 돼요.

단계 3. 저장 위치 정하기: Local Object

이어서 Create Object Directory Entry 창이 떠요. "어느 Package에 넣을까요?"라고 묻는 창이에요(1장 1-6). 연습용이니 Local Object 버튼을 눌러요. 1

단계 4. 코드 쓰고 저장하기

드디어 ABAP Editor 화면이에요. 맨 위에 REPORT yg##_02_hello. 한 줄과 설명 주석 몇 줄이 이미 들어 있을 거예요. 그 아래에 코드를 이어서 써요.

REPORT yg##_02_hello.

START-OF-SELECTION.
  WRITE 'Hello ABAP'.
  WRITE / '안녕하세요, ABAP!'.

다 썼으면 Ctrl+S로 저장해요.

번호 버튼 단축키 하는 일
1 검사(Check) Ctrl+F2 문법이 맞는지 검사해요
2 활성화(Activate) Ctrl+F3 저장한 코드를 "정식 버전"으로 만들어요
3 실행(Direct Processing) F8 프로그램을 실행해요
4 Pretty Printer Shift+F1 들여쓰기와 대소문자를 보기 좋게 정리해요

단계 5. 문법 검사하기

Ctrl+F2를 눌러요. 상태 표시줄에 문법이 맞다는 초록색 메시지가 나오면 통과예요. 빨간 오류가 나오면 2-6절을 보고 고쳐요.

단계 6. 활성화하기

Ctrl+F3를 눌러요. 활성화할 객체 목록 창이 뜨면 내 프로그램이 체크되어 있는지 보고 Enter(✓)를 눌러요. 코드 위쪽 프로그램 이름 옆의 Inactive 글자가 Active로 바뀌면 끝이에요.

단계 7. 실행하기

F8을 누르면 결과 화면이 나와요. 이렇게 나오면 첫 프로그램 완성이에요!

결과 화면 맨 위의 제목 줄과 가로선은 SAP가 자동으로 붙여 줘요. 단계 2에서 적은 Title이 여기에 나오고, 오른쪽 숫자는 쪽 번호예요. F3을 누르면 코드 화면으로 돌아가요.

2-3. 저장과 활성화는 달라요

여기가 처음 배울 때 가장 많이 헷갈리는 부분이에요. 저장은 "초안 저장", 활성화는 "정식 발행"이라고 생각하면 쉬워요.

자주 하는 실수
  • 코드를 고치고 저장만 하고 활성화를 잊는 경우가 정말 많아요. 고친 뒤엔 습관처럼 Ctrl+F3까지 눌러 주세요.
  • 활성화는 문법 오류가 하나라도 있으면 실패해요. 활성화가 안 되면 먼저 Ctrl+F2로 오류를 찾아요.

2-4. 첫 코드 뜯어보기

방금 쓴 코드를 한 줄씩 볼게요.

REPORT yg##_02_hello.          " ① 프로그램 이름표

START-OF-SELECTION.            " ② 실행하면 여기서부터 시작
  WRITE 'Hello ABAP'.          " ③ 화면에 글자 출력
  WRITE / '안녕하세요, ABAP!'.  " ④ 줄을 바꾸고 출력
번호 코드 뜻
① REPORT 이름. "이건 실행할 수 있는 프로그램이에요"라는 첫 줄이에요. 프로그램을 만들면 자동으로 들어가요.
② START-OF-SELECTION. F8을 누르면 이 줄 아래부터 실행돼요. 왜 이런 줄이 필요한지는 5장에서 자세히 알아봐요. 지금은 "시작 표시"라고만 기억해요.
③ WRITE '글자'. 작은따옴표 안의 글자를 화면에 출력해요.
④ WRITE / '글자'. /는 줄 바꿈이에요. 새 줄로 내려가서 출력해요.
들여쓰기는 왜 해요?

WRITE 앞의 공백 두 칸은 없어도 실행돼요. 하지만 "이 줄들은 START-OF-SELECTION 아래에 속해요"라는 것이 한눈에 보이도록 들여 써요. 직접 맞추기 귀찮으면 Shift+F1(Pretty Printer)을 누르면 알아서 정리해 줘요.

2-5. ABAP 문장의 다섯 가지 규칙

규칙 1. 문장은 마침표(.)로 끝나요

ABAP은 줄이 아니라 마침표로 문장을 나눠요. 그래서 한 문장을 여러 줄에 걸쳐 써도 되고, 마침표를 빠뜨리면 오류가 나요.

WRITE
  'Hello ABAP'.      " 두 줄이지만 마침표가 하나니까 한 문장이에요

규칙 2. 대소문자를 구분하지 않아요

WRITE, write, Write는 모두 같아요. 단, 작은따옴표 안의 글자는 쓴 그대로 출력돼요. 보통 명령어(키워드)는 대문자, 이름은 소문자로 써서 구분하기 쉽게 해요. Pretty Printer가 이렇게 맞춰 줘요.

규칙 3. 단어 사이는 한 칸 이상 띄워요

WRITE'Hello'.처럼 붙여 쓰지 말고, 키워드와 값 사이는 꼭 한 칸 이상 띄어 써요. 붙여 쓰면 읽기 어렵고, 나중에 배울 괄호 같은 곳에서는 바로 오류가 나요.

규칙 4. 주석은 *와 " 두 가지예요

주석은 프로그램이 무시하는, 사람을 위한 메모예요. 1주차 과제에서도 강조했듯이 주석은 "나중의 나"와 "코드를 읽는 동료"를 위한 친절이에요.

* 줄 맨 앞(첫 칸)에 별표를 쓰면 그 줄 전체가 주석이에요
WRITE 'Hello ABAP'.   " 큰따옴표부터 줄 끝까지가 주석이에요
기호 위치 범위
* 줄의 맨 첫 칸 그 줄 전체
" 줄 어디든 그 자리부터 줄 끝까지
단축키로 주석 달기

여러 줄을 선택하고 Ctrl+,(또는 Ctrl+<)를 누르면 한꺼번에 주석이 되고, Ctrl+.(또는 Ctrl+>)를 누르면 주석이 풀려요. 코드를 잠깐 꺼 두고 싶을 때 편해요.

규칙 5. 같은 명령어가 반복되면 체인 문장으로 묶어요

같은 키워드로 시작하는 문장이 여러 개면, 키워드 뒤에 콜론(:)을 붙이고 나머지를 쉼표(,)로 이어 쓸 수 있어요. 마지막에만 마침표를 찍어요.

" 따로 쓴 경우
WRITE 'Hello ABAP'.
WRITE / '안녕하세요'.
WRITE / '반가워요'.
" 체인 문장으로 묶은 경우
WRITE: 'Hello ABAP',
       / '안녕하세요',
       / '반가워요'.

두 코드의 결과는 똑같아요. 체인 문장은 앞으로 변수를 여러 개 만들 때(3장) 아주 자주 쓰니 지금 눈에 익혀 두세요.

2-6. 오류를 일부러 만나 보기

오류 메시지는 무서운 게 아니라 "여기를 고치세요"라는 안내문이에요. 일부러 한 번 틀려 볼게요.

직접 해 보기
  1. 코드 마지막 줄 WRITE / '안녕하세요, ABAP!'.의 마침표를 지워요.
  2. Ctrl+F2로 검사해요.
  3. 아래처럼 오류 목록이 나와요. 줄 번호와 메시지를 확인해요.
  4. 오류 줄을 두 번 클릭하면 해당 줄로 커서가 이동해요. 마침표를 다시 넣고 검사해서 통과하는지 확인해요.

메시지를 우리말로 옮기면 "마지막 문장이 끝나지 않았어요(마침표가 없어요)"예요. 영어 메시지라도 Line(줄 번호)과 핵심 단어(period, unknown, expected)만 봐도 대부분 원인을 찾을 수 있어요.

자주 하는 실수
증상 원인 고치는 법
period missing 오류 문장 끝 마침표 빠짐 마침표 넣기
글자가 이상하게 이어짐, 따옴표 오류 작은따옴표 짝이 안 맞음 '...' 짝 확인
이름을 만들 때 등록 키를 물어봄 이름이 Z나 Y로 시작하지 않음 연습용은 YG##_...으로 바꾸기
고쳤는데 결과가 그대로 저장만 하고 활성화 안 함 Ctrl+F3
##이 그대로 남은 이름 내 번호로 안 바꿈 G## → G05처럼 바꾸기

2-7. 한 걸음 더: Text Symbol

지금까지는 출력할 글자를 코드 안에 직접 썼어요. 그런데 회사 프로그램은 같은 프로그램을 한국어, 영어로 함께 쓰는 경우가 많아서, 글자를 코드 밖 Text Symbol에 따로 모아 두는 습관을 들여요. 1주차 과제에서 써 본 TEXT-001이 바로 이거예요.

직접 해 보기
  1. ABAP Editor 메뉴에서 Goto → Text Elements로 들어가요.
  2. Text Symbols 탭에서 Sym 칸에 001, Text 칸에 Hello ABAP을 입력해요.
  3. 이 화면에서도 저장 후 활성화(Ctrl+F3)를 해요. F3으로 코드 화면에 돌아와요.
  4. 코드를 아래처럼 바꾸고 실행해서 결과가 같은지 확인해요.
REPORT yg##_02_hello.

START-OF-SELECTION.
  WRITE TEXT-001.               " Text Symbol 001의 글자를 출력해요
  WRITE / '안녕하세요, ABAP!'.
자주 하는 실수

Text Symbol은 따로 활성화해야 해요. 프로그램만 활성화하고 Text Symbol을 안 하면 실행했을 때 그 자리가 비어서 나와요.

2-8. 미니 실습: 자기소개 프로그램

직접 해 보기

프로그램 YG##_02_INTRO를 새로 만들어서 아래 결과가 나오게 해 보세요.

  • 제목(Title)은 자기소개로 해요.
  • WRITE는 체인 문장 한 개로 써요.
  • 맨 위에 * 주석으로 "작성자, 작성일"을 남겨요.
  • 첫 줄의 CODE 2기 자기소개는 Text Symbol 001로 출력해요.
예시 답안 보기
*&---------------------------------------------------------------------*
* 작성자: 홍길동
* 작성일: 2026-11-17
* 설명  : 체인 문장과 Text Symbol 연습
*&---------------------------------------------------------------------*
REPORT yg##_02_intro.

START-OF-SELECTION.
  WRITE: TEXT-001,                       " Text Symbol 001: CODE 2기 자기소개
         / '이름: 홍길동',
         / '반: CODE 2기 부산반',
         / '한마디: ABAP 잘해 보고 싶어요!'.
확인 문제
  1. 코드를 고치고 저장만 했어요. 다른 친구가 내 프로그램을 실행하면 고친 내용이 보일까요?
  2. 아래 코드에서 틀린 곳 두 군데를 찾아보세요. 
    START-OF-SELECTION.
  WRITE 'Hello'
  WRITE / 'ABAP".
  3. *로 시작하는 주석과 "로 시작하는 주석은 어떻게 다를까요?
  4. 아래 세 줄을 체인 문장 하나로 바꿔 보세요. 
    WRITE 'A'.
WRITE / 'B'.
WRITE / 'C'.
정답 보기
  1. 안 보여요. 저장만 한 것은 Inactive(초안)라서, 다른 사람은 활성화된 옛 버전을 실행해요. Ctrl+F3로 활성화해야 해요.
  2. ① WRITE 'Hello' 끝에 마침표가 없어요. ② 'ABAP"는 작은따옴표로 열고 큰따옴표로 닫아서 따옴표 짝이 안 맞아요. 게다가 "부터는 주석이 되어 버려요. 'ABAP'으로 고쳐요.
  3. *는 줄 맨 첫 칸에 써서 그 줄 전체를 주석으로 만들고, "는 줄 어디서든 쓸 수 있고 그 자리부터 줄 끝까지 주석이에요.
  4. WRITE: 'A',
       / 'B',
       / 'C'.
정리
  • 프로그램은 SE38 → 속성 → Local Object → 코드 → 저장 → 검사 → 활성화 → 실행 순서로 만들어요.
  • 저장은 초안(Inactive), 활성화는 정식 버전(Active)이에요. 고친 뒤엔 꼭 활성화해요.
  • ABAP 문장은 마침표로 끝나고, 대소문자를 가리지 않고, 주석은 *와 "로 달아요.
  • 같은 키워드가 반복되면 :와 ,로 묶는 체인 문장을 써요.
  • 출력할 글자는 Text Symbol(TEXT-001)로 빼 두는 습관을 들여요. Text Symbol도 따로 활성화해요.
다음 장 예고

지금은 정해진 글자만 출력했어요. 3장에서는 변수를 만들어 숫자를 계산하고, 문자열을 이어 붙이고, 오늘 날짜를 출력해 볼 거예요.
