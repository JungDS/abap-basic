4장

조건문과 반복문

이번 장 목표
  • IF와 CASE로 조건에 따라 다른 일을 하게 만들 수 있어요.
  • 비교 연산자와 AND·OR·NOT으로 조건을 정확하게 쓸 수 있어요.
  • DO와 WHILE로 같은 일을 여러 번 반복하고, sy-index로 몇 번째인지 알 수 있어요.
  • EXIT·CONTINUE로 반복을 멈추거나 건너뛸 수 있어요.

4-1. 조건에 따라 다르게: IF

지금까지의 프로그램은 위에서 아래로 한 줄씩 전부 실행됐어요. 하지만 "60점 이상이면 합격, 아니면 불합격"처럼 상황에 따라 다른 일을 해야 할 때가 많아요. 이때 쓰는 것이 IF예요.

DATA gv_score TYPE i VALUE 75.

START-OF-SELECTION.
  IF gv_score >= 60.
    WRITE / '합격이에요'.
  ELSE.
    WRITE / '아쉽지만 불합격이에요'.
  ENDIF.
  • IF 조건. 뒤에는 조건이 맞을 때 할 일을 써요.
  • ELSE. 뒤에는 조건이 틀릴 때 할 일을 써요. 필요 없으면 ELSE 부분은 빼도 돼요.
  • 마지막은 꼭 ENDIF.로 닫아요. IF마다 ENDIF가 하나씩 짝을 이뤄요.
  • 조건 안쪽 줄은 두 칸 들여 써서 "여기는 IF 안이에요"가 보이게 해요(Shift+F1).

4-2. 비교 연산자

뜻 기호 글자로 쓰기 예
같다 = EQ gv_a = 10
다르다 <> NE gv_a <> 0
작다 < LT gv_a < 60
크다 > GT gv_a > 100
작거나 같다 <= LE gv_a <= 9
크거나 같다 >= GE gv_a >= 1
사이에 있다 BETWEEN … AND … gv_a BETWEEN 1 AND 100
비어 있다(초기값) IS INITIAL gv_name IS INITIAL

기호와 글자는 뜻이 똑같아요. 회사 코드에서는 둘 다 보이니 읽을 줄만 알면 돼요. 이 교재는 기호를 써요.

BETWEEN은 양 끝을 포함해요

gv_a BETWEEN 1 AND 100은 gv_a >= 1 AND gv_a <= 100과 같아요. 1과 100도 "사이"에 들어가요.

4-3. 여러 갈래로 나누기: ELSEIF

갈래가 셋 이상이면 ELSEIF를 이어 써요. 위에서부터 차례로 검사하다가 처음 맞는 곳 하나만 실행해요.

DATA gv_score TYPE i VALUE 85.

START-OF-SELECTION.
  IF gv_score >= 90.
    WRITE / 'A 등급'.
  ELSEIF gv_score >= 80.
    WRITE / 'B 등급'.          " 85점은 여기서 멈춰요
  ELSEIF gv_score >= 70.
    WRITE / 'C 등급'.
  ELSE.
    WRITE / '다시 도전!'.
  ENDIF.
자주 하는 실수
  • 순서가 거꾸로면 결과가 틀려요. IF gv_score >= 70.을 맨 위에 두면 95점도 첫 줄에서 걸려서 C 등급이 돼요. 큰 기준부터 차례로 써요.
  • ELSEIF는 붙여서 한 단어로 써요. ELSE IF로 띄우면 문법 오류가 나요.

4-4. 조건 여러 개 묶기: AND · OR · NOT

연산자 뜻 예
AND 둘 다 맞아야 gv_age >= 20 AND gv_age < 30 (20대)
OR 하나만 맞아도 gv_day = 6 OR gv_day = 7 (주말)
NOT 반대로 NOT gv_name IS INITIAL (이름이 비어 있지 않으면) 
IF gv_num < 1 OR gv_num > 100.
  WRITE / '1부터 100 사이의 숫자만 넣어 주세요'.
ENDIF.
자주 하는 실수

IF gv_day = 6 OR 7.처럼 쓰면 안 돼요. 사람 말로는 자연스럽지만 ABAP은 OR 양쪽을 각각 완전한 조건으로 읽어요. IF gv_day = 6 OR gv_day = 7.처럼 변수를 다시 써 줘요.

조건이 헷갈릴 땐 괄호

AND와 OR를 섞으면 AND가 먼저 묶여요. 헷갈리면 괄호로 확실하게 묶어 주세요. 괄호 안쪽은 꼭 한 칸씩 띄워요.

IF ( gv_day = 6 OR gv_day = 7 ) AND gv_rain = 'X'.

4-5. 값 하나로 갈래 나누기: CASE

변수 하나의 값에 따라 갈래가 여러 개라면 CASE가 더 읽기 쉬워요.

DATA gv_menu TYPE i VALUE 2.

START-OF-SELECTION.
  CASE gv_menu.
    WHEN 1.
      WRITE / '아메리카노'.
    WHEN 2.
      WRITE / '카페라테'.
    WHEN 3 OR 4.
      WRITE / '스무디'.
    WHEN OTHERS.
      WRITE / '없는 메뉴예요'.
  ENDCASE.
  • WHEN 값. 아래에 그 값일 때 할 일을 써요. WHEN 3 OR 4.처럼 여러 값을 묶을 수도 있어요.
  • WHEN OTHERS.는 위의 어떤 값에도 해당하지 않을 때예요. IF의 ELSE와 같아요.
  • 마지막은 ENDCASE.로 닫아요.
IF와 CASE, 언제 뭘 쓰나요?

"값이 1이면, 2면, 3이면…"처럼 같은 변수의 값을 하나씩 비교하면 CASE, "60점 이상이면"처럼 범위나 여러 변수를 비교하면 IF가 잘 어울려요.

4-6. 정해진 횟수만큼 반복: DO … TIMES

같은 일을 여러 번 해야 할 때 코드를 복사해서 붙이는 대신 반복문을 써요.

DO 3 TIMES.
  WRITE / 'ABAP 화이팅!'.
ENDDO.

DO 횟수 TIMES.와 ENDDO. 사이를 정한 횟수만큼 반복해요. 이 코드는 ABAP 화이팅!을 세 줄 출력해요.

몇 번째 바퀴인지 알려 주는 sy-index

반복하는 동안 SAP는 지금이 몇 번째 바퀴인지를 시스템 필드 sy-index에 넣어 줘요. 첫 바퀴는 1, 두 번째 바퀴는 2예요. 이걸 이용하면 1부터 5까지 더하기를 이렇게 쓸 수 있어요.

DATA gv_sum TYPE i.

START-OF-SELECTION.
  DO 5 TIMES.
    gv_sum = gv_sum + sy-index.
  ENDDO.

  WRITE: / '1부터 5까지의 합:', gv_sum.     " 15

이렇게 표로 값을 따라가 보는 연습을 해 두면, 6장에서 디버거로 직접 확인할 때 훨씬 쉬워요.

4-7. 조건이 될 때까지 반복: EXIT와 WHILE

몇 번 반복할지 미리 모를 때도 있어요. 예를 들어 "1부터 차례로 더하다가 합이 100을 넘는 순간 멈추기"가 그래요.

방법 1. DO + EXIT

DO.에 횟수를 쓰지 않으면 계속 반복해요. 멈추고 싶은 곳에서 EXIT.를 쓰면 반복문을 빠져나가요.

DATA: gv_sum   TYPE i,
      gv_count TYPE i.

START-OF-SELECTION.
  DO.
    gv_sum = gv_sum + sy-index.
    IF gv_sum > 100.
      gv_count = sy-index.     " 몇 번째에서 멈췄는지 기억해 두기
      EXIT.                    " 반복문 빠져나가기
    ENDIF.
  ENDDO.

  WRITE: / '더한 횟수:', gv_count,     " 14
         / '합계:',      gv_sum.       " 105

방법 2. WHILE

WHILE 조건.은 조건이 맞는 동안 반복해요. 바퀴를 시작하기 전에 조건부터 검사해요.

DATA: gv_sum TYPE i,
      gv_num TYPE i.

START-OF-SELECTION.
  WHILE gv_sum <= 100.
    gv_num = gv_num + 1.
    gv_sum = gv_sum + gv_num.
  ENDWHILE.

  WRITE: / '더한 횟수:', gv_num,      " 14
         / '합계:',      gv_sum.      " 105
자주 하는 실수
  • 반복문이 끝나면 sy-index는 반복 전 값(보통 0)으로 돌아가요. 그래서 위 DO 예제처럼 ENDDO 뒤에서 몇 번째였는지 알고 싶으면, 반복문 안에서 다른 변수에 옮겨 둬야 해요.
  • EXIT가 없는 DO.는 끝나지 않아요(무한 반복). 프로그램이 멈춘 것처럼 보이면 SAP GUI 창 왼쪽 위의 아이콘(Customize Local Layout, Alt+F12) 메뉴에서 Stop Transaction을 눌러 멈춰요. WHILE도 조건이 영원히 맞으면 똑같아요.

4-8. 이번 바퀴만 건너뛰기: CONTINUE와 CHECK

EXIT가 반복문 전체를 끝낸다면, CONTINUE는 이번 바퀴만 건너뛰고 다음 바퀴로 가요.

DO 10 TIMES.
  IF sy-index MOD 2 = 0.     " 짝수면
    CONTINUE.                " 아래는 건너뛰고 다음 바퀴로
  ENDIF.
  WRITE / sy-index.          " 1 3 5 7 9 만 출력돼요
ENDDO.

같은 일을 CHECK로 더 짧게 쓸 수도 있어요. CHECK 조건.은 조건이 틀리면 이번 바퀴의 나머지를 건너뛰어요.

DO 10 TIMES.
  CHECK sy-index MOD 2 = 1.  " 홀수일 때만 아래로 내려가요
  WRITE / sy-index.
ENDDO.
자주 하는 실수

CHECK와 EXIT는 반복문 밖에서 쓰면 반복문이 아니라 지금 실행 중인 블록(예: START-OF-SELECTION) 전체를 끝내 버려요. 지금은 반복문 안에서만 쓰기로 해요.

4-9. 반복 안의 반복: 구구단

반복문 안에 반복문을 넣을 수도 있어요. 구구단 2단과 3단을 출력해 볼게요.

REPORT yg##_04_gugu.

DATA: gv_dan    TYPE i,
      gv_result TYPE i.

START-OF-SELECTION.
  DO 2 TIMES.                        " 바깥 반복: 단 (2단, 3단)
    gv_dan = sy-index + 1.           " 1, 2 → 2, 3
    DO 9 TIMES.                      " 안쪽 반복: 곱하는 수 (1~9)
      gv_result = gv_dan * sy-index.
      WRITE: /(2) gv_dan, 'x', (1) sy-index, '=', (2) gv_result.
    ENDDO.
    SKIP.                            " 단 사이에 빈 줄 하나
  ENDDO.
  • 반복문이 겹치면 sy-index는 지금 돌고 있는 가장 안쪽 반복문의 바퀴 수예요. 그래서 바깥쪽 바퀴 수(단)는 안쪽 반복이 시작되기 전에 gv_dan에 옮겨 둬요.
  • WRITE 뒤 /(2), (1)처럼 괄호 안에 숫자를 쓰면 그 칸 수만큼만 써서 출력해요. 3장에서 본 숫자 앞의 긴 공백을 줄일 수 있어요.
  • SKIP.은 빈 줄을 하나 넣어요.
자주 하는 실수

(2)처럼 칸을 정했는데 값이 더 길면 잘려서 나와요. 숫자는 앞에 *가 붙어서 "칸이 모자라요"라고 알려 줘요. 예를 들어 합계가 100을 넘을 수 있는데 (2) gv_sum으로 쓰면 *0처럼 보여요. 나올 수 있는 가장 큰 값을 생각해서 칸 수를 정해요.

4-10. 미니 실습: 3의 배수 모으기

직접 해 보기

프로그램 YG##_04_MULTI를 만들어 보세요.

  1. 1부터 20까지 반복하면서 3의 배수만 출력해요. (MOD와 CONTINUE 또는 CHECK)
  2. 출력한 3의 배수를 모두 더해서 합계를 출력해요.
  3. 합계가 50보다 크면 많이 모았어요!, 아니면 조금 더 모아 봐요를 출력해요. (IF … ELSE)
예시 답안 보기
*&---------------------------------------------------------------------*
* 설명: 반복문(DO), 건너뛰기(CHECK), 조건문(IF) 연습
*&---------------------------------------------------------------------*
REPORT yg##_04_multi.

DATA gv_sum TYPE i.

START-OF-SELECTION.
  " 1~20 중 3의 배수만 출력하고 더하기
  DO 20 TIMES.
    CHECK sy-index MOD 3 = 0.        " 3의 배수가 아니면 건너뛰기
    WRITE: /(2) sy-index.
    gv_sum = gv_sum + sy-index.
  ENDDO.

  WRITE: / '합계:', gv_sum.

  " 합계에 따라 다른 메시지
  IF gv_sum > 50.
    WRITE / '많이 모았어요!'.
  ELSE.
    WRITE / '조금 더 모아 봐요'.
  ENDIF.
확인 문제
  1. 아래 코드에서 gv_score가 95일 때 무엇이 출력될까요? 그리고 무엇이 문제일까요? 
    IF gv_score >= 60.
  WRITE '합격'.
ELSEIF gv_score >= 90.
  WRITE '우수'.
ENDIF.
  2. IF gv_a = 1 OR 2.는 왜 틀렸을까요? 바르게 고쳐 보세요.
  3. 아래 코드가 끝난 뒤 gv_x의 값은 얼마일까요? 
    DO 4 TIMES.
  gv_x = gv_x + 10.
ENDDO.
  4. EXIT와 CONTINUE의 차이를 한 문장으로 말해 보세요.
  5. 반복문이 끝난 뒤 WRITE sy-index.를 했더니 0이 나왔어요. 왜 그럴까요?
정답 보기
  1. 합격이 출력돼요. 95점은 첫 조건 >= 60에서 이미 맞아서 아래 ELSEIF는 검사하지 않아요. 큰 기준(>= 90)을 먼저 써야 해요.
  2. OR 양쪽은 각각 완전한 조건이어야 해요. IF gv_a = 1 OR gv_a = 2.로 고쳐요.
  3. 40이에요(처음 값이 0이라면). 네 바퀴 동안 10씩 더해요.
  4. EXIT는 반복문을 완전히 끝내고, CONTINUE는 이번 바퀴만 건너뛰고 다음 바퀴를 계속해요.
  5. 반복문이 끝나면 sy-index가 반복 전 값으로 돌아가기 때문이에요. 바퀴 수가 필요하면 반복문 안에서 다른 변수에 옮겨 둬요.
정리
  • IF … ELSEIF … ELSE … ENDIF로 조건에 따라 다른 일을 해요. 위에서부터 처음 맞는 하나만 실행해요.
  • 같은 변수의 값으로 갈래를 나눌 땐 CASE … WHEN … ENDCASE가 읽기 좋아요.
  • DO n TIMES는 정해진 횟수, DO + EXIT나 WHILE은 조건이 될 때까지 반복해요.
  • sy-index는 지금 몇 번째 바퀴인지 알려 주고, 반복문이 끝나면 원래 값으로 돌아가요.
  • EXIT는 반복 끝내기, CONTINUE·CHECK는 이번 바퀴 건너뛰기예요.
다음 장 예고

지금은 점수나 숫자를 코드 안에 직접 적어 넣었어요. 5장에서는 프로그램을 실행할 때 사용자에게 값을 입력받는 화면(Selection Screen)을 만들고, 잘못된 값은 오류 메시지로 막아 볼 거예요.
