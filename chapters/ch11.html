11장

ALV로 결과 보기

이번 장 목표
  • WRITE 목록과 ALV의 차이를 말할 수 있어요.
  • CL_SALV_TABLE로 Internal Table을 ALV 화면에 띄울 수 있어요.
  • 컬럼 제목이 Data Element에서 온다는 것을 알고, 칸 숨기기·제목 바꾸기·폭 맞추기를 할 수 있어요.
  • 정렬, 필터, 합계, 엑셀 내려받기 버튼을 켤 수 있어요.

11-1. ALV가 뭐예요?

지금까지는 결과를 WRITE로 한 줄씩 찍었어요. 칸을 맞추려고 (20)처럼 길이를 정하고, 정렬하고 싶으면 SORT를 코드에 넣어야 했죠.

ALV(ABAP List Viewer)는 Internal Table을 넘겨주기만 하면 표 화면을 만들어 주는 SAP의 도구예요. 사용자가 화면에서 직접 정렬하고, 거르고, 합계를 내고, 엑셀로 내려받을 수 있어요. 회사에서 쓰는 조회 프로그램은 대부분 결과를 ALV로 보여 줘요.

WRITE 목록 ALV
칸 맞추기 길이를 직접 정해요 알아서 맞춰요
컬럼 제목 직접 찍어야 해요 Data Element에서 자동으로 와요
정렬·필터·합계 코드로 해야 해요 사용자가 버튼으로 해요
엑셀 내려받기 어려워요 버튼 하나예요

ALV를 만드는 방법은 여러 가지가 있어요. 이 교재에서는 코드가 가장 짧은 CL_SALV_TABLE 클래스를 써요.

11-2. 가장 짧은 ALV

9장에서 읽어 온 gt_book을 그대로 ALV로 띄워 볼게요.

REPORT yg##_11_alv.

DATA: gt_book TYPE TABLE OF yg##_book,
      go_alv  TYPE REF TO cl_salv_table.     " ALV를 가리키는 변수

START-OF-SELECTION.
  " 1. 데이터 읽기 (9장)
  SELECT * FROM yg##_book INTO TABLE gt_book.

  " 2. ALV 만들기
  TRY.
      cl_salv_table=>factory(
        IMPORTING
          r_salv_table = go_alv
        CHANGING
          t_table      = gt_book ).
    CATCH cx_salv_msg.
      MESSAGE 'ALV를 만들지 못했어요.' TYPE 'S' DISPLAY LIKE 'E'.
      RETURN.
  ENDTRY.

  " 3. 화면에 띄우기
  go_alv->display( ).

실행하면 책 다섯 권이 표로 나와요. F3(Back)을 누르면 돌아가요. 새로 나온 것을 하나씩 볼게요.

코드 뜻
TYPE REF TO cl_salv_table go_alv는 값을 담는 칸이 아니라 ALV 객체를 가리키는 손잡이예요. 객체는 factory가 만들어 줘요.
cl_salv_table=>factory( … ) 클래스의 Method를 불러 ALV 객체를 만들어요. =>는 10장에서 본 "이 클래스의"예요.
t_table = gt_book 보여 줄 Internal Table을 넘겨요.
go_alv->display( ) 만든 ALV를 화면에 띄워요. 객체의 Method는 ->로 불러요.
TRY … CATCH … ENDTRY factory가 실패하면 예외 cx_salv_msg를 던져요. CATCH에서 받아 처리해요. 10장 EXCEPTIONS의 클래스 버전이라고 생각하면 돼요.
`=>`와 `->`
  • 클래스=>메서드( ): 클래스 이름으로 바로 불러요. 10장의 lcl_calc=>discount( ), 여기의 cl_salv_table=>factory( )가 그래요.
  • 객체->메서드( ): 만들어진 객체로 불러요. go_alv->display( )처럼요.

화살표 모양만 기억해 두면 충분해요. 객체지향은 다음 과정에서 자세히 배워요.

자주 하는 실수
  • display( )를 빼먹으면 아무것도 안 나와요. 만들기(factory)와 띄우기(display)는 따로예요.
  • factory보다 먼저 데이터를 읽어 와야 해요. 순서를 바꾸면 빈 표가 나와요.
  • 괄호 안쪽은 앞뒤를 한 칸씩 띄워요. display()처럼 붙이면 오류가 나요. 빈 괄호도 display( )예요.

11-3. 컬럼 제목은 어디서 와요?

ALV를 띄워 보면 칸 이름이 TITLE이 아니라 "도서 제목"처럼 나와요. 7장에서 Data Element를 만들 때 적은 Field Label을 ALV가 가져다 쓰기 때문이에요.

  • Data Element를 쓴 칸은 제목이 자동으로 붙어요. 칸 폭에 따라 Short·Medium·Long 이름표 중 하나를 골라 써요.
  • TYPE c LENGTH 20처럼 Data Element 없이 만든 칸은 제목이 비어 보여요.
  • 그래서 Internal Table을 직접 만들 때도 TYPE yg##_book-title처럼 Table의 칸을 참조하면 좋아요. 그 칸의 Data Element가 따라와요.
TYPES: BEGIN OF ty_list,
         book_id TYPE yg##_book-book_id,    " 제목: 도서 번호
         title   TYPE yg##_book-title,      " 제목: 도서 제목
         memo    TYPE c LENGTH 20,          " 제목: (비어 있음)
       END OF ty_list.

칸 다듬기: 폭 맞추기, 숨기기, 제목 바꾸기

display( ) 전에 컬럼 설정을 바꿀 수 있어요.

DATA: go_columns TYPE REF TO cl_salv_columns_table,
      go_column  TYPE REF TO cl_salv_column.

...
  go_columns = go_alv->get_columns( ).        " 컬럼 전체를 가리키는 손잡이

  " 1. 모든 칸 폭을 내용에 맞추기
  go_columns->set_optimize( abap_true ).

  TRY.
      " 2. MANDT 칸 숨기기
      go_column = go_columns->get_column( 'MANDT' ).
      go_column->set_visible( abap_false ).

      " 3. STOCK 칸 제목 바꾸기
      go_column = go_columns->get_column( 'STOCK' ).
      go_column->set_short_text( '남은 재고' ).
      go_column->set_medium_text( '남은 재고' ).
      go_column->set_long_text( '남은 재고' ).
    CATCH cx_salv_not_found.
      " 칸 이름을 잘못 적으면 여기로 와요
  ENDTRY.

  go_alv->display( ).
  • abap_true는 'X', abap_false는 ' '(공백)이에요. "켜기/끄기"를 뜻하는 이름 있는 값이에요.
  • get_column( 'MANDT' )의 칸 이름은 대문자로 적어요. 없는 이름이면 cx_salv_not_found가 일어나요.
  • 제목은 Short(10자)·Medium(20자)·Long(40자) 세 가지가 있어요. ALV가 칸 폭에 따라 골라 쓰니 세 개 모두 바꿔 두는 것이 안전해요.
MANDT는 왜 나와요?

SELECT *로 Table의 모든 칸을 읽었으니 MANDT도 Internal Table에 들어 있어요. 사용자에게는 필요 없는 칸이라 숨기는 경우가 많아요. 처음부터 필요한 칸만 SELECT해서 담는 방법(9장 필드 목록)도 좋아요.

11-4. 버튼 켜기: 정렬 · 필터 · 합계 · 엑셀

CL_SALV_TABLE은 처음에는 툴바 버튼이 거의 없어요. 한 줄로 기본 버튼을 모두 켤 수 있어요.

  go_alv->get_functions( )->set_all( abap_true ).     " 툴바 버튼 모두 켜기

get_functions( )가 돌려준 객체에서 바로 ->set_all( )을 부르는 모양이에요. 이렇게 Method 호출을 이어서 쓸 수 있어요.

번호 버튼 쓰는 법
1 정렬 컬럼 제목을 클릭해 고른 뒤 누르면 그 칸 기준으로 정렬돼요. 그림은 가격 내림차순이에요.
2 필터 칸을 고르고 조건(예: 장르 = I)을 넣으면 그 줄만 남아요.
3 합계 숫자 칸을 고르고 누르면 맨 아래에 합계 줄이 생겨요.
4 내보내기 Export → Spreadsheet로 엑셀 파일을 내려받아요.
5 레이아웃 보이는 칸과 칸 순서를 바꿔요.

버튼 모양과 위치는 SAP GUI 버전과 테마에 따라 조금씩 달라요. 아이콘에 마우스를 올리면 이름이 나오니 확인해 보세요.

직접 해 보기
  1. YG##_11_ALV에 위의 컬럼 설정 코드와 set_all 한 줄을 넣고 실행해요.
  2. 가격 컬럼 제목을 클릭한 뒤 내림차순 버튼을 눌러요.
  3. 그대로 합계 버튼을 눌러 가격 합계가 98,000인지 확인해요.
  4. 장르 칸에 필터를 걸어 I인 책만 남겨 봐요.
  5. Export 버튼으로 엑셀 파일을 내려받아 열어 봐요.

화면 꾸미기: 제목과 줄무늬

  DATA go_display TYPE REF TO cl_salv_display_settings.

  go_display = go_alv->get_display_settings( ).
  go_display->set_list_header( '도서 목록' ).         " 화면 제목
  go_display->set_striped_pattern( abap_true ).      " 한 줄씩 줄무늬

11-5. 정리: ALV 프로그램의 순서

ALV 프로그램은 거의 항상 이 순서예요. 12장 종합 실습도 이 뼈대로 만들어요.

회사 프로그램에서 만날 다른 ALV

오래된 프로그램에서는 Function Module REUSE_ALV_GRID_DISPLAY로 만든 ALV를 자주 봐요. 화면 일부에 ALV를 넣을 때는 CL_GUI_ALV_GRID 클래스를 써요. 이름은 달라도 "Internal Table을 넘기면 표가 나온다"는 생각은 같아요. 처음에는 CL_SALV_TABLE로 익히고, 필요할 때 넓혀 가면 돼요.

11-6. 미니 실습: 재고 부족 도서 ALV

직접 해 보기

프로그램 YG##_11_STOCK을 만들어요.

  1. Selection Screen에서 기준 재고(pa_stock, 기본값 3)를 받아요.
  2. 재고가 기준보다 적은 책만 읽어요. 재고가 적은 순서로 가져와요(ORDER BY stock).
  3. 한 권도 없으면 메시지("재고가 부족한 책이 없어요.")를 띄우고 끝내요.
  4. ALV로 띄워요. 폭 맞추기, MANDT 숨기기, 툴바 버튼 모두 켜기, 화면 제목 "재고 부족 도서"를 넣어요.
예시 답안 보기
REPORT yg##_11_stock.

DATA: gt_book    TYPE TABLE OF yg##_book,
      go_alv     TYPE REF TO cl_salv_table,
      go_columns TYPE REF TO cl_salv_columns_table,
      go_column  TYPE REF TO cl_salv_column.

PARAMETERS pa_stock TYPE yg##_e_stock DEFAULT 3.

START-OF-SELECTION.
  " 1. 데이터 읽기
  SELECT * FROM yg##_book
    INTO TABLE gt_book
    WHERE stock < pa_stock
    ORDER BY stock.

  IF sy-subrc <> 0.
    MESSAGE '재고가 부족한 책이 없어요.' TYPE 'S' DISPLAY LIKE 'E'.
    RETURN.
  ENDIF.

  " 2. ALV 만들기
  TRY.
      cl_salv_table=>factory(
        IMPORTING
          r_salv_table = go_alv
        CHANGING
          t_table      = gt_book ).
    CATCH cx_salv_msg.
      MESSAGE 'ALV를 만들지 못했어요.' TYPE 'S' DISPLAY LIKE 'E'.
      RETURN.
  ENDTRY.

  " 3. 설정하기
  go_columns = go_alv->get_columns( ).
  go_columns->set_optimize( abap_true ).
  TRY.
      go_column = go_columns->get_column( 'MANDT' ).
      go_column->set_visible( abap_false ).
    CATCH cx_salv_not_found.
  ENDTRY.

  go_alv->get_functions( )->set_all( abap_true ).
  go_alv->get_display_settings( )->set_list_header( '재고 부족 도서' ).

  " 4. 띄우기
  go_alv->display( ).
확인 문제
  1. cl_salv_table=>factory( … )까지만 쓰고 실행했더니 아무 화면도 나오지 않았어요. 무엇을 빠뜨렸을까요?
  2. Internal Table의 칸을 TYPE c LENGTH 40으로 만들었더니 ALV 컬럼 제목이 비어 있어요. 어떻게 하면 제목이 자동으로 나올까요?
  3. =>와 ->는 각각 언제 써요?
  4. get_column( 'mandt' )처럼 소문자로 적으면 어떻게 될까요?
  5. 사용자가 엑셀로 내려받고 싶어 하는데 툴바에 버튼이 없어요. 어떤 한 줄을 넣으면 될까요?
정답 보기
  1. go_alv->display( ).예요. factory는 ALV를 만들기만 하고, 띄우는 건 display예요.
  2. TYPE yg##_book-title처럼 Table의 칸이나 Data Element를 참조해요. 그 Data Element의 Field Label이 제목이 돼요.
  3. =>는 클래스 이름으로 부를 때(cl_salv_table=>factory), ->는 만들어진 객체로 부를 때(go_alv->display) 써요.
  4. 칸을 찾지 못해서 cx_salv_not_found 예외가 일어나요. 칸 이름은 대문자로 적어요.
  5. go_alv->get_functions( )->set_all( abap_true ).예요.
정리
  • ALV는 Internal Table을 넘기면 정렬·필터·합계·엑셀이 되는 표 화면을 만들어 줘요.
  • 순서는 읽기 → factory → 설정 → display예요. factory는 TRY … CATCH cx_salv_msg로 감싸요.
  • 컬럼 제목은 Data Element의 Field Label에서 와요. Data Element 없는 칸은 제목이 비어요.
  • get_columns( )로 폭 맞추기(set_optimize), 숨기기(set_visible), 제목 바꾸기(set_short_text 등)를 해요.
  • get_functions( )->set_all( abap_true )로 툴바 버튼을 켜요.
